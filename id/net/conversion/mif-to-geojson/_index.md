        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="" >}}

GeoJSON adalah format berbasis JSON yang dirancang untuk mewakili fitur geografis dengan atribut non-spasialnya. Format ini mendefinisikan berbagai objek JSON (Notasi Objek JavaScript) dan cara penyambungannya. Format JSON mewakili informasi kolektif tentang fitur Geografis, luas spasialnya, dan propertinya. Sebuah objek dari file ini dapat menunjukkan geometri (Titik, LineString, Poligon), fitur atau kumpulan fitur. Fitur-fitur tersebut mencerminkan alamat dan tempat sebagai titik, jalan utama dan perbatasan sebagai garis lurus, serta negara, provinsi, dan wilayah daratan sebagai poligon. Dengan GeoJSON, berbagai aplikasi perutean dan navigasi seluler dapat menunjukkan cakupan layanan mereka. TopoJSON adalah ekstensi dari GeoJSON yang lebih kecil ukurannya dan menyandikan topologi geospatial.
