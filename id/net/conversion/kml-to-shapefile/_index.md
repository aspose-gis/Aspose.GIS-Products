SHP adalah ekstensi file untuk salah satu jenis file utama yang digunakan untuk representasi ESRI Shapefile. Ini mewakili informasi Geospatial dalam bentuk data vektor untuk digunakan oleh aplikasi Geographic Information Systems (GIS). Format ini telah dikembangkan sebagai spesifikasi terbuka untuk memfasilitasi interoperabilitas antara ESRI dan produk perangkat lunak lainnya.
