File dengan ekstensi CSV (Comma Separated Values) mewakili file teks biasa yang berisi catatan data dengan nilai dipisahkan koma. Setiap baris dalam file CSV adalah catatan baru dari kumpulan catatan yang terkandung dalam file. File tersebut dibuat ketika transfer data dimaksudkan dari satu sistem penyimpanan ke sistem lainnya. Karena semua aplikasi dapat mengenali catatan yang dipisahkan oleh koma, impor file tersebut ke database dilakukan dengan sangat mudah.

Ekstensi GPX mewakili format Pertukaran GPS untuk pertukaran data GPS antara aplikasi dan layanan web di internet. Ini adalah format XML ringan yang berisi data GPS yaitu titik jalan, rute, dan trek yang akan diimpor dan dibaca oleh banyak program. GPX bersifat terbuka dan didukung oleh berbagai aplikasi dan perangkat GPS.
