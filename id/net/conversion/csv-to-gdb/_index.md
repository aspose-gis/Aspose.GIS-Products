File dengan ekstensi CSV (Comma Separated Values) mewakili file teks biasa yang berisi catatan data dengan nilai dipisahkan koma. Setiap baris dalam file CSV adalah catatan baru dari kumpulan catatan yang terkandung dalam file. File tersebut dibuat ketika transfer data dimaksudkan dari satu sistem penyimpanan ke sistem penyimpanan lainnya. Karena semua aplikasi dapat mengenali catatan yang dipisahkan oleh koma, impor file tersebut ke database dilakukan dengan sangat mudah.
