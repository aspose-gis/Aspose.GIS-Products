## Fitur

*   Mendukung berbagai format GeoTIFF, termasuk data multibanda dan georeferensi.
*   Antarmuka pengguna yang intuitif untuk navigasi dan zoom.
*   Opsi untuk menyesuaikan tampilan warna dan transparansi.
*   Kemampuan untuk mengukur jarak dan area.
*   Dukungan untuk koordinat proyeksi dan sistem.

## Penggunaan

1.  Buka Penampil GeoTIFF di browser web Anda.
2.  Muat file GeoTIFF menggunakan tombol "Pilih File".
3.  Gunakan kontrol navigasi untuk menjelajahi gambar.
4.  Sesuaikan tampilan warna dan transparansi sesuai kebutuhan.
5.  Gunakan alat pengukuran untuk mengukur jarak dan area.

## Contoh

Berikut adalah contoh cara menggunakan Penampil GeoTIFF untuk melihat gambar satelit:

1.  Muat file GeoTIFF yang berisi gambar satelit.
2.  Zoom ke area minat.
3.  Sesuaikan tampilan warna untuk meningkatkan visibilitas fitur.
4.  Gunakan alat pengukuran untuk mengukur jarak antara dua titik.

## Pemecahan Masalah

Jika Anda mengalami masalah dengan Penampil GeoTIFF, coba langkah-langkah berikut:

*   Pastikan file GeoTIFF valid dan tidak rusak.
*   Periksa apakah browser web Anda mendukung format gambar yang diperlukan.
*   Coba hapus cache browser Anda.
*   Hubungi dukungan teknis untuk bantuan lebih lanjut.
