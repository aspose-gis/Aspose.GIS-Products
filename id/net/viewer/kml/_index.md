## Apa itu KML?
KML (Keyhole Markup Language) adalah bahasa markup berbasis XML yang digunakan untuk menampilkan data geografis di Bumi. Ini sering digunakan untuk membuat peta dengan fitur-fitur seperti tempat, rute, dan bentuk.

## Penampil KML
Penampil KML memungkinkan Anda melihat file KML dan KMZ. Anda dapat memperbesar dan menggeser peta, serta memilih berbagai lapisan.

## Fitur
* Dukungan untuk file KML dan KMZ
* Kemampuan untuk memperbesar dan menggeser peta
* Pemilihan lapisan
* Pencarian fitur
* Ekspor data sebagai format lain

## Cara Menggunakan
1. Buka Penampil KML.
2. Klik tombol "Buka".
3. Pilih file KML atau KMZ yang ingin Anda lihat.
4. Gunakan kontrol untuk memperbesar, menggeser, dan memilih lapisan.

## Contoh
Berikut adalah beberapa contoh penggunaan Penampil KML:

* Melihat peta lokasi tempat wisata
* Merencanakan rute perjalanan
* Menampilkan data lingkungan
