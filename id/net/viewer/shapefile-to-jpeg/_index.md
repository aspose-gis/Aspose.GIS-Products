## Konversi Shapefile ke JPEG Menggunakan Pemirsa .NET

Panduan ini menjelaskan cara mengonversi file shapefile menjadi gambar JPEG menggunakan Pemirsa .NET.

### Prasyarat

*   Pemirsa .NET terinstal
*   File shapefile yang ingin Anda konversi

### Langkah-langkah

1.  Buka Pemirsa .NET.
2.  Klik "Berkas" > "Buka".
3.  Pilih file shapefile yang ingin Anda konversi.
4.  Klik "Eksport" > "JPEG".
5.  Tentukan nama dan lokasi untuk file JPEG yang dihasilkan.
6.  Klik "Simpan".

### Opsi Tambahan

Anda dapat menyesuaikan proses konversi dengan opsi berikut:

*   **Resolusi:** Tentukan resolusi gambar JPEG yang dihasilkan.
*   **Kualitas:** Tentukan kualitas gambar JPEG yang dihasilkan.
*   **Warna:** Pilih palet warna untuk digunakan dalam gambar JPEG yang dihasilkan.
*   **Skala:** Tentukan skala file shapefile saat dikonversi ke gambar JPEG.

### Pemecahan Masalah

Jika Anda mengalami masalah saat mengonversi file shapefile menjadi gambar JPEG, coba langkah-langkah berikut:

*   Pastikan Anda telah menginstal Pemirsa .NET.
*   Pastikan file shapefile tidak rusak.
*   Coba konversi file shapefile yang berbeda.
*   Hubungi dukungan teknis untuk bantuan lebih lanjut.

### Kesimpulan

Dengan mengikuti langkah-langkah ini, Anda dapat dengan mudah mengonversi file shapefile menjadi gambar JPEG menggunakan Pemirsa .NET. Ini memungkinkan Anda untuk berbagi data geospasial dalam format yang lebih ramah pengguna dan serbaguna.
