## Overview

NetViewer is a web application that allows users to view and interact with geospatial data. It supports various data formats, including shapefiles, GeoJSON, and raster datasets.

## Features

*   **Data Visualization:** Display geospatial data on an interactive map.
*   **Attribute Queries:** Query attribute information for selected features.
*   **Spatial Analysis:** Perform basic spatial analysis operations such as buffering and intersection.
*   **Customization:** Customize the appearance of the map and data display.
*   **Sharing:** Share maps and datasets with others.

## Supported Data Formats

*   Shapefile
*   GeoJSON
*   Raster Datasets (e.g., GeoTIFF)
*   WMS/WMTS Services

## Getting Started

1.  **Installation:** Download and install the NetViewer application.
2.  **Data Loading:** Load geospatial data into the application.
3.  **Map Configuration:** Configure the map display settings.
4.  **Interaction:** Interact with the map to view and query data.

## Usage Examples

### Displaying a Shapefile

1.  Load the shapefile into NetViewer.
2.  Configure the symbology for each layer.
3.  Zoom to the extent of the shapefile.

### Performing a Buffer Analysis

1.  Select a feature layer.
2.  Specify a buffer distance.
3.  Run the buffer analysis.
4.  View the resulting buffered features.

## Troubleshooting

*   **Data Loading Errors:** Ensure that the data format is supported and that the file paths are correct.
*   **Display Issues:** Check the symbology settings and map projection.
*   **Performance Problems:** Simplify the data or use a faster rendering engine.
