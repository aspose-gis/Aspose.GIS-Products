## Mengubah File GPX menjadi Gambar PNG

Alat ini memungkinkan Anda mengonversi file GPX (GPS Exchange Format) menjadi gambar PNG. Ini berguna untuk membuat peta kustom dari rute atau jejak GPS.

### Cara Penggunaan

1.  Unggah file GPX Anda.
2.  Pilih opsi tampilan yang diinginkan, seperti warna jalur, ketebalan garis, dan label titik.
3.  Klik tombol "Konversi" untuk menghasilkan gambar PNG.
4.  Unduh gambar PNG yang dihasilkan.

### Opsi Tampilan

*   **Warna Jalur:** Pilih warna untuk jalur GPS pada peta.
*   **Ketebalan Garis:** Sesuaikan ketebalan garis jalur GPS.
*   **Label Titik:** Tampilkan label untuk titik-titik GPS, seperti nama atau deskripsi.
*   **Skala Peta:** Ubah skala peta untuk memperbesar atau memperkecil tampilan.
*   **Orientasi Utara:** Atur orientasi utara pada peta.

### Contoh File GPX

File GPX adalah file XML yang berisi data GPS. Berikut adalah contoh sederhana dari file GPX:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<gpx version="1.1">
  <trk>
    <name>Rute Contoh</name>
    <waypoint lat="37.7749" lon="-122.4194"/>
    <waypoint lat="37.7833" lon="-122.4065"/>
  </trk>
</gpx>
```

### Catatan

*   Alat ini memerlukan koneksi internet untuk berfungsi.
*   Ukuran file GPX yang diunggah dibatasi hingga 10MB.
*   Gambar PNG yang dihasilkan memiliki resolusi maksimum 1024x768 piksel.
