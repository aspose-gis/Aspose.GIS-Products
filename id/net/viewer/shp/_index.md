## Apa itu Shapefile?
Shapefile adalah format file yang umum digunakan untuk menyimpan data geospasial. Format ini terdiri dari beberapa berkas, termasuk berkas .shp yang berisi geometri fitur, berkas .shx yang merupakan indeks untuk mempercepat pencarian, dan berkas .dbf yang berisi atribut fitur.

## Fitur Penampil Shapefile
Penampil Shapefile kami menawarkan berbagai fitur, termasuk:

*   **Tampilan Interaktif:** Zoom, pan, dan putar data shapefile Anda untuk menjelajahi data secara detail.
*   **Atribut Data:** Lihat dan edit atribut yang terkait dengan setiap fitur.
*   **Gaya:** Sesuaikan tampilan data shapefile Anda menggunakan berbagai gaya dan simbol.
*   **Kueri:** Kueri data shapefile Anda berdasarkan atribut tertentu.
*   **Dukungan untuk Berbagai Format Shapefile:** Penampil kami mendukung berbagai format shapefile, termasuk titik, garis, dan poligon.

## Cara Menggunakan Penampil Shapefile
Untuk menggunakan Penampil Shapefile, cukup seret dan lepas berkas shapefile Anda ke dalam penampil atau gunakan tombol "Pilih Berkas" untuk memilih berkas dari komputer Anda. Setelah berkas dimuat, Anda dapat mulai menjelajahi data Anda.

## Contoh Penggunaan
Penampil Shapefile dapat digunakan untuk berbagai tujuan, termasuk:

*   **Inspeksi Data:** Periksa akurasi dan kelengkapan data shapefile Anda.
*   **Analisis Data:** Lakukan analisis spasial pada data shapefile Anda.
*   **Presentasi Data:** Sajikan data shapefile Anda kepada audiens.
*   **Pendidikan:** Ajarkan siswa tentang data geospasial.
