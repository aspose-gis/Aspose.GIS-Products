## Apa itu GML?
GML (Geography Markup Language) adalah aplikasi XML yang dirancang khusus untuk merepresentasikan data geografis. Ini digunakan untuk mengkodekan fitur-fitur seperti titik, garis, poligon, dan permukaan, bersama dengan atributnya.

## Fitur Penampil GML
*   Mendukung berbagai versi GML
*   Menampilkan data GML dalam format yang mudah dibaca
*   Memungkinkan Anda untuk memperbesar dan menggeser peta
*   Memberikan informasi tentang fitur-fitur individual
*   Dapat digunakan untuk melihat data GML dari berbagai sumber

## Cara Menggunakan Penampil GML
1.  Buka Penampil GML.
2.  Muat file GML yang ingin Anda lihat.
3.  Gunakan kontrol untuk memperbesar, menggeser, dan menelusuri data.
4.  Klik pada fitur untuk melihat informasi lebih lanjut.

## Contoh Penggunaan
Penampil GML dapat digunakan untuk berbagai tujuan, termasuk:

*   Memvalidasi data GML
*   Memeriksa kesalahan dalam data GML
*   Melihat data GML sebelum mempublikasikannya ke web
*   Berbagi data GML dengan orang lain
