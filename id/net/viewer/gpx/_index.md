## What is GPX?
/* Apa itu GPX? */
GPX (GPS Exchange Format) is an XML schema for representing geographic data. It can store waypoints, routes, and tracks.
/* GPX (Format Pertukaran GPS) adalah skema XML untuk merepresentasikan data geografis. Ini dapat menyimpan titik jalan, rute, dan jejak. */

## GPX Viewer Features
/* Fitur Penampil GPX */
*   View GPX files
/* Tampilan berkas GPX */
*   Display waypoints, routes, and tracks on a map
/* Menampilkan titik jalan, rute, dan jejak pada peta */
*   Filter by track name
/* Filter berdasarkan nama jejak */
*   Zoom to selected feature
/* Perbesar ke fitur yang dipilih */
*   Download GPX files
/* Unduh berkas GPX */

## Supported GPX File Versions
/* Versi Berkas GPX yang Didukung */
The GPX Viewer supports the following versions:
/* Penampil GPX mendukung versi berikut: */
*   GPX 1.0
/* GPX 1.0 */
*   GPX 1.1

## How to Use
/* Cara Penggunaan */
1.  Upload a GPX file.
/* Unggah berkas GPX. */
2.  The waypoints, routes, and tracks will be displayed on the map.
/* Titik jalan, rute, dan jejak akan ditampilkan pada peta. */
3.  Use the controls to zoom, pan, and filter the data.
/* Gunakan kontrol untuk memperbesar, menggeser, dan memfilter data. */

## Troubleshooting
/* Pemecahan Masalah */
If you are having trouble viewing a GPX file, please make sure that it is valid XML and does not contain any errors.
/* Jika Anda mengalami masalah saat melihat berkas GPX, pastikan berkas tersebut merupakan XML yang valid dan tidak berisi kesalahan apa pun. */
