## Pengantar

Penampil berbasis web memungkinkan Anda untuk mengonversi file KML (Keyhole Markup Language) menjadi gambar JPEG. Ini berguna untuk membuat pratinjau peta atau menyertakan gambar peta dalam dokumen atau situs web.

## Persyaratan

*   Penampil berbasis web terinstal dan berfungsi
*   File KML yang valid

## Langkah-langkah

1.  Buka Penampil berbasis web.
2.  Muat file KML menggunakan tombol "Muat".
3.  Tentukan parameter konversi, seperti resolusi dan format gambar.
4.  Klik tombol "Konversi" untuk memulai proses konversi.
5.  Setelah konversi selesai, unduh gambar JPEG yang dihasilkan.

## Parameter Konversi

*   **Resolusi:** Resolusi gambar keluaran dalam piksel (misalnya, 1024x768).
*   **Format Gambar:** Format gambar keluaran (JPEG).
*   **Skala:** Skala peta saat konversi.
*   **Tampilan Pusat:** Koordinat lintang dan bujur titik tengah tampilan.

## Pemecahan Masalah

*   Jika Anda mengalami masalah dalam memuat file KML, pastikan file tersebut valid dan tidak rusak.
*   Jika gambar JPEG yang dihasilkan buram atau terdistorsi, coba sesuaikan parameter resolusi dan skala.
*   Jika Anda masih mengalami masalah, hubungi dukungan teknis untuk mendapatkan bantuan lebih lanjut.

## Catatan Tambahan

*   Penampil berbasis web mendukung berbagai format file KML, termasuk KML 2.2.
*   Anda dapat mengonversi beberapa file KML sekaligus dengan menggunakan fitur konversi batch.
*   Gambar JPEG yang dihasilkan dapat digunakan dalam berbagai aplikasi, seperti situs web, presentasi, dan laporan.
