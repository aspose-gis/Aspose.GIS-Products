# Konversi KML ke PNG

Penampil berbasis web ini memungkinkan Anda untuk mengonversi file KML menjadi gambar PNG. Ini berguna untuk membuat cuplikan layar dari data geospasial atau untuk menyertakan peta dalam dokumen atau presentasi.

## Cara Menggunakan

1.  Unggah file KML Anda.
2.  Tentukan parameter konversi, seperti lebar dan tinggi gambar.
3.  Klik tombol "Konversi".
4.  Unduh gambar PNG yang dihasilkan.

## Parameter Konversi

*   **Lebar:** Lebar gambar dalam piksel.
*   **Tinggi:** Tinggi gambar dalam piksel.
*   **Skala:** Skala peta.
*   **Pusat:** Koordinat pusat peta.

## Contoh

Untuk mengonversi file KML bernama "data.kml" menjadi gambar PNG dengan lebar 800 piksel dan tinggi 600 piksel, Anda akan menggunakan parameter berikut:

*   **File KML:** data.kml
*   **Lebar:** 800
*   **Tinggi:** 600

## Catatan

*   Ukuran file KML yang diunggah dibatasi hingga 10 MB.
*   Gambar PNG yang dihasilkan akan disimpan dalam format JPEG.
*   Penampil berbasis web ini menggunakan layanan peta Google untuk merender data KML.
