<p>
 Aspose.GIS pour .NET vous permet de convertir le système de référence géographique mondial (GeoRef) pour les unités géospatiales. Notre bibliothèque vous permet de convertir facilement et rapidement la latitude et la longitude vers un format d'unité souhaité. De plus, notre bibliothèque contient une possibilité d'extraire des emplacements à partir d'un texte en tant que point.
</p>

<p>
 Aspose.GIS pour .NET est conçu avec simplicité, performance, utilisabilité et portabilité à l'esprit. Il contient des API à utiliser avec les plateformes .NET Framework et .NET Core, vous permettant de créer des applications multiplateformes avec une grande facilité.
</p>
