Le langage de balisage géographique (connu sous le nom de GML) est un format basé sur XML utilisé dans les SIG. GML est un format d'échange ouvert pour les transactions géographiques sur Internet. Ce format est orienté données et structure.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="CSV" readMoreLink="https://docs.fileformat.com/spreadsheet/csv/" >}}

Les fichiers avec l'extension CSV (Comma Separated Values) représentent des fichiers texte simples qui contiennent des enregistrements de données avec des valeurs séparées par des virgules. Chaque ligne d'un fichier CSV est un nouvel enregistrement de l'ensemble des enregistrements contenus dans le fichier. Ces fichiers sont générés lorsque le transfert de données est destiné d'un système de stockage à un autre. Étant donné que toutes les applications peuvent reconnaître les enregistrements séparés par une virgule, l'importation de ces fichiers de données dans une base de données se fait très facilement.
