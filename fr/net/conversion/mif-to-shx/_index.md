 La conversion peut être effectuée avec une seule ligne de code lors de l'utilisation de la méthode
 *VectorLayer.Convert* 
 . Elle prend 4 paramètres comme détaillé ci-dessous.

{{% /blocks/products/pf/agp/text %}}

1.  Un chemin d'accès au fichier source MIF de type chaîne
2.  Pilote source pour informer l'API du format d'entrée. Définissez-le sur Drivers.MapInfoInterchange
3.  Le chemin d'accès au fichier de données SHX de destination de type chaîne
4.  Pilote de destination pour spécifier le format de sortie. Définissez-le sur Drivers.Shapefile
