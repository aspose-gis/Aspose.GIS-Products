OpenStreetMap (OSM) est une vaste collection d'informations géographiques volontaires stockées dans différents types de fichiers, utilisant différents schémas de codage pour convertir ces données en bits et octets. OSM est un effort collaboratif visant à la création d'une carte mondiale éditable gratuite. La sortie principale de cet effort collaboratif est constituée de données géographiques plutôt que de la carte elle-même. Les contraintes sur l'utilisation ou la disponibilité des informations géographiques dans le monde entier déclenchent le besoin de créer un OSM. Les données disponibles à partir d'OSM sont prêtes à remplacer Google Maps pour les applications classiques (Facebook, Craigslist etc.) et les données par défaut pour les applications de récepteurs GPS. Bien que la qualité des données varie considérablement dans le monde, les données OpenStreetMap peuvent être facilement comparées aux sources de données brevetées.
