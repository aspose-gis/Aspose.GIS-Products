KML (Keyhole Markup Language) contient des informations géospatiales au format XML. KML peut être ouvert dans des applications de systèmes d'information géographique (SIG) à condition qu'elles le prennent en charge. De nombreuses applications ont commencé à prendre en charge le format KML après son adoption comme norme internationale.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="CSV" readMoreLink="https://docs.fileformat.com/spreadsheet/csv/" >}}

Les fichiers avec l'extension CSV (Comma Separated Values) représentent des fichiers texte simples qui contiennent des enregistrements de données avec des valeurs séparées par des virgules. Chaque ligne d'un fichier CSV est un nouvel enregistrement de l'ensemble des enregistrements contenus dans le fichier. Ces fichiers sont générés lorsque le transfert de données entre un système de stockage et un autre est prévu. Étant donné que toutes les applications peuvent reconnaître les enregistrements séparés par une virgule, l'importation de ces fichiers de données dans une base de données se fait très facilement.
