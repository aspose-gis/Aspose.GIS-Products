GeoJSON est un format basé sur JSON conçu pour représenter les entités géographiques avec leurs attributs non spatiaux. Ce format définit différents objets JSON (JavaScript Object Notation) et leur mode de jonction. Le JSON représente une information collective sur les entités géographiques, leurs étendues spatiales et leurs propriétés.

L'extension GPX représente le format d'échange GPS pour l'interchange de données GPS entre les applications et les services web sur Internet. C'est un format XML léger qui contient des données GPS, c'est-à-dire des points de passage, des itinéraires et des pistes à importer et à lire par plusieurs programmes. GPX est ouvert et pris en charge par une variété d'applications et de dispositifs GPS.
