Shapefile est un format multi-fichiers (connu sous le nom de Shapefile ESRI). Le principal a l'extension SHP. Shapefile est un format de fichier géographique vectoriel populaire. Développé et maintenu par ESRI pour la compatibilité entre les produits Esri et d'autres programmes.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="CSV" readMoreLink="https://docs.fileformat.com/spreadsheet/csv/" >}}

Les fichiers avec l'extension CSV (Comma Separated Values) représentent des fichiers texte simples qui contiennent des enregistrements de données avec des valeurs séparées par des virgules. Chaque ligne d'un fichier CSV est un nouvel enregistrement de l'ensemble des enregistrements contenus dans le fichier. Ces fichiers sont générés lorsque le transfert de données est prévu d'un système de stockage à un autre. Étant donné que toutes les applications peuvent reconnaître les enregistrements séparés par une virgule, l'importation de ces fichiers de données dans une base de données se fait très facilement.
