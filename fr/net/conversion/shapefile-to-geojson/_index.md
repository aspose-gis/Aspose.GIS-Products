SHP est l'extension de fichier pour l'un des principaux types de fichiers utilisés pour la représentation d'ESRI Shapefile. Il représente les informations géospatiales sous forme de données vectorielles à utiliser par les applications de systèmes d'information géographique (SIG). Le format a été développé comme spécifications ouvertes afin de faciliter l'interopérabilité entre ESRI et d'autres produits logiciels.

        {{< blocks/products/pf/agp/about-file-text fileFormat="GeoJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON est un format basé sur JSON conçu pour représenter les entités géographiques avec leurs attributs non spatiaux. Ce format définit différents objets JSON (JavaScript Object Notation) et leur mode de jonction. JSON représente une information collective sur les entités géographiques, leurs étendues spatiales et leurs propriétés.
