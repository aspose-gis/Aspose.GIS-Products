GeoJSON est un format basé sur JSON conçu pour représenter les entités géographiques avec leurs attributs non spatiaux. Ce format définit différents objets JSON et leur mode de jonction. JSON représente une information collective sur les entités géographiques, leurs étendues spatiales et leurs propriétés.

        {{< blocks/products/pf/agp/about-file-text fileFormat="CSV" readMoreLink="https://docs.fileformat.com/spreadsheet/csv/" >}}

Les fichiers avec l'extension CSV (Comma Separated Values) représentent des fichiers texte simples qui contiennent des enregistrements de données avec des valeurs séparées par des virgules. Chaque ligne d'un fichier CSV est un nouvel enregistrement de l'ensemble des enregistrements contenus dans le fichier. Ces fichiers sont générés lorsqu'un transfert de données est prévu d'un système de stockage à un autre. Étant donné que toutes les applications peuvent reconnaître les enregistrements séparés par une virgule, l'importation de ces fichiers de données dans une base de données se fait très facilement.
