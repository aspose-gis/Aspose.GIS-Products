<p>
 Aspose.GIS pour .NET vous permet de créer un visualiseur MapInfo-MIF pour les formats de données géospatiales basés sur des vecteurs et des raster. Les données ne sont utiles que si quelqu'un peut les voir. La bibliothèque GIS .NET facilite et accélère l'exportation des données SIG vers des images vectorielles ou matricielles et fournit une symbolisation riche pour des scénarios de visualisation complexes. 
</p>

<p>
 Aspose.GIS pour .NET est conçu avec la simplicité, les performances, la convivialité et la portabilité à l’esprit. Il contient des API à utiliser avec les plateformes .NET Framework et .NET Core, vous permettant de créer des applications multiplateformes avec une grande facilité.
</p>
