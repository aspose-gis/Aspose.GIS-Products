<p>Aspose.GIS pour .NET vous permet d’accéder et de manipuler les informations géographiques à partir de formats de données géospatiales basés sur des vecteurs. L'API prend en charge la lecture, l'écriture et la conversion des formats de fichiers SIG les plus populaires tels que Shapefile, GeoJSON, FIleGDB, KML et OSM XML, ainsi que l’affichage d’une carte à partir de formats pris en charge au format SVG. De plus, un développeur peut facilement personnaliser le rendu et les styles de fonctionnalités pour obtenir l'apparence souhaitée de la carte.</p>

<p>Aspose.GIS pour .NET est conçu dans un souci de simplicité, de performance, d’utilisabilité et de portabilité. Il contient des API à utiliser avec les plateformes .NET Framework, .NET Core et Xamarin, vous permettant de créer facilement des applications multiplateformes.</p>

   <div class="col-lg-12">
    <h2 class="h2title">
     API unique pour différents formats
    </h2>
    <p>
     Aspose.GIS prend en charge tous les détails fastidieux des formats de données et vous fournit un modèle d’objet propre et simple pour les données SIG. Vous pouvez lire ou stocker des données dans des fichiers avec un code universel et indépendant du format.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Lire les données SIG à partir d’un Shapefile - C#
     </h3>
     <pre><code class="cs">using (var layer = VectorLayer.Open(dir + "myDataFile.shp", Drivers.Shapefile))

{

    foreach (var feature in layer)

    {

        Console.WriteLine(feature.Geometry.AsText()); // affiche la géométrie au format WKT

        Console.WriteLine(feature.GetValue&lt;string&gt;("CITY_NAME")); // affiche une valeur d’attribut

        Console.WriteLine(feature.GetValue&lt;DateTime&gt;("UPDATE_DAT")); 
    }

}</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Convertir les données SIG entre les formats
    </h2>
    <p>
     La conversion des données SIG d’un format à un autre avec Aspose.GIS prend généralement une seule ligne de code.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Convertir un Shapefile en GeoJSON - C#
     </h3>
     <pre><code class="cs">VectorLayer.Convert(dir + "example.shp", Drivers.Shapefile, dir + "output.json", Drivers.GeoJson);</code></pre>
    </div>
    <p>
     Si nécessaire, vous pouvez effectuer des opérations supplémentaires pendant les conversions telles que l’ajustement du schéma d’attributs de données ou la reprojection à la volée des géométries de fonctionnalités.
    </p>
    <p>
     Voici quelques exemples de conversions de formats pris en charge :
    </p>
    <ul>
     <li>
      Shapefile vers KML
     </li>
     <li>
      Shapefile vers File Geodatabase
     </li>
     <li>
      GeoJSON vers Shapefile
     </li>
     <li>
      KML vers File Geodatabase
     </li>
     <li>
      KML vers Shapefile
     </li>
     <li>
      KML vers GeoJSON
     </li>
     <li>
      GPX vers File Geodatabase
     </li>
     <li>
      GPX vers GeoJSON
     </li>
     <li>
      GPX vers KML
     </li>
     <li>
      GPX vers TopoJSON
     </li>
     <li>
      MapInfo Interchange vers GeoJSON
     </li>
     <li>
      MapInfo Interchange vers Shapefile
     </li>
     <li>
      MapInfo TAB vers KML
     </li>
     <li>
      OSM vers Shapefile
     </li>
     <li>
      GML vers File Geodatabase
     </li>
    </ul>
    <p>
     La conversion de fichiers SIG en formats raster est assurée par les
     <a href="https://products.aspose.com/imaging/net">
      modules Aspose.Imaging
     </a>
     d’exportation.
    </p>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Rendu de cartes
    </h2>
    <p>
     Les données ne sont utiles que si quelqu'un peut les voir. La bibliothèque SIG .NET facilite et accélère l’exportation des données SIG au format vectoriel ou raster et fournit une symbologie riche pour des scénarios de visualisation complexes.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Rendre une carte TopoJSON au format SVG - C#
     </h3>
     <pre><code class="cs">using (var map = new Map(800, 600))

{

    var layer = VectorLayer.Open(dir + "map.json", Drivers.TopoJson);

    var style = new SimpleFill { FillColor = Color.Azure, StrokeWidth = 1.5 };

    map.Add(layer, style);

    map.Render(dir + "mymap.svg", Renderers.Svg);

}</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Utiliser différents systèmes de coordonnées
    </h2>
    <p>
     Avec Aspose.GIS, vous pouvez transformer les coordonnées géospatiales, les géométries et les couches entières d’un système de référence de coordonnées à un autre. Les projections cartographiques ainsi que les transformations géodésiques sont prises en charge.
    </p>
    <p>
     Vous pouvez rechercher un système de référence de coordonnées par SRID, importer à partir de WKT ou définir des paramètres personnalisés directement dans le code.
    </p>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Effectuer une analyse spatiale

     Aspose.GIS inclut un ensemble complet de prédicats spatiaux basés sur le modèle DE-9IM qui évalue les relations topologiques entre les objets. Les cas typiques sont :
    </p>
    <ul>
     <li>
      Déterminer si deux objets se chevauchent
     </li>
     <li>
      Déterminer si un objet intersecte un autre objet
     </li>
     <li>
      Trouver la distance minimale entre une géométrie et une autre géométrie
     </li>
     <li>
      Vérifier si la géométrie d’un objet s’intersecte elle-même
     </li>
     <li>
      Calculer l’aire d’une géométrie
     </li>
    </ul>
    <p>
     Aspose.GIS vous permet d’effectuer facilement des opérations géométriques, telles que :
