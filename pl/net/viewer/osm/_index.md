## Overview

The OpenStreetMap Viewer allows you to visualize and interact with OpenStreetMap data. You can pan, zoom, and identify features on the map.

## Features

*   Pan and zoom functionality
*   Feature identification
*   Support for various tile providers
*   Customizable map styles

## Usage

1.  Open the viewer in your web browser.
2.  Use the mouse or keyboard to pan and zoom the map.
3.  Click on features to identify them.
4.  Change the tile provider or map style as needed.

## Configuration

The viewer can be configured using a JSON file. The configuration file specifies the tile provider, map style, and other options.
