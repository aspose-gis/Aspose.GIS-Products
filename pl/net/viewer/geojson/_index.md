## Introduction

The GeoJSON Viewer is a tool that allows you to view and interact with GeoJSON data directly on a map. It provides a user-friendly interface for exploring geographic features, attributes, and relationships within your GeoJSON files.

## Features

*   **Display GeoJSON Data:** Easily load and display GeoJSON data from local files or URLs.
*   **Interactive Map:** Pan, zoom, and interact with the map to explore different areas of interest.
*   **Feature Highlighting:** Highlight individual features on the map by clicking on them in the table.
*   **Attribute Inspection:** View detailed attribute information for each feature.
*   **Filtering:** Filter features based on their attributes.
*   **Styling:** Customize the appearance of GeoJSON features using various styling options.

## Usage

1.  **Load GeoJSON Data:** Click the "Load" button to select a local GeoJSON file or enter a URL for remote data.
2.  **Explore the Map:** Use the map controls to pan, zoom, and navigate around the map.
3.  **Inspect Features:** Click on features in the table or on the map to view their attributes.
4.  **Filter Data:** Use the filtering options to narrow down the displayed features based on specific attribute values.
5.  **Customize Styling:** Adjust the styling options to change the appearance of GeoJSON features, such as color, size, and opacity.

## Supported GeoJSON Formats

The GeoJSON Viewer supports a wide range of GeoJSON formats, including:

*   Feature Collections
*   Feature
*   Geometry (Point, LineString, Polygon, MultiPolygon)
*   Properties

## Troubleshooting

If you encounter any issues while using the GeoJSON Viewer, please refer to the following troubleshooting tips:

*   **Invalid GeoJSON:** Ensure that your GeoJSON file is valid and well-formed. Use a GeoJSON validator tool to check for errors.
*   **Large Files:** Loading very large GeoJSON files may take time or cause performance issues. Consider simplifying your data or using a more efficient format.
*   **Browser Compatibility:** The GeoJSON Viewer is compatible with most modern web browsers. If you encounter any compatibility issues, try updating your browser to the latest version.
