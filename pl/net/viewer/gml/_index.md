## What is GML?
Geographic Markup Language (GML) is an XML-based format for encoding geographic information. It's a standard of the Open Geospatial Consortium (OGC) and is widely used for exchanging geospatial data.

## Features
*   View GML files in a user-friendly interface.
*   Zoom and pan to explore different areas.
*   Identify features by clicking on them.
*   Display feature attributes in a table.
*   Support for various GML flavors, including Simple Feature and Motion Feature.

## Usage
1.  Open the GML Viewer application.
2.  Load a GML file using the "File" -> "Open" menu option.
3.  The GML data will be displayed on the map.
4.  Use the zoom and pan controls to navigate the map.
5.  Click on features to view their attributes.

## Supported GML Flavors
The GML Viewer supports the following GML flavors:

*   Simple Feature
*   Motion Feature
*   Other OGC-compliant GML formats
