## Overview

This viewer allows you to convert OpenStreetMap data into static PNG images. You can customize the rendering process by adjusting various parameters such as zoom level, map style, and output resolution.

## Features

*   Convert OpenStreetMap data to PNG images
*   Adjustable zoom level
*   Customizable map styles
*   Configurable output resolution
*   Easy-to-use interface

## Usage

1.  Enter the latitude and longitude coordinates of the area you want to render.
2.  Specify the desired zoom level. Higher zoom levels will result in more detailed images but may take longer to generate.
3.  Select a map style from the available options. Different styles use different color schemes and visual representations for various features.
4.  Set the output resolution (width and height) of the PNG image. Larger resolutions will produce higher-quality images but also increase file size.
5.  Click the "Generate" button to create the PNG image.

## Parameters

*   **Latitude:** The latitude coordinate of the center of the area to render.
*   **Longitude:** The longitude coordinate of the center of the area to render.
*   **Zoom Level:** The zoom level for rendering the map.  A higher value means more detail.
*   **Map Style:** The visual style to apply to the rendered map.
*   **Width:** The width of the output PNG image in pixels.
*   **Height:** The height of the output PNG image in pixels.

## Example

To generate a PNG image of London, England with a zoom level of 12 and a resolution of 800x600 pixels, you would enter the following values:

*   Latitude: 51.5074
*   Longitude: -0.1278
*   Zoom Level: 12
*   Map Style: Default
*   Width: 800
*   Height: 600
