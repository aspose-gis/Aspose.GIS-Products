## GPX to PNG Converter

This tool converts GPX files into PNG images. This allows you to easily share your GPS tracks and routes with others who may not have the software to view GPX files directly.

Ten narzędzie konwertuje pliki GPX na obrazy PNG. Pozwala to łatwo udostępniać swoje trasy i ścieżki GPS innym osobom, które mogą nie mieć oprogramowania do bezpośredniego przeglądania plików GPX.

### Features

*   Supports various GPX file formats.
*   Customizable image size and resolution.
*   Option to add a scale bar and north arrow.
*   Easy to use interface.

Obsługuje różne formaty plików GPX.
Możliwość dostosowania rozmiaru i rozdzielczości obrazu.
Opcja dodawania skali i strzałki północnej.
Łatwy w użyciu interfejs.

### How to Use

1.  Upload your GPX file.
2.  Configure the image settings (size, resolution, scale bar, north arrow).
3.  Click "Convert".
4.  Download the resulting PNG image.

1.  Prześlij swój plik GPX.
2.  Skonfiguruj ustawienia obrazu (rozmiar, rozdzielczość, skala, strzałka północna).
3.  Kliknij „Konwertuj”.
4.  Pobierz wynikowy obraz PNG.

### Example Usage

```java
// This is an example of how to use the GPX to PNG converter in Java.
// To jest przykład tego, jak użyć konwertera GPX do PNG w Javie.

GPXConverter converter = new GPXConverter();
PNGImage image = converter.convert(gpxFile, settings);
image.save("output.png");
```

### Troubleshooting

*   If the conversion fails, make sure your GPX file is valid and not corrupted.
*   If the resulting image is too small or large, adjust the image size settings.
*   If you are having trouble with the scale bar or north arrow, try different settings.

Jeśli konwersja się nie powiedzie, upewnij się, że Twój plik GPX jest prawidłowy i nieuszkodzony.
Jeśli wynikowy obraz jest zbyt mały lub duży, dostosuj ustawienia rozmiaru obrazu.
Jeśli masz problemy ze skalą lub strzałką północną, spróbuj różnych ustawień.
