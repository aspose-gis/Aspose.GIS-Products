## Konwertuj GeoJSON do SVG Online

Nasz konwerter GeoJSON do SVG pozwala łatwo przekształcić pliki GeoJSON w obrazy SVG. Po prostu wklej swój kod GeoJSON lub załaduj plik, a my zajmiemy się resztą.

### Jak to działa?

1.  **Wklej GeoJSON:** Skopiuj i wklej swój kod GeoJSON do pola tekstowego powyżej.
2.  **Załaduj plik GeoJSON:** Alternatywnie możesz załadować plik GeoJSON ze swojego komputera, klikając przycisk „Prześlij plik”.
3.  **Konwertuj:** Kliknij przycisk „Konwertuj”, aby rozpocząć proces konwersji.
4.  **Pobierz SVG:** Po zakończeniu konwersji możesz pobrać obraz SVG, klikając przycisk „Pobierz SVG”.

### Przykładowy GeoJSON

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Polygon",
        "coordinates": [[
          [ -122.86, 37.39 ],
          [ -122.86, 37.40 ],
          [ -122.85, 37.40 ],
          [ -122.85, 37.39 ],
          [ -122.86, 37.39 ]
        ]]
      },
      "properties": {
        "name": "Polygon 1"
      }
    }
  ]
}
```

### Opcje konwersji

*   **Styl:** Dostosuj wygląd swojego obrazu SVG, modyfikując opcje stylu, takie jak kolor wypełnienia, kolor obrysu i grubość obrysu.
*   **Rozdzielczość:** Wybierz rozdzielczość dla swojego obrazu SVG. Wyższa rozdzielczość da lepszą jakość, ale spowoduje większy rozmiar pliku.
*   **Skala:** Dostosuj skalę swojego obrazu SVG.

### Dlaczego konwertować GeoJSON do SVG?

*   **Wektorowa grafika:** Obrazy SVG są oparte na wektorach, co oznacza, że można je powiększać bez utraty jakości.
*   **Mały rozmiar pliku:** Pliki SVG są zwykle mniejsze niż pliki rastrowe, takie jak JPEG lub PNG.
*   **Edytowalność:** Pliki SVG są edytowalne w programach do grafiki wektorowej, takich jak Adobe Illustrator lub Inkscape.
*   **Interaktywność:** Możesz dodać interaktywność do swoich obrazów SVG za pomocą JavaScript.

### Często zadawane pytania (FAQ)

*   **Co to jest GeoJSON?** GeoJSON to format wymiany danych geograficznych. Jest to lekki format oparty na JSON, który może być używany do kodowania różnych typów cech geograficznych.
*   **Co to jest SVG?** SVG to Scalable Vector Graphics. Jest to język znaczników XML do opisywania grafiki wektorowej.
*   **Czy konwersja GeoJSON do SVG jest darmowa?** Tak, nasza usługa konwersji GeoJSON do SVG jest całkowicie darmowa.
*   **Jakie są ograniczenia rozmiaru pliku GeoJSON?** Rozmiar pliku GeoJSON nie powinien przekraczać 10 MB.
