## What is GPX?
GPX (GPS Exchange Format) is an XML schema designed for the interchange of GPS data. It's a standard format used to store waypoints, routes, and tracks.

## Viewing GPX Files with Our Viewer
Our viewer allows you to easily view and interact with GPX files directly in your browser.  You can upload GPX files to see them displayed on a map.

## Features
*   **Upload Support:** Easily upload GPX files from your computer.
*   **Map Display:** View routes, tracks, and waypoints overlaid on a map.
*   **Interactive Map:** Pan, zoom, and interact with the map to explore the data.
*   **Data Visualization:** Clear visualization of GPS data points and paths.

## How to Use
1.  **Upload GPX File:** Click the "Upload" button to select a GPX file from your computer.
2.  **View on Map:** The GPX data will be displayed on the map automatically.
3.  **Interact with Data:** Zoom, pan, and click on points to view details.

## Supported Elements
Our viewer supports the following elements within a GPX file:

*   `wpt`: Waypoint - A single point of interest.
*   `rte`: Route - A planned route between waypoints.
*   `trk`: Track - A recorded path with timestamps and potentially elevation data.
*   `name`: Name of the waypoint, route or track.
*   `desc`: Description of the waypoint, route or track.
*   `latitude`: Latitude coordinate of a point.
*   `longitude`: Longitude coordinate of a point.
*   `time`: Timestamp for a track point.
*   `ele`: Elevation data for a track point.

## Troubleshooting
*   **File Not Loading:** Ensure the file is in valid GPX format and not corrupted.
*   **Data Not Displaying:** Check that the GPX file contains supported elements (waypoints, routes, or tracks).
*   **Map Issues:** Verify your internet connection and browser compatibility.
