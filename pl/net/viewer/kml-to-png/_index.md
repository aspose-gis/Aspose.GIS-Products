## Overview
## Przegląd

This tool converts KML (Keyhole Markup Language) files into PNG image format. It allows you to visualize geographical data represented in KML as a static image.

Ten narzędzie konwertuje pliki KML (język znaczników Keyhole) do formatu obrazu PNG. Pozwala na wizualizację danych geograficznych reprezentowanych w KML jako statyczny obraz.

## Features
## Funkcje

*   **KML to PNG Conversion:** Converts KML files into PNG images. Konwertuje pliki KML na obrazy PNG.
*   **Customizable Output:** Allows customization of the output image, including size and resolution. Umożliwia dostosowanie obrazu wyjściowego, w tym rozmiaru i rozdzielczości.
*   **Geographic Data Visualization:** Provides a way to visualize geographic data from KML files. Zapewnia sposób wizualizacji danych geograficznych z plików KML.
*   **Easy to Use:** Simple and intuitive interface for easy conversion. Prosty i intuicyjny interfejs dla łatwej konwersji.

## Usage
## Użycie

1.  **Input KML File:** Provide the path to the KML file you want to convert. Podaj ścieżkę do pliku KML, który chcesz przekonwertować.
2.  **Output PNG File:** Specify the desired output PNG file name and location. Określ żądany nazwa i lokalizacja pliku wyjściowego PNG.
3.  **Conversion Settings:** Adjust conversion settings such as image size, resolution, and map style (if applicable). Dostosuj ustawienia konwersji, takie jak rozmiar obrazu, rozdzielczość i styl mapy (jeśli dotyczy).
4.  **Convert:** Click the "Convert" button to start the conversion process. Kliknij przycisk „Konwertuj”, aby rozpocząć proces konwersji.

## Example
## Przykład

```java
// This is an example of how to use the KML to PNG converter in Java.
// To jest przykład, jak używać konwertera KML na PNG w Javie.

KmlToPngConverter converter = new KmlToPngConverter();
converter.setInputFile("path/to/your/kmlfile.kml");
converter.setOutputFile("path/to/output/image.png");
converter.setSize(640, 480);
converter.convert();
```

## Troubleshooting
## Rozwiązywanie problemów

*   **Invalid KML File:** Ensure the input file is a valid KML file. Upewnij się, że plik wejściowy jest prawidłowym plikiem KML.
*   **Output File Error:** Check if you have write permissions to the specified output location. Sprawdź, czy masz uprawnienia do zapisu w określonej lokalizacji wyjściowej.
*   **Conversion Errors:** Review any error messages for specific details about the conversion failure. Przejrzyj wszelkie komunikaty o błędach, aby uzyskać szczegółowe informacje na temat niepowodzenia konwersji.
