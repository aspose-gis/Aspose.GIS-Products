## Converting GeoTIFF to PNG

This guide explains how to convert a GeoTIFF file to a PNG image using our NetViewer.  The process is straightforward and requires no special software beyond the viewer itself.

### Understanding GeoTIFF and PNG

*   **GeoTIFF:** A TIFF file format that incorporates georeferencing information, allowing it to be associated with specific locations on Earth.
*   **PNG:** A raster graphics file format that supports lossless data compression.  It's widely used for images that require high quality and sharp details.

### Conversion Steps

1.  **Load the GeoTIFF:** Open the NetViewer and load your GeoTIFF file using the "Open File" button or by dragging and dropping it into the viewer window.
2.  **Adjust Display Settings (Optional):** You can adjust the display settings, such as contrast, brightness, and color balance, to optimize the image for conversion.
3.  **Export as PNG:** Click the "Export" button and select "PNG" from the available export formats.
4.  **Save the PNG:** Choose a location on your computer and save the converted PNG file.

### Troubleshooting

*   **Image Quality:** If the resulting PNG image appears blurry or pixelated, try adjusting the zoom level before exporting.
*   **File Size:** GeoTIFF files can be large. The resulting PNG file will also be relatively large, especially if you export at a high resolution. Consider reducing the resolution before exporting if file size is a concern.
*   **Georeferencing Information:**  The georeferencing information from the GeoTIFF is *not* preserved in the PNG format. The PNG will simply be a raster image.
