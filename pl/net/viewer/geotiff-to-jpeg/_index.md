## Converting GeoTIFF to JPEG

This guide explains how to convert GeoTIFF files to JPEG format using our NetViewer.  The process is straightforward and allows you to easily generate JPEGs from your geospatial data.

### Prerequisites

*   A supported browser (Chrome, Firefox, Safari, or Edge).
*   A GeoTIFF file that you want to convert.

### Steps

1.  **Open NetViewer:** Launch the NetViewer application in your web browser.
2.  **Load GeoTIFF:** Use the "Open" button to load your GeoTIFF file into the viewer. Supported formats include: `.tif`, `.tiff`.
3.  **Adjust Parameters (Optional):** You can adjust parameters like zoom level, contrast, and brightness before conversion. These adjustments will be reflected in the resulting JPEG.
4.  **Export as JPEG:** Click the "Export" button and select "JPEG" from the available options.
5.  **Save JPEG:** Choose a location on your computer to save the converted JPEG file.

### Parameters

*   **Zoom Level:** Controls the magnification of the GeoTIFF image.
*   **Contrast:** Adjusts the difference between light and dark areas in the image.
*   **Brightness:** Alters the overall lightness or darkness of the image.

### Troubleshooting

*   **File Not Supported:** Ensure that the file is a valid GeoTIFF file with a supported extension (`.tif` or `.tiff`).
*   **Conversion Errors:** If you encounter errors during conversion, try reducing the size of the GeoTIFF file or adjusting your browser settings.
*   **Image Quality:** The quality of the resulting JPEG depends on the original GeoTIFF data and any adjustments made before export.

### Additional Information

For more detailed information about NetViewer features and functionality, please refer to the complete documentation.
