<p>
 Aspose.GIS for .NET umożliwia konwersję Stopni Minut Sekund (DMS) dla jednostek geograficznych. Nasza biblioteka pozwala łatwo i szybko przekształcać współrzędne szerokości i długości do pożądanego formatu jednostek. Ponadto nasza biblioteka zawiera możliwość wyodrębniania lokalizacji do punktu z tekstu.
</p>

<p>
 Aspose.GIS for .NET został zaprojektowany z myślą o prostocie, wydajności, użyteczności i przenośności. Zawiera API do wykorzystania z platformami .NET Framework i .NET Core, umożliwiając budowanie aplikacji międzyplatformowych z dużą łatwością.
</p>
