        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON to format oparty na JSON, zaprojektowany do reprezentowania cech geograficznych wraz z ich atrybutami nielokalizacyjnymi. Ten format definiuje różne obiekty JSON (Notacja Obiektowa JavaScript) i sposób ich łączenia. Format JSON reprezentuje zbiorcze informacje o cechach geograficznych, ich zasięgu przestrzennym oraz właściwościach. Obiekt tego pliku może wskazywać geometrię (Punkt, LiniaString, Wielokąt), cechę lub zbiór cech. Cechy odzwierciedlają adresy i miejsca jako punkty, ulice, główne drogi i granice jako linie oraz kraje, prowincje i regiony lądowe jako wielokąty. Korzystając z GeoJSON, różne aplikacje routingu i nawigacji mobilnych mogą wskazywać zasięg swoich usług. Rozszerzeniem GeoJSON jest TopoJSON, które ma mniejszy rozmiar i koduje topologię przestrzenną.

JSON (JavaScript Object Notation) to otwarty standardowy format pliku do udostępniania danych, który wykorzystuje czytelny dla człowieka tekst do przechowywania i przesyłania danych. Pliki JSON są przechowywane z rozszerzeniem .json. JSON wymaga mniej formatowania i jest dobrą alternatywą dla XML. JSON pochodzi z JavaScriptu, ale jest formatem danych niezależnym od języka.
