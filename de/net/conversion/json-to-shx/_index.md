JSON (JavaScript Object Notation) ist ein offener Standard für Dateiformate zum Teilen von Daten, der einen für Menschen lesbaren Text verwendet, um Daten zu speichern und zu übertragen. JSON-Dateien werden mit der Erweiterung .json gespeichert. JSON erfordert weniger Formatierung und ist eine gute Alternative zu XML. JSON leitet sich von JavaScript ab, ist aber ein sprachunabhängiges Datenformat. Die Generierung und Analyse von JSON wird von vielen modernen Programmiersprachen unterstützt. application/json ist der Medientyp für JSON.
