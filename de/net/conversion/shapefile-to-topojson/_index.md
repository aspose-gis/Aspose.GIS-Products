SHP ist die Dateierweiterung für einen der Hauptdateitypen, die zur Darstellung von ESRI Shapefiles verwendet werden. Es stellt Geodaten in Form von Vektordaten dar, die von Geographic Information Systems (GIS)-Anwendungen verwendet werden. Das Format wurde als offene Spezifikationen entwickelt, um die Interoperabilität zwischen ESRI und anderen Softwareprodukten zu erleichtern.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="TopoJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

TopoJSON ist eine GeoJSON-Erweiterung, die Topologie kodiert. JSON-basierte Format, das entwickelt wurde, um geografische Merkmale mit ihren nichträumlichen Attributen darzustellen. Dieses Format definiert verschiedene JSON (JavaScript Object Notation)-Objekte und ihre Verknüpfungsweise. Das JSON-Format stellt kollektive Informationen über die geografischen Merkmale, ihre räumliche Ausdehnung und Eigenschaften dar.
