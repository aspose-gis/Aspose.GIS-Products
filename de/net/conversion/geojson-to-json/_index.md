        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON ist ein JSON-basiertes Format, das entwickelt wurde, um die geografischen Merkmale mit ihren nichträumlichen Attributen darzustellen. Dieses Format definiert verschiedene JSON (JavaScript Object Notation)-Objekte und ihre Verknüpfungsweise. Das JSON-Format stellt eine kollektive Information über die Geografischen Merkmale, ihre räumliche Ausdehnung und Eigenschaften dar. Ein Objekt dieser Datei kann eine Geometrie (Punkt, LinieString, Polygon), ein Feature oder eine Sammlung von Features angeben. Die Features spiegeln Adressen und Orte als Punkte, Straßen und Hauptverkehrswege als Linienstrings und Länder, Provinzen und Landregionen als Polygone wider. Mithilfe von GeoJSON können verschiedene mobile Routing- und Navigationsanwendungen die Abdeckung ihrer Dienste anzeigen. Eine Erweiterung von GeoJSON ist TopoJSON, die kleiner ist und die räumliche Topologie kodiert.

JSON (JavaScript Object Notation) ist ein offener Standard für Dateiformate zum Teilen von Daten, der einen für Menschen lesbaren Text verwendet, um Daten zu speichern und zu übertragen. JSON-Dateien werden mit der Erweiterung .json gespeichert. JSON erfordert weniger Formatierung und ist eine gute Alternative zu XML. JSON leitet sich von JavaScript ab, ist aber ein sprachunabhängiges Datenformat. Die Generierung und Analyse von JSON wird von vielen modernen Programmiersprachen unterstützt. application/json ist der Medientyp, der für JSON verwendet wird.
