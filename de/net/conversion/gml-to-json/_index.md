Geographic Markup Language (bekannt als GML) ist ein XML-basiertes Format, das in GIS verwendet wird. GML ist ein offenes Austauschformat für geografische Transaktionen im Internet. Dieses Format ist daten- und strukturorientiert.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="JSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

JSON-basiertes Format, das entwickelt wurde, um die geografischen Merkmale mit ihren nichträumlichen Attributen darzustellen. Dieses Format definiert verschiedene JSON (JavaScript Object Notation)-Objekte und ihre Verknüpfungsweise. JSON repräsentiert kollektive Informationen über die Geografischen Merkmale, ihre räumliche Ausdehnung und Eigenschaften.
