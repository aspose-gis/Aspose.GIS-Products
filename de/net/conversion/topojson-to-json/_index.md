JSON (JavaScript Object Notation) ist ein offenes Standarddateiformat zum Teilen von Daten, das lesbaren Text verwendet, um Daten zu speichern und zu übertragen. JSON-Dateien werden mit der Erweiterung .json gespeichert. JSON erfordert weniger Formatierung und ist eine gute Alternative für XML. JSON leitet sich von JavaScript ab, ist aber ein sprachunabhängiges Datenformat. Die Generierung und Analyse von JSON wird von vielen modernen Programmiersprachen unterstützt. application/json ist der Medientyp, der für JSON verwendet wird.
