<p>Aspose.GIS für .NET ermöglicht Ihnen den Zugriff auf und die Manipulation geografischer Informationen aus vektorbasierten Geoinformationsdatenformaten. Die API unterstützt das Lesen, Schreiben und Konvertieren der beliebtesten GIS-Dateiformate wie Shapefile, GeoJSON, FIleGDB, KML und OSM XML sowie das Rendern einer Karte aus unterstützten Formaten in SVG. Darüber hinaus kann ein Entwickler problemlos Rendering und Feature-Stile anpassen, um das gewünschte Kartenbild zu erhalten.</p>

<p>Aspose.GIS für .NET wurde mit Blick auf Einfachheit, Leistung, Benutzerfreundlichkeit und Portabilität entwickelt. Es enthält APIs zur Verwendung mit .NET Framework, .NET Core und Xamarin-Plattformen, sodass Sie problemlos plattformübergreifende Anwendungen erstellen können.</p>

   <div class="col-lg-12">
    <h2 class="h2title">
     Ein einzelnes API für verschiedene Formate
    </h2>
    <p>
     Aspose.GIS kümmert sich um alle mühsamen Details von Datenformaten und bietet Ihnen ein sauberes und einfaches Objektmodell für GIS-Daten. Sie können Daten in Dateien mit einem universellen, formatunabhängigen Code lesen oder speichern.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Lesen von GIS-Daten aus einer Shapefile - C#
     </h3>
     <pre><code class="cs">using (var layer = VectorLayer.Open(dir + "myDataFile.shp", Drivers.Shapefile))

{

    foreach (var feature in layer)

    {

        Console.WriteLine(feature.Geometry.AsText()); // print the geometry as WKT

        Console.WriteLine(feature.GetValue&lt;string&gt;("CITY_NAME")); // print an attribute value

        Console.WriteLine(feature.GetValue&lt;DateTime&gt;("UPDATE_DAT")); 
    }

}</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Konvertieren von GIS-Daten zwischen Formaten
    </h2>
    <p>
     Die Konvertierung von GIS-Daten in ein anderes Format mit Aspose.GIS dauert normalerweise nur eine Codezeile.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Konvertieren einer Shapefile in GeoJSON - C#
     </h3>
     <pre><code class="cs">VectorLayer.Convert(dir + "example.shp", Drivers.Shapefile, dir + "output.json", Drivers.GeoJson);</code></pre>
    </div>
    <p>
     Wenn nötig, können Sie während der Konvertierungen zusätzliche Operationen durchführen, z. B. das Anpassen des Datenattributschemas oder die On-the-Fly-Reprojektion von Feature-Geometrien.
    </p>
    <p>
     Einige Beispiele für unterstützte Formatkonvertierungen:
    </p>
    <ul>
     <li>
      Shapefile zu KML
     </li>
     <li>
      Shapefile zu File Geodatabase
     </li>
     <li>
      GeoJSON zu Shapefile
     </li>
     <li>
      KML zu File Geodatabase
     </li>
     <li>
      KML zu Shapefile
     </li>
     <li>
      KML zu GeoJSON
     </li>
     <li>
      GPX zu File Geodatabase
     </li>
     <li>
      GPX zu GeoJSON
     </li>
     <li>
      GPX zu KML
     </li>
     <li>
      GPX zu TopoJSON
     </li>
     <li>
      MapInfo Interchange zu GeoJSON
     </li>
     <li>
      MapInfo Interchange zu Shapefile
     </li>
     <li>
      MapInfo TAB zu KML
     </li>
     <li>
      OSM zu Shapefile
     </li>
     <li>
      GML zu File Geodatabase
     </li>
    </ul>
    <p>
     Die Konvertierung von GIS-Dateien in Rasterbildformate wird durch die
     <a href="https://products.aspose.com/imaging/net">
      Aspose.Imaging
     </a>
     Exportmodule unterstützt.
    </p>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Karten rendern
    </h2>
    <p>
     Daten sind nur dann nützlich, wenn jemand sie sehen kann. Die .NET GIS Bibliothek macht es einfach und schnell, GIS-Daten in Vektor- oder Rasterbilder zu exportieren und bietet eine umfangreiche Symbolisierung für komplexe Visualisierungsszenarien.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Rendern einer TopoJSON-Karte in SVG - C#
     </h3>
     <pre><code class="cs">using (var map = new Map(800, 600))

{

    var layer = VectorLayer.Open(dir + "map.json", Drivers.TopoJson);

    var style = new SimpleFill { FillColor = Color.Azure, StrokeWidth = 1.5 };

    map.Add(layer, style);

    map.Render(dir + "mymap.svg", Renderers.Svg);

}</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Verwenden verschiedener Koordinatensysteme
    </h2>
    <p>
     Mit Aspose.GIS können Sie geografische Koordinaten, Geometrien und ganze Ebenen von einem Koordinatensystem in ein anderes transformieren. Kartographische Projektionen sowie geodätische Transformationen werden unterstützt.
    </p>
    <p>
     Sie können entweder ein Koordinatensystem anhand der SRID suchen, es aus WKT importieren oder Parameter direkt im Code festlegen.
    </p>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Führen Sie eine räumliche Analyse durch
    </h2>
    <p>
     Aspose.GIS enthält einen vollständigen Satz von räumlichen Prädikaten, die auf dem DE-9IM-Modell basieren und topologische Beziehungen zwischen Objekten bewerten. Typische Fälle sind:
    </p>
    <ul>
     <li>
      Bestimmen Sie, ob zwei Objekte sich überschneiden
     </li>
     <li>
      Bestimmen Sie, ob ein Objekt ein anderes Objekt schneidet
     </li>
     <li>
      Finden Sie den minimalen Abstand zwischen einer Geometrie und einer anderen Geometrie
     </li>
     <li>
      Überprüfen Sie, ob die Geometrie eines Objekts sich selbst schneidet
     </li>
     <li>
      Berechnen Sie die Fläche einer Geometrie
     </li>
    </ul>
    <p>
     Mit Aspose.GIS können Sie problemlos geometrische Operationen durchführen, wie z. B.:
    </p>
    <ul>
     <li>
      Erstellen Sie ein Pufferpolygon um eine Geometrie
     </li>
     <li>
      Finden Sie den Schwerpunkt einer Geometrie
     </li>
     <li>
      Finden Sie die konvexe Hülle einer Geometrie
     </li>
     <li>
      Berechnen Sie die Begrenzungsumgebung
     </li>
     <li>
      Linearisieren Sie eine Kurve
     </li>
    </ul>
