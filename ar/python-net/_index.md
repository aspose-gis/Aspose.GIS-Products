with VectorLayer.open(input, Drivers.shapefile) as layer:

    <h2 class="h2title">دعم تنسيقات قواعد البيانات</h2>
       <p>
     يدعم Aspose.GIS تنسيقات GIS القائمة على قواعد البيانات. اتصالات Post GIS و SQL Server (MS SQL) مدعومة لمعالجة بيانات نظم المعلومات الجغرافية. بالإضافة إلى ذلك، يدعم Aspose.GIS تنسيق GeoPackage. يرجى ملاحظة أن Aspose.GIS لـ Python قد يكون لديه بعض القيود في العمل مع DB ، يرجى التحقق أولاً مما إذا كان إصدار Python يناسب احتياجاتك.
    </p>
