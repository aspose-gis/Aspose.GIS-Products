    <h2 class="h2title">
     واجهة برمجة تطبيقات واحدة للعديد من التنسيقات
    </h2>
    <p>
     تعتني Aspose.GIS بجميع التفاصيل الدقيقة لتنسيقات البيانات وتوفر لك نموذجًا نظيفًا وبسيطًا لبيانات نظم المعلومات الجغرافية. يمكنك قراءة أو تخزين البيانات في الملفات باستخدام رمز عالمي ومستقل عن التنسيق.
    </p>
    <div class="codeblock" id="code">
     <h3>
      قراءة بيانات نظم المعلومات الجغرافية من ملف Shapefile - C#
     </h3>
     <pre><code class="cs">using (var layer = VectorLayer.Open(dir + "myDataFile.shp", Drivers.Shapefile))

{

    foreach (var feature in layer)

    {

        Console.WriteLine(feature.Geometry.AsText()); // طباعة الهندسة كـ WKT
        Console.WriteLine(feature.GetValue&lt;string&gt;("CITY_NAME")); // طباعة قيمة السمة
        Console.WriteLine(feature.GetValue&lt;DateTime&gt;("UPDATE_DAT")); 

    }

}</code></pre>
    </div>

     عرض الخرائط
    </h2>
    <p>

    </p>
    <div class="codeblock" id="code">
     <h3>
      عرض خريطة TopoJSON إلى SVG - C#
     </h3>
     <pre><code class="cs">using (var map = new Map(800, 600))

{

    var layer = VectorLayer.Open(dir + "map.json", Drivers.TopoJson);

    var style = new SimpleFill { FillColor = Color.Azure, StrokeWidth = 1.5 };

    map.Add(layer, style);

    map.Render(dir + "mymap.svg", Renderers.Svg);

}</code></pre>

    </p>
    <ul>
