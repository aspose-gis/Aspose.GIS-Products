## MapInfo Tab

The MapInfo tab provides access to MapInfo specific functionality within the viewer.

### Toolbar

The toolbar contains the following buttons:

*   **Identify:** Identifies features at the current cursor location.
*   **Select:** Selects features based on a defined criteria.
*   **Query:** Queries feature attributes.
*   **Zoom to Selection:** Zooms to the extent of selected features.
*   **Measure:** Measures distance and area.

### Properties Panel

The properties panel displays information about the currently selected feature.  It includes:

*   Shape type
*   Coordinates
*   Attribute values

### Table View

The table view displays all features in the current layer. It allows you to:

*   Sort data by column
*   Filter data based on criteria
*   Edit attribute values (if enabled)

### Context Menu

Right-clicking on a feature opens a context menu with the following options:

*   **Identify:** Identifies the feature.
*   **Select:** Selects the feature.
*   **Query:** Queries the feature's attributes.
*   **Zoom to:** Zooms to the extent of the feature.
*   **Edit:** Edits the feature (if enabled).

### התאמות אישיות

The MapInfo tab can be customized through the settings panel.  You can adjust:

*   Toolbar button visibility
*   Default measurement units
*   Attribute editing permissions
