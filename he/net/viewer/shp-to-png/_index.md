## SHP to PNG Viewer

This application allows you to convert shapefiles (.shp) into Portable Network Graphics (.png) images. It provides a simple and user-friendly interface for visualizing and exporting geospatial data.

### Features

*   **Shapefile Input:** Supports standard shapefile format.
*   **PNG Output:** Generates high-quality PNG images.
*   **Customization Options:** Allows users to adjust rendering parameters such as color scheme, background color, and resolution.
*   **User-Friendly Interface:** Easy to use for both novice and experienced users.

### Usage

1.  **Load Shapefile:** Select a shapefile (.shp) from your computer using the "Browse" button.
2.  **Configure Rendering Options:** Adjust the rendering parameters as desired.
3.  **Generate PNG:** Click the "Generate PNG" button to create the image.
4.  **Save Image:** Save the generated PNG file to your desired location.

### Requirements

*   **Operating System:** Windows, macOS, Linux
*   **Dependencies:** GDAL, Python 3

### Installation

1.  **Install Dependencies:** Ensure that GDAL and Python 3 are installed on your system.
2.  **Download Application:** Download the SHP to PNG Viewer application from the provided link.
3.  **Run Application:** Execute the downloaded file to launch the application.

### Troubleshooting

*   **Shapefile Not Found:** Verify that the shapefile exists in the specified location and that the path is correct.
*   **Rendering Errors:** Check the rendering parameters and ensure they are valid.
*   **Output Image Issues:** Try adjusting the resolution or color scheme to improve image quality.
