<p>
 Aspose.GIS for .NET מאפשר לכם ליצור צופה GeoTIFF עבור פורמטים של נתוני גיאוגרפיים וקטוריים וראסטריים. הנתונים שימושיים רק כאשר מישהו יכול לראות אותם. ספריית GIS .NET מקלה ומזרזת את היצוא של נתוני GIS לתמונות וקטוריות או ראסטריות ומספקת סמלים עשירים עבור תרחישי הדמיה מורכבים. 
</p>

<p>
 Aspose.GIS for .NET תוכנן תוך מחשבה על פשטות, ביצועים, שימושיות וניידות. הוא מכיל ממשקי API לשימוש עם פלטפורמות .NET Framework &amp; .NET Core, ומאפשר לכם לבנות יישומים חוצי-פלטפורמה בקלות רבה.
</p>
