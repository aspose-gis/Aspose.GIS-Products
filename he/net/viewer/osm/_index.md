## Overview ##

The OpenStreetMap Viewer allows you to view and interact with OpenStreetMap data directly within the application. You can pan, zoom, identify features, and perform various spatial analysis tasks.

## Features ##

*   **Interactive Map:** Pan, zoom, and explore the map using mouse or keyboard controls.
*   **Feature Identification:** Click on features to display their attributes in a pop-up window.
*   **Spatial Analysis:** Perform basic spatial queries and calculations.
*   **Customizable Layers:** Add and remove layers based on your needs.
*   **Data Download:** Export data in various formats for further analysis.

## Usage ##

1.  **Access the Viewer:** Navigate to the OpenStreetMap Viewer module within the application.
2.  **Explore the Map:** Use the pan and zoom controls to explore different areas of the map.
3.  **Identify Features:** Click on features to view their attributes.
4.  **Perform Analysis:** Utilize the spatial analysis tools to gain insights from the data.

## Configuration ##

The OpenStreetMap Viewer can be configured through a variety of settings:

*   **Base Map Style:** Choose from different base map styles (e.g., Standard, Satellite, Terrain).
*   **Layer Visibility:** Control the visibility of individual layers.
*   **Data Sources:** Configure data sources for custom layers.
