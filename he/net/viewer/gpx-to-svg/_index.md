## Convert GPX to SVG

This tool converts GPX files into SVG format.  You can use it to visualize GPS tracks and routes in a vector graphics format, which is ideal for web applications and custom mapping projects.

### How to Use

1.  **Upload your GPX file:** Drag and drop or select a GPX file from your computer.
2.  **Adjust settings (optional):** Customize the appearance of the SVG output by modifying parameters like line width, color, and font size.
3.  **Generate SVG:** Click the "Convert" button to generate the SVG file.
4.  **Download SVG:** Download the generated SVG file for use in your projects.
