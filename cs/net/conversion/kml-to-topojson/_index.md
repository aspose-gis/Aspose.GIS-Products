KML (Keyhole Markup Language) obsahuje geografické informace v XML notaci. KML lze otevřít v aplikacích Geographic Information System (GIS), pokud jej podporují. Mnoho aplikací začalo podporovat formát KML poté, co byl přijat jako mezinárodní standard.

        {{< blocks/products/pf/agp/about-file-text fileFormat="TopoJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

TopoJSON je rozšíření GeoJSON, které kóduje topologii. Formát založený na JSON navržený tak, aby reprezentoval geografické prvky s jejich nestrannými atributy. Tento formát definuje různé objekty JSON (JavaScript Object Notation) a způsob jejich spojování. Formát JSON představuje kolektivní informace o geografických prvcích, jejich prostorových rozměrech a vlastnostech.
