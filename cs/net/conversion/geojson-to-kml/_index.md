GeoJSON je formát založený na JSON, který je navržen tak, aby reprezentoval geografické objekty s jejich nestrannými atributy. Tento formát definuje různé objekty JSON (JavaScript Object Notation) a způsob jejich spojování. JSON představuje kolektivní informace o geografických objektech, jejich prostorových rozměrech a vlastnostech.
