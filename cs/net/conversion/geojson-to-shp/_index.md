GeoJSON je formát založený na JSON, který má za úkol reprezentovat geografické objekty s jejich nespočetnými atributy. Tento formát definuje různé JSON (JavaScript Object Notation) objekty a způsob jejich spojování. JSON představuje kolektivní informace o geografických objektech, jejich prostorových rozměrech a vlastnostech.
