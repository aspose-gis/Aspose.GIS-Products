        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON je formát založený na JSON, který má za cíl reprezentovat geografické prvky s jejich nestrannými atributy. Tento formát definuje různé objekty JSON a způsob jejich spojování. Formát JSON představuje kolektivní informace o geografických prvcích, jejich prostorových rozsahech a vlastnostech. Objekt tohoto souboru může označovat geometrii (bod, LineString, Polygon), funkci nebo kolekci funkcí. Funkce odrážejí adresy a místa jako body, ulice, hlavní silnice a hranice jako řetězce a země, provincie a pozemní oblasti jako polygony. Pomocí GeoJSON mohou různé mobilní aplikace pro směrování a navigaci označovat pokrytí jejich služeb. Rozšířením GeoJSON je TopoJSON, který má menší velikost a kóduje prostorovou topologii.

        {{< blocks/products/pf/agp/about-file-text fileFormat="JSON" readMoreLink="https://docs.fileformat.com/web/json/" >}}

JSON (JavaScript Object Notation) je otevřený standardní formát souborů pro sdílení dat, který používá text srozumitelný člověku k ukládání a přenosu dat. JSON soubory jsou uloženy s příponou .json. JSON vyžaduje méně formátování a je dobrou alternativou k XML. JSON je odvozen z JavaScriptu, ale jedná se o jazykově nezávislý formát dat. Generování a parsování JSON podporuje mnoho moderních programovacích jazyků. application/json je typ média používaný pro JSON.
