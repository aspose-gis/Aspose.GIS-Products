        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON je formát založený na JSON, který má za úkol reprezentovat geografické objekty s jejich nespočetnými atributy. Tento formát definuje různé JSON (JavaScript Object Notation) objekty a způsob jejich spojování. Formát JSON představuje kolektivní informace o geografických objektech, jejich prostorových rozměrech a vlastnostech. Objekt tohoto souboru může označovat geometrii (Bod, LineString, Polygon), prvek nebo kolekci prvků. Prvky odrážejí adresy a místa jako body, ulice, hlavní silnice a hranice jako řetězce a země, provincie a pozemní oblasti jako polygony. Pomocí GeoJSON mohou různé aplikace pro mobilní navigaci a směrování označovat pokrytí jejich služeb. Rozšířením GeoJSON je TopoJSON, které je menší velikostí a kóduje prostorovou topologii.
