Geographic Markup Language (známý jako GML) je formát založený na XML používaný v GIS. GML je otevřený výměnný formát pro geografické transakce na internetu. Tento formát je orientován na data a strukturu.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="GeoJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON je formát založený na JSON, který má za cíl reprezentovat geografické prvky s jejich nestrannými atributy. Tento formát definuje různé objekty JSON (JavaScript Object Notation) a způsob jejich spojování. JSON představuje kolektivní informace o geografických prvcích, jejich prostorových rozsahech a vlastnostech.
