<p>Aspose.GIS pro .NET umožňuje přistupovat a manipulovat s geografickými informacemi z formátů geoprostorových dat založených na vektorech. API podporuje čtení, zápis a převod většiny oblíbených formátů souborů GIS, jako jsou Shapefile, GeoJSON, FIleGDB, KML a OSM XML, stejně tak vykreslení mapy z podporovaných formátů do SVG. Vývojář si navíc může snadno přizpůsobit vykreslování a styly prvků, aby dosáhl požadovaného vzhledu mapy.</p>

<p>Aspose.GIS pro .NET je navrženo s ohledem na jednoduchost, výkon, použitelnost a přenositelnost. Obsahuje API pro použití s .NET Framework, .NET Core a platformami Xamarin, což vám umožňuje vytvářet aplikace pro více platforem s velkou snadností.</p>

   <div class="col-lg-12">
    <h2 class="h2title">
     Jediné API pro různé formáty
    </h2>
    <p>
     Aspose.GIS se postará o všechny únavné detaily formátů dat a poskytne vám čistý a jednoduchý objektový model pro data GIS. Můžete číst nebo ukládat data do souborů s univerzálním kódem nezávislým na formátu.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Čtení dat GIS ze Shapefile - C#
     </h3>
     <pre><code class="cs">using (var layer = VectorLayer.Open(dir + "myDataFile.shp", Drivers.Shapefile))

{

    foreach (var feature in layer)

    {

        Console.WriteLine(feature.Geometry.AsText()); // print the geometry as WKT

        Console.WriteLine(feature.GetValue&lt;string&gt;("CITY_NAME")); // print an attribute value

        Console.WriteLine(feature.GetValue&lt;DateTime&gt;("UPDATE_DAT")); 
    }

}</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Převod dat GIS mezi formáty
    </h2>
    <p>
     Převod dat GIS z jednoho formátu do druhého s Aspose.GIS obvykle trvá pouze jeden řádek kódu.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Převedení Shapefile na GeoJSON - C#
     </h3>
     <pre><code class="cs">VectorLayer.Convert(dir + "example.shp", Drivers.Shapefile, dir + "output.json", Drivers.GeoJson);</code></pre>
    </div>
    <p>
     Pokud je to nutné, můžete během převodů provádět další operace, jako je úprava schématu atributů dat nebo on-line reprojekce geometrií prvků.
    </p>
    <p>
     Některé příklady podporovaných konverzí formátů:
    </p>

     </li>

    </p>

   <div class="col-lg-12">
    <h2 class="h2title">
     Vykreslování map
    </h2>
    <p>
     Data jsou užitečná pouze tehdy, když je může někdo vidět. .NET GIS knihovna usnadňuje a urychluje export dat GIS do vektorových nebo rastrových obrázků a poskytuje bohatou symboliku pro složité vizualizační scénáře.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Vykreslení mapy TopoJSON do SVG - C#
     </h3>
     <pre><code class="cs">using (var map = new Map(800, 600))

{

    var layer = VectorLayer.Open(dir + "map.json", Drivers.TopoJson);

    var style = new SimpleFill { FillColor = Color.Azure, StrokeWidth = 1.5 };

    map.Add(layer, style);

    map.Render(dir + "mymap.svg", Renderers.Svg);

}</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Použití různých souřadnicových systémů
    </h2>
    <p>
     S Aspose.GIS můžete transformovat geoprostorové souřadnice, geometrie a celé vrstvy z jednoho referenčního systému souřadnic do druhého. Jsou podporovány kartografické projekce i geodetické transformace.
    </p>
    <p>
     Můžete buď vyhledat referenční systém souřadnic podle SRID, importovat ho z WKT nebo přímo v kódu nastavit vlastní parametry.
    </p>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Provádění prostorové analýzy
    </h2>
    <p>
