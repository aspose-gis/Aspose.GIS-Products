<p>
 Aspose.GIS for .NET umožňuje převést OSM do PNG pro vektorová a rastrová geoprostrorová data. Data jsou užitečná pouze tehdy, když je někdo může vidět. Knihovna GIS pro .NET usnadňuje a urychluje export dat GIS do vektorových nebo rastrových obrázků a poskytuje bohatou symboliku pro složité scénáře vizualizace. 
</p>

<p>
 Aspose.GIS for .NET je navrženo s ohledem na jednoduchost, výkon, použitelnost a přenositelnost. Obsahuje API pro použití s platformami .NET Framework &amp; .NET Core, což vám umožňuje vytvářet multiplatformní aplikace s velkou snadností.
</p>
