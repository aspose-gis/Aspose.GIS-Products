<p>
 Aspose.GIS for .NET umožňuje vytvářet prohlížeč MapInfo-MIF pro formáty vektorových a rastrových geoprostorových dat. Data jsou užitečná pouze tehdy, když je někdo může vidět. Knihovna GIS pro .NET usnadňuje a urychluje export geografických dat do vektorových nebo rastrových obrázků a poskytuje bohatou symboliku pro složité vizualizační scénáře. 
</p>

<p>
 Aspose.GIS for .NET je navrženo s ohledem na jednoduchost, výkon, použitelnost a přenositelnost. Obsahuje API pro použití s platformami .NET Framework &amp; .NET Core, což vám umožňuje vytvářet aplikace s podporou více platforem s velkou snadností.
</p>
