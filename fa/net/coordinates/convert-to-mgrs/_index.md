<p>
 Aspose.GIS for .NET به شما امکان می دهد سیستم مرجع نظامی (MGRS) را برای واحدهای جغرافیایی تبدیل کنید. کتابخانه ما به شما این امکان را می دهد که به راحتی و به سرعت طول و عرض جغرافیایی را به فرمت واحد مورد نظر خود تبدیل کنید. همچنین کتابخانه ما دارای قابلیتی برای استخراج مکان ها به یک نقطه از متن است.
</p>

<p>
 Aspose.GIS for .NET با در نظر گرفتن سادگی، عملکرد، قابلیت استفاده و قابلیت حمل طراحی شده است. این شامل API هایی برای استفاده با پلتفرم های .NET Framework و .NET Core است که به شما امکان می دهد برنامه های چند پلتفرمی را با سهولت زیادی ایجاد کنید.
</p>
