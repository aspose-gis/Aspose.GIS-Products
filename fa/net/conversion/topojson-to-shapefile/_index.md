 Aspose.GIS for .NET یک API دستکاری و تبدیل داده‌های GIS است. این از خواندن، نوشتن و تبدیل فرمت‌های معروف داده‌های GIS مانند Shapefile های ESRI، GeoJSON، TopoJSON، پایگاه داده Geodatabase ESRI، زبان نشانه گذاری جغرافیا، Google Earth، فرمت تبادل GPS، فرمت‌های MapInfo و OpenStreetMap به طور کامل پشتیبانی می‌کند. این یک API مستقل مبتنی بر .NET است و نیازی به نرم‌افزارهای GIS مانند ArcGIS / ArcMap، QGIS و غیره ندارد.

TopoJSON یک توسعه GeoJSON است که توپولوژی را رمزگذاری می‌کند. فرمت مبتنی بر JSON که برای نمایش ویژگی‌های جغرافیایی با صفات غیر فضایی آنها طراحی شده است. این فرمت اشیاء مختلف JSON و نحوه اتصال آنها را تعریف می‌کند. فرمت JSON اطلاعات جمعی در مورد ویژگی‌های جغرافیایی، وسعت مکانی و خصوصیات آنها را نشان می‌دهد.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="Shapefile" readMoreLink="https://docs.fileformat.com/gis/shp/" >}}

SHP پسوند فایل یکی از انواع اصلی فایل مورد استفاده برای نمایش اطلاعات مکانی است که توسط برنامه‌های Geographic Information Systems (GIS) استفاده می‌شود. این فرمت به عنوان مشخصات باز توسعه یافته است تا قابلیت همکاری بین ESRI و سایر محصولات نرم‌افزاری را تسهیل کند.
