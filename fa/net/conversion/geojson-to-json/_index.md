GeoJSON یک فرمت مبتنی بر JSON است که برای نمایش ویژگی‌های جغرافیایی با صفات غیر فضایی آنها طراحی شده است. این فرمت اشیاء مختلف JSON (نمادگذاری شیء جاوا اسکریپت) و روش پیوستن آنها را تعریف می‌کند. فرمت JSON اطلاعات جمعی در مورد ویژگی‌های جغرافیایی، وسعت‌های فضایی و ویژگی‌های آنها را نشان می‌دهد. یک شیء از این فایل ممکن است هندسه (نقطه، LineString، چند ضلعی)، یک ویژگی یا مجموعه ای از ویژگی‌ها را نشان دهد. ویژگی‌ها آدرس‌ها و مکان‌ها را به صورت نقاط، خیابان‌ها و جاده‌های اصلی و مرزها را به صورت خطوط و کشورها، استان‌ها و مناطق زمین را به صورت چند ضلعی منعکس می‌کنند. با استفاده از GeoJSON، برنامه‌های مسیریابی و ناوبری تلفن همراه مختلف می‌توانند پوشش خدمات خود را نشان دهند. یک توسعه GeoJSON، TopoJSON است که اندازه کوچکتری دارد و توپولوژی فضایی را رمزگذاری می‌کند.

JSON (نمادگذاری شیء جاوا اسکریپت) یک فرمت فایل استاندارد باز برای اشتراک‌گذاری داده‌ها است که از متن قابل خواندن توسط انسان برای ذخیره و انتقال داده‌ها استفاده می‌کند. فایل‌های JSON با پسوند .json ذخیره می‌شوند. JSON به قالب‌بندی کمتری نیاز دارد و جایگزین خوبی برای XML است. JSON از جاوا اسکریپت مشتق شده است اما یک فرمت داده مستقل از زبان است. تولید و تجزیه JSON توسط بسیاری از زبان‌های برنامه‌نویسی مدرن پشتیبانی می‌شود. application/json نوع رسانه مورد استفاده برای JSON است.
