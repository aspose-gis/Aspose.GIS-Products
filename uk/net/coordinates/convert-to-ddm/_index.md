<p>
 Aspose.GIS для .NET дозволяє конвертувати Градуси, Хвилини, Секунди (DDM) для геопросторових одиниць. Наша бібліотека дозволяє легко та швидко перетворювати широту та довготу в бажаний формат одиниць. Також наша бібліотека містить можливість вилучення місць розташування з тексту.
</p>

<p>
 Aspose.GIS для .NET розроблено з урахуванням простоти, продуктивності, зручності використання та портативності. Він містить API для використання з платформами .NET Framework &amp; .NET Core, що дозволяє створювати кросплатформенні додатки з великою легкістю.
</p>
