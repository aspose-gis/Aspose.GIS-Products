GeoJSON - це формат на основі JSON, призначений для представлення географічних об'єктів з їх не просторовими атрибутами. Цей формат визначає різні об’єкти JSON (JavaScript Object Notation) та спосіб їх з’єднання. JSON представляє колективну інформацію про географічні об’єкти, їх просторові межі та властивості.
