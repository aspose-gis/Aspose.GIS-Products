## Overview

This tool converts OpenStreetMap (OSM) data into Scalable Vector Graphics (SVG) format. It allows users to visualize and interact with OSM data in a web browser.

## Features

*   Convert OSM data to SVG format
*   Zoom and pan the map
*   Display various layers of OSM data, such as roads, buildings, and landuse
*   Customizable rendering options
*   Support for large datasets

## Usage

1.  Provide an OpenStreetMap (.osm) file or a URL pointing to one.
2.  Configure rendering options (optional).
3.  Click the "Convert" button.
4.  View and interact with the generated SVG map.

## Rendering Options

*   **Layers:** Select which OSM layers to display.
*   **Zoom Level:** Set the initial zoom level of the map.
*   **Style:** Choose a predefined style for rendering OSM features.
*   **Simplify:** Reduce the complexity of vector data by simplifying geometries.

## Technical Details

The tool uses JavaScript and SVG libraries to perform the conversion and rendering. It is designed to be lightweight and efficient, allowing it to handle large datasets with reasonable performance.

## Limitations

*   Large OSM files may take a significant amount of time to convert.
*   Complex styles may impact rendering performance.
*   The tool does not support editing OSM data.
