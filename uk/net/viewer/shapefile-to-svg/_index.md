## Перетворення Shapefile у SVG за допомогою .NET Viewer

Цей документ містить інструкції щодо перетворення файлів Shapefile у формат SVG (Scalable Vector Graphics) за допомогою .NET Viewer.  SVG - це векторний графічний формат, який добре підходить для відображення географічних даних на веб-сайтах та в інших додатках.

### Необхідне програмне забезпечення

*   **.NET Framework** або **.NET (.NET Core)**: Переконайтеся, що у вас встановлено .NET Framework 4.7.2 або новішу версію, або .NET (.NET Core) SDK.
*   **Visual Studio** або інший IDE для розробки .NET додатків.
*   **.NET Viewer бібліотека**:  Встановіть необхідну бібліотеку .NET Viewer з NuGet пакетного менеджера.

### Кроки перетворення

1.  **Створіть новий проект .NET**: Створіть новий консольний додаток або інший тип проекту у Visual Studio або вашому улюбленому IDE.
2.  **Додайте посилання на .NET Viewer бібліотеку**: Додайте посилання на .NET Viewer бібліотеку до вашого проекту. Це можна зробити за допомогою NuGet пакетного менеджера.
3.  **Напишіть код для перетворення Shapefile у SVG**: Використовуйте API .NET Viewer для відкриття файлу Shapefile та збереження його у форматі SVG.

```csharp
// Приклад коду C# для перетворення Shapefile у SVG
using Net.Sfshapefile;
using System;
using System.IO;

public class ShapefileToolToSvgConverter
{
    public static void Main(string[] args)
    {
        string shapefilePath = "path/to/your/shapefile.shp"; // Шлях до вашого файлу Shapefile
        string svgFilePath = "path/to/output/shapefile.svg"; // Шлях для збереження SVG файлу

        try
        {
            // Відкрийте файл Shapefile
            Shapefile shapefile = new Shapefile(shapefilePath);

            // Збережіть файл у форматі SVG
            shapefile.SaveToSvg(svgFilePath);

            Console.WriteLine($"Файл Shapefile успішно перетворено у SVG: {svgFilePath}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"Помилка під час перетворення файлу Shapefile: {ex.Message}");
        }
    }
}
```

4.  **Запустіть код**: Запустіть ваш проект .NET, щоб виконати перетворення Shapefile у SVG.

### Параметри перетворення

.NET Viewer надає різні параметри для налаштування процесу перетворення Shapefile у SVG. Ці параметри включають:

*   **Колір заповнення**: Вкажіть колір заповнення для полігонів та інших геометричних об'єктів.
*   **Колір контуру**: Вкажіть колір контуру для ліній, полігонів та інших геометричних об’єктів.
*   **Товщина контуру**: Вкажіть товщину контуру для ліній, полігонів та інших геометричних об’єктів.
*   **Прозорість**: Вкажіть рівень прозорості для заповнення та контурів.
*   **Стиль лінії**: Виберіть стиль лінії (наприклад, суцільна, пунктирна, штрих-пунктирна) для лінійних об’єктів.

Детальніше про параметри перетворення можна дізнатися з документації .NET Viewer API.

### Поширені помилки та їх вирішення

*   **Помилка: Не вдалося відкрити файл Shapefile**: Переконайтеся, що шлях до файлу Shapefile вказано правильно і у вас є права на читання файлу.
*   **Помилка: Не вдалося зберегти SVG файл**: Переконайтеся, що шлях для збереження SVG файлу вказано правильно і у вас є права на запис у папку призначення.
*   **Помилка: Відсутня бібліотека .NET Viewer**:  Переконайтеся, що ви встановили та додали посилання на бібліотеку .NET Viewer до вашого проекту.
