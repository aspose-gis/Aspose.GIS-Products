## Overview

NetViewer is a web application designed for visualizing and interacting with geospatial data. It provides a user-friendly interface to explore maps, perform spatial analysis, and manage geographic information.

## Features

*   **Interactive Map Display:** Zoom, pan, and rotate the map view to examine different areas of interest.
*   **Data Layer Management:** Add, remove, and reorder data layers to customize the map display.
*   **Spatial Analysis Tools:** Perform basic spatial analysis operations such as buffering, intersection, and union.
*   **Attribute Data Exploration:** View and filter attribute data associated with geographic features.
*   **Customizable Basemaps:** Choose from a variety of basemap styles to suit your preferences.
*   **User Authentication:** Secure access to the application with user authentication.

## Installation

1.  Clone the repository:

    ```bash
    git clone [repository URL]
    ```
2.  Install dependencies:

    ```bash
    npm install
    ```
3.  Configure environment variables:

    *   `API_URL`: The base URL of the backend API.
    *   `MAPBOX_ACCESS_TOKEN`: Your Mapbox access token (optional).
4.  Run the application:

    ```bash
    npm start
    ```

## Usage

1.  Launch the NetViewer application in your web browser.
2.  Log in with your credentials.
3.  Explore the map and interact with data layers.
4.  Use spatial analysis tools to perform geographic calculations.
5.  Customize the map display to suit your needs.
