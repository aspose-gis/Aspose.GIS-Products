## Огляд

Переглядач GeoTIFF дозволяє переглядати зображення GeoTIFF безпосередньо у веб-браузері. Він підтримує великі файли та надає такі функції, як масштабування, панорамування та налаштування колірної гами.

## Функціональність

*   Перегляд зображень GeoTIFF
*   Масштабування та панорамування
*   Налаштування колірної гами
*   Підтримка великих файлів
*   Інтерактивні інструменти вимірювань (в розробці)

## Використання

1.  Завантажте файл GeoTIFF на сервер.
2.  Відкрийте переглядач GeoTIFF у веб-браузері.
3.  Виберіть файл GeoTIFF для перегляду.
4.  Використовуйте інструменти керування для масштабування, панорамування та налаштування колірної гами.

## Приклад коду

```javascript
// Цей код демонструє, як завантажити та відобразити GeoTIFF у переглядачі.
function loadGeoTiff(url) {
  // Завантаження зображення GeoTIFF з URL-адреси.
  loadImage(url, (image) => {
    // Відображення зображення в переглядачі.
    displayImage(image);
  });
}
```

## Поширені запитання

### Як я можу завантажити файл GeoTIFF?

Файл GeoTIFF можна завантажити з будь-якого джерела, наприклад, з веб-сайту або локального диска. Переконайтеся, що файл доступний для перегляду у веб-браузері.

### Чи підтримує переглядач великі файли?

Так, переглядач GeoTIFF розроблено для підтримки великих файлів. Однак час завантаження може змінюватися залежно від розміру файлу та швидкості з’єднання з Інтернетом.

### Як я можу налаштувати колірну гаму?

Колірна гама можна налаштувати, використовуючи інструменти керування в переглядачі. Ці інструменти дозволяють змінювати контрастність, яскравість та насиченість зображення.
