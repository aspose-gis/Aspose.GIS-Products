## Overview

The Shapefile viewer allows you to visualize and interact with geospatial data stored in Shapefile format. It provides a user-friendly interface for exploring vector layers, querying features, and performing basic spatial analysis.

## Features

*   **Data Visualization:** Display Shapefiles on an interactive map canvas.
*   **Layer Management:** Add, remove, and reorder Shapefile layers.
*   **Feature Querying:** Select and view attribute data for individual features.
*   **Zoom and Pan:** Navigate the map using standard zoom and pan controls.
*   **Attribute Table:** View and sort feature attributes in a table format.
*   **Custom Styling:** Customize the appearance of Shapefile layers (e.g., color, size, symbol).

## Usage

1.  **Load Data:** Use the "Open" button to load a Shapefile from your local machine.
2.  **Explore Layers:** The loaded Shapefiles will appear in the layer list on the left side of the screen.
3.  **View Features:** Click on features on the map canvas to view their attribute data in the feature query window.
4.  **Customize Appearance:** Use the styling options to change the visual representation of your Shapefile layers.

## Supported Shapefile Versions

The viewer supports a wide range of Shapefile versions, including:

*   ESRI Shapefile
*   GeoJSON (limited support)

## Limitations

*   Large Shapefiles may take time to load and render.
*   Complex styling options are not currently supported.
*   Limited support for non-standard Shapefile formats.
