## Overview

This application allows you to convert GeoJSON data into JPEG images. It's a useful tool for visualizing geospatial data and creating custom maps.

## Features

*   **GeoJSON Input:** Accepts GeoJSON files as input.
*   **JPEG Output:** Generates high-quality JPEG images from the GeoJSON data.
*   **Customizable Styling:** Allows you to customize the appearance of the map, including colors, line widths, and font sizes.
*   **Projection Support:** Supports various map projections for accurate rendering.
*   **User-Friendly Interface:** Provides a simple and intuitive interface for easy operation.

## Usage

1.  **Input GeoJSON File:** Load your GeoJSON file into the application.
2.  **Configure Styling (Optional):** Adjust the styling options to customize the map's appearance.
3.  **Generate JPEG:** Click the "Generate JPEG" button to create the image.
4.  **Download Image:** Download the generated JPEG image.

## Technical Details

*   **Programming Language:** C#
*   **Framework:** .NET Framework
*   **Libraries:** GeoJSON.Net, NetTopologySuite
