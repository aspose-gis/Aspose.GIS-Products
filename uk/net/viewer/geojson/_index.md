## GeoJSON Переглядач

Завантажуйте та переглядайте файли GeoJSON на карті.

### Функціональність

*   Перегляд файлів GeoJSON
*   Інтерактивна карта з масштабуванням та панорамуванням
*   Відображення географічних даних у вигляді точок, ліній та полігонів
*   Налаштування стилю відображення даних (колір, розмір, прозорість)
*   Можливість перегляду інформації про об'єкти GeoJSON при наведенні курсора або кліку

### Використання

1.  Відкрийте GeoJSON Переглядач.
2.  Натисніть кнопку "Завантажити файл".
3.  Виберіть файл GeoJSON з вашого комп’ютера.
4.  Файл буде завантажено та відображено на карті.
5.  Використовуйте елементи керування картою для навігації та масштабування.

### Приклад файлу GeoJSON

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Point",
        "coordinates": [10.45, 59.92]
      },
      "properties": {
        "name": "Осло",
        "population": 693000
      }
    },
    {
      "type": "Feature",
        "geometry": {
          "type": "LineString",
          "coordinates": [[10.45, 59.92], [10.74, 60.36]]
        },
        "properties": {
          "name": "Дорога",
          "length": 10000
        }
    }
  ]
}
```

### Поради та рекомендації

*   Переконайтеся, що ваш файл GeoJSON є валідним.
*   Для великих файлів GeoJSON може знадобитися більше часу для завантаження та відображення.
*   Використовуйте елементи керування картою для навігації та масштабування.
*   Експериментуйте з налаштуваннями стилю відображення даних, щоб отримати найкращий результат.
