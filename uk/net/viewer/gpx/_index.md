## What is GPX?
// Що таке GPX?

GPX (GPS Exchange Format) is an XML schema for representing geographic data. It can store waypoints, routes, and tracks.
GPX (Формат обміну даними GPS) є схемою XML для представлення географічних даних. Він може зберігати точки маршруту, маршрути та треки.

## GPX Viewer Features
// Функції переглядача GPX

*   View GPX files on the map
*   Filter routes and tracks by name
*   Display elevation profiles
*   Export data to other formats
*   Support for custom icons
*   Offline support
*   GPX file validation
*   Route planning
*   Data filtering
*   Customizable appearance

Переглядач підтримує такі версії файлів GPX:
1.  GPX 1.0

## How to Use
// Як користуватися

1.  Open the viewer.
2.  Load a GPX file using the "File" menu.
3.  The routes and tracks will be displayed on the map.
4.  Use the controls to zoom, pan, and filter data.

Відкрийте переглядач.
Завантажте файл GPX за допомогою меню «Файл».
Маршрути та треки відображатимуться на карті.
Використовуйте засоби керування для масштабування, панорамування та фільтрації даних.
