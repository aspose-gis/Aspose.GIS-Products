## GML Viewer

The GML Viewer allows you to visualize and interact with Geographic Markup Language (GML) files.

### Features

*   View GML data in a map view
*   Display feature attributes in a table
*   Search for features by attribute value
*   Zoom to a specific feature
*   Export GML data to other formats

### Usage

1.  Open the GML Viewer application.
2.  Load a GML file using the "File" -> "Open" menu option.
3.  The GML data will be displayed in the map view.
4.  Use the navigation controls to pan and zoom the map.
5.  Select a feature to view its attributes in the table.
6.  Use the search bar to find features by attribute value.
7.  Right-click on a feature to export it to other formats.

### Supported GML Dialects

The GML Viewer supports the following GML dialects:

*   Simple Feature (SFS)
*   Motion Function (MF)
*   Transaction (T)
*   Coverage (C)

### Troubleshooting

If you encounter any problems with the GML Viewer, please consult the troubleshooting guide or contact support.
