## Overview ##

This viewer allows you to convert a GeoTIFF file into a JPEG image. It provides options for controlling the output quality and other parameters.

## Usage ##

1.  **Load GeoTIFF:** Select a GeoTIFF file from your computer using the "Choose File" button.
2.  **Adjust Parameters (Optional):** Modify the following settings to customize the conversion:
    *   **Quality:** Adjust the JPEG quality level (0-100). Higher values result in better image quality but larger file sizes.
    *   **Resolution:** Specify the desired resolution for the output image.
3.  **Convert:** Click the "Convert" button to start the conversion process.
4.  **Download JPEG:** Once the conversion is complete, a download link will appear allowing you to save the resulting JPEG image.

## Parameters ##

*   **Input File:** The GeoTIFF file to be converted.
*   **Output Quality:** A value between 0 and 100 representing the quality of the output JPEG image.  A higher value means better quality but a larger file size.
*   **Resolution:** The desired resolution (width x height) for the output image in pixels.

## Troubleshooting ##

*   **File Size Limits:** There may be limitations on the maximum file size that can be uploaded. If you encounter issues with large files, try reducing the resolution or quality settings.
*   **Unsupported File Formats:** Ensure that the input file is a valid GeoTIFF (.tif or .tiff) file.
*   **Conversion Errors:**  If the conversion fails, check the console for error messages and ensure that all required parameters are set correctly.
