## Map Info

This tab provides access to MapInfo specific functionality.

### Layers

The Layers section allows you to manage the layers displayed on the map. You can add, remove, and reorder layers as needed.

### Tables

The Tables section displays a list of tables associated with the current map document. You can view table data, perform queries, and export data to various formats.

### Layouts

The Layouts section allows you to manage the layout of your MapInfo documents. You can create, edit, and save layouts to customize the appearance of your maps.

### Toolbars

The Toolbars section provides access to commonly used MapInfo tools. These tools can help you perform tasks such as measuring distances, creating polygons, and labeling features.
