Geographic Markup Language (GML) は、GIS で使用される XML ベースの形式です。GML は、インターネット上の地理的トランザクションのためのオープンな交換形式です。この形式はデータと構造指向です。

GPX 拡張は、インターネット上のアプリケーションおよび Web サービス間で GPS データと交換するための GPS Exchange 形式を表します。これは軽量の XML 形式であり、複数のプログラムでインポートおよび読み取りできる GPS データ (ウェイポイント、ルート、トラック) を含んでいます。GPX はオープンであり、さまざまなアプリケーションや GPS デバイスによってサポートされています。
