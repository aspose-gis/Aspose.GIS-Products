## GPX to PNG変換ツール

このツールは、GPXファイルをPNG画像に変換します。

### 機能

*   GPXファイルからの経路データの読み込み
*   地図の表示とズームレベルの調整
*   PNG画像の生成

### 使用方法

1.  GPXファイルを選択してください。
2.  地図の種類とズームレベルを設定してください。
3.  「変換」ボタンをクリックして、PNG画像を生成してください。

### 注意事項

*   大きなGPXファイルは、変換に時間がかかる場合があります。
*   生成される画像のサイズは、設定したズームレベルによって異なります。
*   このツールは、オンラインで動作します。インターネット接続が必要です。

### 開発者向け情報

このツールは、以下の技術を用いて開発されています。

*   JavaScript
*   Leaflet.js
*   HTML5
*   CSS3
