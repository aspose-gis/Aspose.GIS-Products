## Overview ##

NetViewer is a powerful and versatile web application designed for the seamless viewing of geospatial data. It provides an intuitive interface for exploring maps, analyzing features, and interacting with geographic information. Whether you're a GIS professional or simply need to visualize spatial data, NetViewer offers a comprehensive solution.

## Key Features ##

*   **Interactive Map Display:** Zoom, pan, and rotate the map to explore different areas of interest.
*   **Layer Management:** Add, remove, and reorder layers to customize your view.
*   **Feature Information:** View detailed information about individual features by clicking on them.
*   **Attribute Filtering:** Filter features based on their attributes to focus on specific data subsets.
*   **Customizable Basemaps:** Choose from a variety of basemaps to suit your needs.
*   **Data Export:** Export map images and feature data in various formats.

## Supported Data Formats ##

NetViewer supports a wide range of geospatial data formats, including:

*   Shapefile
*   GeoJSON
*   KML
*   WMS
*   WFS
*   Raster data (e.g., GeoTIFF)

## System Requirements ##

*   **Web Browser:** Modern web browser (Chrome, Firefox, Safari, Edge)
*   **Operating System:** Windows, macOS, Linux

## Getting Started ##

1.  **Download NetViewer:** Download the latest version of NetViewer from our website.
2.  **Installation:** Extract the downloaded files to a suitable directory on your server.
3.  **Configuration:** Configure NetViewer by modifying the `config.ini` file.
4.  **Deployment:** Deploy NetViewer to your web server.
5.  **Access NetViewer:** Access NetViewer through your web browser using the configured URL.
