## はじめに

このツールは、OpenStreetMap (OSM) のデータを基に、PNG 画像を作成します。地図の表示範囲やズームレベルなどを調整して、必要な画像を簡単に作成できます。

## 機能概要

*   **OSM データソース:** OpenStreetMap API から直接データを取得します。
*   **表示範囲設定:** 経度と緯度の範囲を指定することで、地図の表示領域を制御します。
*   **ズームレベル調整:** 地図の詳細度合いを調整できます。
*   **出力画像形式:** PNG 形式で画像を保存します。
*   **カスタマイズオプション:** タイルセットやスタイルなどを変更して、地図の外観を調整できます。

## 使用方法

1.  **表示範囲の指定:** 経度と緯度の値を入力し、地図の表示領域を設定します。
2.  **ズームレベルの設定:** ズームレベルを入力し、地図の詳細度合いを調整します。
3.  **画像の生成:** 「生成」ボタンをクリックすると、PNG 画像が作成されます。
4.  **画像のダウンロード:** 作成された画像をダウンロードします。

## 詳細設定

*   **タイルセットの選択:** 使用するタイルセットを選択できます。デフォルトでは OpenStreetMap の標準タイルセットが使用されます。
*   **スタイルの変更:** 地図のスタイルを変更できます。例えば、道路や建物の色を変えることができます。
*   **オーバーレイの追加:** 他のデータセットを地図上に重ねて表示することができます。

## 注意事項

*   OSM API の利用規約に従って使用してください。
*   大量のデータを一度に処理すると、API からの応答が遅くなることがあります。
*   生成される画像のサイズや品質は、設定したパラメータによって異なります。

## 補足

このツールは、OpenStreetMap のデータを活用して地図画像を作成するための便利なツールです。様々なカスタマイズオプションを利用して、目的に合った地図画像を生成してください。
