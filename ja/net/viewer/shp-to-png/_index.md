## Overview

This application converts shapefiles (.shp) into Portable Network Graphics (.png) images. It allows users to visualize and export geospatial data in a convenient image format.

## Features

*   **Shapefile Input:** Supports standard shapefile formats.
*   **PNG Output:** Generates high-quality PNG images.
*   **Customization Options:** Allows adjustments to rendering parameters (e.g., color, resolution).
*   **User-Friendly Interface:** Provides an intuitive interface for easy operation.

## Usage

1.  **Input Shapefile:** Select a shapefile (.shp) from your local system.
2.  **Configure Rendering:** Adjust the rendering options as needed.
3.  **Generate PNG:** Click the "Generate" button to create the PNG image.
4.  **Save Image:** Save the generated PNG file to your desired location.

## Technical Details

*   **Programming Language:** Python
*   **Libraries:** `geopandas`, `matplotlib`
*   **Dependencies:** Requires a working installation of Python and the necessary libraries.

## Troubleshooting

*   **Error: "Shapefile not found"**: Verify that the shapefile path is correct.
*   **Error: "Invalid shapefile format"**: Ensure that the file is a valid shapefile (.shp).
*   **Image quality issues:** Adjust rendering parameters (e.g., resolution, DPI) to improve image quality.
