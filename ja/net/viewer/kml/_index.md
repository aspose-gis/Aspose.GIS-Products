## Overview

The KML viewer allows you to view and interact with KML (Keyhole Markup Language) files within the Net Viewer environment.  It provides a user-friendly interface for exploring geospatial data represented in KML format.

## Features

*   **KML File Loading:** Easily load KML files from local storage or remote URLs.
*   **Interactive Map Display:** Visualize KML features on an interactive map with zoom and pan capabilities.
*   **Feature Styling:** Customize the appearance of KML features using various styling options, including colors, sizes, and icons.
*   **Data Filtering:** Filter KML features based on attributes or properties to focus on specific data subsets.
*   **Information Popups:** Display detailed information about each KML feature when clicked.
*   **Geocoding Support:**  Automatically geocode addresses and locations using integrated geocoding services.
*   **Customizable Basemaps:** Choose from a variety of basemap providers to enhance the visual context of your KML data.

## Usage

1.  **Loading a KML File:**
    *   Click the "Load KML" button.
    *   Browse and select a KML file from your local storage, or enter a URL for a remote KML file.
2.  **Navigating the Map:**
    *   Use the mouse wheel to zoom in and out of the map.
    *   Click and drag the map to pan around.
3.  **Viewing Feature Information:**
    *   Click on a KML feature to display its associated information in a popup window.
4.  **Styling Features (Optional):**
    *   Access the styling panel to modify the appearance of KML features.

## Supported KML Features

The KML viewer supports a wide range of KML features, including:

*   Placemarks
*   Folders
*   Network Links
*   Ground Overlays
*   Screen Overlays
*   Photogrammetry
*   Solid and Styled Polygons
*   Solid and Styled Lines
*   Points

## Troubleshooting

*   **KML File Not Loading:** Ensure the KML file is valid and accessible. Check for any errors in the file structure or syntax.
*   **Map Display Issues:** Verify that the basemap provider is available and functioning correctly.  Try switching to a different basemap.
*   **Feature Styling Problems:** Double-check the styling rules to ensure they are compatible with the KML features.
