## GeoJSON からの PNG 生成

このツールを使用すると、GeoJSON ファイルを PNG 画像に変換できます。

### 機能

*   さまざまなズームレベルと解像度でマップをレンダリングします。
*   カスタムタイルサーバーを使用してマップを表示します。
*   生成された画像をダウンロードします。

### 使用方法

1.  GeoJSON ファイルを選択します。
2.  必要なオプションを設定します (ズームレベル、解像度、タイルサーバーなど)。
3.  「変換」ボタンをクリックします。
4.  生成された PNG 画像をダウンロードします。

### オプション

*   **ズームレベル:** マップのズームレベルを指定します。
*   **解像度:** 生成される画像の解像度 (幅と高さ) を指定します。
*   **タイルサーバー:** 使用するタイルサーバーの URL を指定します。
*   **属性:** GeoJSON データの表示方法を制御するための追加オプションを設定します。

### 例

GeoJSON ファイル `data.geojson` をズームレベル 10、解像度 512x512 で変換するには、次のコマンドを実行します。

```bash
geojson-to-png -i data.geojson -z 10 -r 512x512
```

このコマンドは、`output.png` という名前の PNG 画像ファイルを生成します。

### 注意事項

*   GeoJSON ファイルが有効であることを確認してください。
*   タイルサーバーを使用する場合は、そのサーバーが利用可能で、必要な認証情報を持っていることを確認してください。
*   高解像度の画像を生成するには、より多くのメモリと時間が必要になる場合があります。
