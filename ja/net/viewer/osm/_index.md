## Overview ##

The OpenStreetMap (OSM) viewer allows you to explore and interact with OSM data directly within the application. You can pan, zoom, identify features, and perform various spatial analysis tasks.

## Features ##

*   **Interactive Map:** Navigate the map using mouse or keyboard controls.
*   **Feature Identification:** Click on features to view their attributes.
*   **Data Layers:** Toggle different OSM data layers (roads, buildings, landuse, etc.).
*   **Search:** Find specific locations by name or address.
*   **Custom Basemaps:** Use alternative basemap providers.

## Usage ##

1.  **Access the Viewer:** Open the OSM viewer from the main menu.
2.  **Navigation:** Use the mouse wheel to zoom, click and drag to pan.
3.  **Feature Identification:** Click on a feature to display its attributes in a pop-up window.
4.  **Layer Control:** Adjust the visibility of different data layers using the layer control panel.
5.  **Search:** Enter a search term in the search box to locate specific places.

## Configuration ##

The OSM viewer can be configured through various settings:

*   **Basemap Provider:** Select your preferred basemap provider (e.g., OpenStreetMap, Mapbox).
*   **Data Layers:** Customize which data layers are displayed by default.
*   **Attribution:** Configure the attribution text to display on the map.

## Troubleshooting ##

*   **Map Loading Issues:** Check your internet connection and ensure that the OSM server is accessible.
*   **Feature Identification Errors:** Verify that the feature attributes are correctly defined in the data source.
*   **Performance Problems:** Reduce the number of visible data layers or use a lower-resolution basemap.
