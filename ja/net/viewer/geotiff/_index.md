## Overview

The GeoTIFF viewer is a tool for visualizing and interacting with GeoTIFF raster datasets. It allows users to pan, zoom, and measure features on the map. The viewer also supports various metadata formats and projections.

## Features

*   Pan and zoom
*   Measure distances and areas
*   Display metadata
*   Support for multiple projections
*   Customizable color schemes

## Usage

To use the GeoTIFF viewer, simply load a GeoTIFF file into the viewer. The viewer will automatically display the raster data on the map. Users can then interact with the map using the pan and zoom controls.

## Supported Formats

The GeoTIFF viewer supports the following formats:

*   GeoTIFF
*   ASCII
*   XYZ
