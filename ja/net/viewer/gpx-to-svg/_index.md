## GPX to SVG Converter

This tool converts GPX files to SVG format. You can use it to share map data or analyze it further.

## How to Use

1.  **Upload your GPX file:** Drag and drop your GPX file into the designated area, or click "Choose File" to select it from your computer.
2.  **Customize options (optional):** Adjust settings like line width, color, and font size to customize the appearance of the SVG output.
3.  **Convert:** Click the "Convert" button to start the conversion process.
4.  **Download your SVG file:** Once the conversion is complete, you can download the resulting SVG file.

## Features

*   Simple and easy-to-use interface
*   Customizable options for appearance
*   Fast conversion speed
*   No registration required

## Example GPX File

Here's an example of a simple GPX file:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<gpx version="1.1">
  <trk>
    <name>My Hike</name>
    <numPoints>5</numPoints>
    <waypoint lat="37.7749" lon="-122.4194"/>
    <waypoint lat="37.7833" lon="-122.4069"/>
    <waypoint lat="37.7905" lon="-122.3984"/>
    <waypoint lat="37.7959" lon="-122.3910"/>
    <waypoint lat="37.7922" lon="-122.3866"/>
  </trk>
</gpx>
```
