## Shapefile を PNG に変換するビューア

このビューアを使用すると、シェープファイル (.shp) を PNG 画像に変換できます。これは、地理空間データを地図やその他の視覚的な表現として共有または表示する必要がある場合に役立ちます。

### 機能

*   シェープファイルを PNG 画像に変換
*   さまざまなプロジェクションをサポート
*   出力画像のサイズと解像度を調整可能
*   ユーザーフレンドリーなインターフェース

### 使用方法

1.  シェープファイル (.shp) を選択します。
2.  必要に応じて、プロジェクション、サイズ、解像度などの変換オプションを設定します。
3.  「変換」ボタンをクリックして、PNG 画像を生成します。
4.  変換された PNG 画像を保存します。

### 依存関係

*   .NET Framework 4.7.2 以降
*   GeoSharp ライブラリ

### 注意事項

*   大きなシェープファイルの場合、変換に時間がかかる場合があります。
*   出力画像の品質は、シェープファイルのデータと選択した変換オプションによって異なります。
