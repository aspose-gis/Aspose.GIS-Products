## Shapefile Viewer

The Shapefile viewer allows you to view and interact with shapefiles directly in your browser.  It supports a wide range of shapefile formats, including points, lines, polygons, and rasters.

### Features

*   **Zoom and Pan:** Easily navigate the map by zooming in and out, and panning around.
*   **Attribute Table:** View and sort data associated with each feature in an attribute table.
*   **Feature Highlighting:** Highlight individual features based on their attributes.
*   **Layer Control:** Toggle layers on and off to focus on specific areas of interest.
*   **Custom Styling:** Customize the appearance of features using different colors, symbols, and line widths.
*   **Measurement Tools:** Measure distances and areas on the map.
*   **Querying:** Query features based on their attributes.

### Supported Shapefile Formats

The viewer supports the following shapefile formats:

*   Points
*   Lines
*   Polygons
*   Multi-points
*   Multi-lines
*   Multi-polygons
*   Collections

### Usage

To use the Shapefile viewer, simply upload a shapefile to the viewer. The viewer will automatically load and display the data. You can then interact with the map using the controls described above.

### Customization

The viewer can be customized by providing a configuration file. The configuration file allows you to specify things like:

*   **Default Zoom Level:** The zoom level at which the map is initially displayed.
*   **Initial Extents:** The geographic area that is initially visible on the map.
*   **Base Map URL:** The URL of a base map to use for the viewer.
*   **Attribute Table Columns:** The columns from the attribute table to display.

### Development

The Shapefile viewer is an open-source project.  You can contribute to the project by submitting pull requests on GitHub.

#### Dependencies

The viewer depends on the following libraries:

*   Leaflet
*   GeoJSON
*   jQuery

#### Build Process

To build the viewer, follow these steps:

1.  Install Node.js and npm.
2.  Clone the repository from GitHub.
3.  Run `npm install`.
4.  Run `npm run build`.

The built files will be located in the `dist` directory.
