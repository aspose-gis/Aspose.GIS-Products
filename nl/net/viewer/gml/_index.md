## GML Viewer

The GML Viewer allows you to visualize and interact with Geographic Markup Language (GML) files.

### Features

*   View GML data on a map
*   Query features by attribute
*   Identify features at a location
*   Measure distances and areas
*   Export data in various formats

### Supported Formats

The GML Viewer supports the following GML formats:

*   Simple Feature Collection
*   Styled Layer Descriptor (SLD)
*   Web Map Service (WMS)

### Getting Started

1.  Open the GML Viewer application.
2.  Click the "Open" button and select your GML file.
3.  The GML data will be displayed on the map.
4.  Use the tools in the toolbar to interact with the data.

### Troubleshooting

If you are having trouble viewing your GML file, please check the following:

*   Make sure that the GML file is valid.
*   Make sure that the GML file contains geographic coordinates.
*   Make sure that you have installed the latest version of the GML Viewer.

## GML-Viewer

De GML-Viewer maakt het mogelijk om geografische markup taal (GML) bestanden te visualiseren en mee te interageren.

### Functies

*   Bekijk GML gegevens op een kaart
*   Vraag kenmerken op basis van attribuut
*   Identificeer kenmerken op een locatie
*   Meet afstanden en oppervlakten
*   Exporteer data in verschillende formaten

### Ondersteunde Formaten

De GML-Viewer ondersteunt de volgende GML-formaten:

*   Simple Feature Collection
*   Styled Layer Descriptor (SLD)
*   Web Map Service (WMS)

### Aan de slag

1.  Open de GML-Viewer applicatie.
2.  Klik op de knop "Openen" en selecteer uw GML bestand.
3.  De GML gegevens worden weergegeven op de kaart.
4.  Gebruik de tools in de werkbalk om met de data te interageren.

### Probleemoplossing

Als u problemen ondervindt bij het bekijken van uw GML-bestand, controleer dan het volgende:

*   Zorg ervoor dat het GML bestand geldig is.
*   Zorg ervoor dat het GML bestand geografische coördinaten bevat.
*   Zorg ervoor dat u de nieuwste versie van de GML-Viewer heeft geïnstalleerd.
