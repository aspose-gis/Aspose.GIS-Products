## Overview

The OpenStreetMap (OSM) viewer allows you to explore and interact with OSM data directly within the application. You can pan, zoom, identify features, and perform various spatial analysis tasks.

## Features

*   **Interactive Map:** Navigate the map using mouse or keyboard controls.
*   **Feature Identification:** Click on features to view their attributes.
*   **Spatial Analysis:** Perform basic spatial queries and calculations.
*   **Customizable Layers:** Control the visibility of different OSM layers.
*   **Data Download:** Export data in various formats (e.g., GeoJSON, Shapefile).

## Usage

1.  **Accessing the Viewer:** Navigate to the OpenStreetMap viewer within the application's menu.
2.  **Navigation:** Use the mouse wheel or keyboard arrows to pan and zoom the map.
3.  **Feature Identification:** Click on a feature to display its attributes in a pop-up window.
4.  **Layer Control:** Adjust the visibility of layers using the layer control panel.

## Configuration

The viewer's behavior can be configured through various settings:

*   **Base Map Tile Server:** Select from different tile server providers (e.g., OpenStreetMap, Mapbox).
*   **Data Cache Size:** Configure the amount of data to cache for faster loading times.
*   **Feature Display Precision:** Adjust the number of decimal places displayed for feature coordinates.

## Troubleshooting

*   **Slow Loading Times:** Ensure a stable internet connection and consider increasing the data cache size.
*   **Missing Features:** Verify that the selected layers are enabled and that the OSM data is up-to-date.
*   **Display Errors:** Check for browser compatibility issues or outdated drivers.

For assistance with the OpenStreetMap viewer, please consult the application's documentation or contact support.
