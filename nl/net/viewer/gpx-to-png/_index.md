## Convert GPX files to PNG images

This tool converts GPX (GPS Exchange Format) files into PNG images. It's useful for visualizing GPS tracks and routes on a map.

### How it works

The converter uses OpenLayers to display the map and draws the GPX track or route on top of it. The resulting image is then saved as a PNG file.

### Usage

1.  Upload your GPX file.
2.  Select the desired map style (e.g., satellite, road).
3.  Adjust the zoom level to fit the data.
4.  Click the "Convert" button.
5.  Download the generated PNG image.

### Features

*   Supports GPX tracks and routes.
*   Multiple map styles available.
*   Zoom level adjustment.
*   Easy-to-use interface.
*   Fast conversion speed.

### Limitations

*   Large GPX files may take longer to convert.
*   The quality of the generated image depends on the zoom level and map style selected.
*   No support for other file formats (e.g., KML, GeoJSON).

### Troubleshooting

*   If the map doesn't load, check your internet connection.
*   If the conversion fails, try uploading a smaller GPX file.
*   If the image quality is poor, adjust the zoom level and map style.
