## Overzicht

Deze tool zet Shapefile (SHP) bestanden om naar SVG (Scalable Vector Graphics) formaat.  SVG is een vectorafbeeldingsformaat dat geschikt is voor webgebruik en schaalbaar zonder kwaliteitsverlies.

## Functionaliteit

*   **SHP inlezen:** De tool leest de geometrische data uit een SHP bestand.
*   **SVG genereren:**  De data wordt omgezet naar SVG code.
*   **Downloaden:** De gegenereerde SVG kan worden gedownload.
*   **Stijlen aanpassen (optioneel):** Mogelijkheid om de stijl van de SVG te beïnvloeden, zoals lijnkleur en vulling.

## Gebruik

1.  Selecteer een SHP bestand via het upload knop.
2.  (Optioneel) Pas stijlinstellingen aan indien gewenst.
3.  Klik op de "Converteer" knop.
4.  Download de gegenereerde SVG file.

## Voorbeelden van gebruik

*   **Webmaps:** Gebruik SVG's voor interactieve webkaarten.
*   **Illustraties:** Maak vectorillustraties gebaseerd op geografische data.
*   **Printmedia:** Integreer SHP data in printproducten zoals kaarten en rapporten.
