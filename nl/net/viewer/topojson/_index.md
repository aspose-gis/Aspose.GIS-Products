## Introduction

The TopoJSON viewer allows you to visualize and interact with TopoJSON data. It provides a user-friendly interface for exploring geographic features and attributes.

## Features

*   **Interactive Map:** Zoom, pan, and rotate the map to explore different regions.
*   **Feature Highlighting:** Hover over features to display their attributes in a tooltip.
*   **Data Filtering:** Filter features based on specific attribute values.
*   **Custom Styling:** Customize the appearance of features using various styling options.
*   **Attribute Tables:** View and sort feature data in tabular format.

## Usage

1.  **Load Data:** Select a TopoJSON file to load into the viewer.
2.  **Explore Map:** Use the map controls to navigate and zoom.
3.  **View Attributes:** Hover over features to see their attributes.
4.  **Filter Data:** Apply filters to focus on specific data subsets.
5.  **Customize Styling:** Adjust styling options to enhance visualization.

## Supported Formats

*   TopoJSON
*   GeoJSON (with limitations)

## Dependencies

*   [Leaflet](https://leafletjs.com/) - JavaScript library for interactive maps.
*   [TopoJSON](https://topojson.org/) - Format for representing geographic data.
*   [jQuery](https://jquery.com/) - Fast, small, versatile JavaScript library.
