## GeoJSON Viewer

The GeoJSON Viewer is a tool that allows you to view and interact with GeoJSON data directly in your web browser. It provides a user-friendly interface for exploring geographic features, attributes, and relationships.

### Features

*   **Interactive Map:** Displays GeoJSON data on an interactive map using Leaflet.js.
*   **Feature Highlighting:** Highlights individual features when clicked or hovered over.
*   **Attribute Display:** Shows the attribute values associated with each feature in a sidebar panel.
*   **Zoom and Pan:** Allows users to zoom in and out of the map and pan around to explore different areas.
*   **Data Filtering:** Provides options for filtering GeoJSON data based on attribute values.
*   **Custom Styling:** Supports custom styling of features using CSS or Mapbox GL styles.
*   **GeoJSON Validation:** Validates GeoJSON files against the official GeoJSON specification.

### Usage

1.  **Load GeoJSON Data:** Provide a URL or upload a GeoJSON file to load data into the viewer.
2.  **Explore Features:** Click on features to view their attributes and details.
3.  **Filter Data:** Use the filtering options to focus on specific subsets of your data.
4.  **Customize Styling:** Adjust the styling of features to enhance visualization.

### Supported GeoJSON Formats

The GeoJSON Viewer supports a wide range of GeoJSON formats, including:

*   Feature Collections
*   Feature Sets
*   Geometry Objects (Point, LineString, Polygon, MultiPolygon)
*   Properties with various data types (string, number, boolean, array, object)

### Customization

The GeoJSON Viewer can be customized to match your website's branding and design. You can modify the following aspects:

*   **Map Tiles:** Use custom map tile providers (e.g., Mapbox, OpenStreetMap).
*   **Color Schemes:** Change the color scheme of the viewer to align with your brand colors.
*   **Font Styles:** Customize the font styles used in the interface.
*   **Attribute Display Format:** Control how attribute values are displayed in the sidebar panel.
