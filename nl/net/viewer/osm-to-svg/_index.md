## Overview

This tool converts OpenStreetMap (OSM) data into Scalable Vector Graphics (SVG) format. It allows users to visualize and interact with OSM data in a web browser.

## Features

*   Convert OSM data to SVG format
*   Zoom and pan the map
*   Display various layers of OSM data, such as roads, buildings, and landuse
*   Customizable rendering options
*   Support for different tile servers

## Usage

1.  Provide an OpenStreetMap URL or a local GeoJSON file as input.
2.  Configure rendering options (optional).
3.  Click the "Convert" button to generate the SVG output.
4.  Download the SVG file or view it in the browser.

## Configuration Options

*   **Tile Server:** Select a tile server from the dropdown list.
*   **Zoom Level:** Set the initial zoom level of the map.
*   **Layer Visibility:** Enable or disable specific layers of OSM data.
*   **Rendering Style:** Choose a rendering style for the SVG output.

## Troubleshooting

*   If the conversion fails, check the input URL or file path.
*   Ensure that the tile server is accessible and functioning correctly.
*   Try adjusting the rendering options to optimize performance.
