## Introduction

NetViewer is a powerful web application designed to view and interact with geospatial data. It allows users to visualize various types of geographic information, including vector layers, raster images, and WMS services. The application provides tools for panning, zooming, querying features, and performing basic spatial analysis.

## Features

*   **Support for multiple data formats:** NetViewer supports a wide range of geospatial data formats, including Shapefile, GeoJSON, KML, and more.
*   **Interactive map display:** Users can easily pan, zoom, and interact with the map to explore different areas of interest.
*   **Feature querying:** The application allows users to query features on the map by clicking on them or using a search bar.
*   **WMS support:** NetViewer supports Web Map Service (WMS) connections, allowing users to view data from remote servers.
*   **Customizable appearance:** Users can customize the appearance of the map, including changing colors, fonts, and labels.

## Getting Started

To get started with NetViewer, simply open the application in your web browser. The application will automatically load a default map layer. You can then use the tools provided to explore the map and interact with the data.

### Data Sources

NetViewer supports various data sources, including:

*   **Local files:** Users can load geospatial data from local files on their computer.
*   **Web services:** NetViewer can connect to web services such as WMS and WMTS servers.
*   **Online basemaps:** The application provides access to online basemaps from providers like OpenStreetMap and Google Maps.

## Advanced Usage

### Feature Styling

NetViewer allows users to customize the appearance of features on the map using CSS-like styling rules. This can be useful for highlighting specific features or creating thematic maps.

### Scripting

The application provides a scripting interface that allows users to automate tasks and extend its functionality. The scripting language is JavaScript.
