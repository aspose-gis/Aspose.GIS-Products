## GeoTIFF Viewer

The GeoTIFF viewer allows you to visualize and interact with GeoTIFF raster datasets.

### Features

*   Display GeoTIFF images
*   Zoom and pan
*   Adjust brightness, contrast, and gamma
*   Measure distances and areas
*   Identify pixel values
*   Support for various georeferencing projections

### Usage

1.  Load a GeoTIFF file using the "Open" button.
2.  The image will be displayed in the viewer.
3.  Use the zoom and pan controls to navigate the image.
4.  Adjust the brightness, contrast, and gamma settings as needed.
5.  Use the measurement tools to measure distances and areas.
6.  Click on a pixel to identify its value.

### Supported GeoTIFF tags

The viewer supports the following GeoTIFF tags:

*   GeoKeyDirectoryTag
*   GeoImageFieldTags
*   TiledGeoimageWorldfileSegmentTag
*   ColorMap
*   Compression

### Limitations

*   Large files may take time to load.
*   Complex projections may not be supported.
*   Some GeoTIFF tags may not be recognized.

### Troubleshooting

If you encounter any problems, please check the following:

*   Make sure that the GeoTIFF file is valid.
*   Check that the projection is supported.
*   Try reloading the file.
*   Contact support if the problem persists.

### Development

The viewer is developed using JavaScript and Leaflet.js. Contributions are welcome!
