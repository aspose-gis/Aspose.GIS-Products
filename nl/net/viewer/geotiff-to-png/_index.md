## Converting GeoTIFF to PNG with the NetViewer

The NetViewer provides a simple and efficient way to convert GeoTIFF files into PNG images. This process is crucial for displaying raster data on web maps or performing image analysis.

### Prerequisites

*   A valid GeoTIFF file.
*   Access to the NetViewer application.

### Conversion Steps

1.  **Load the GeoTIFF:** Open the NetViewer and load your GeoTIFF file using the "Open File" option.
2.  **Configure Rendering Options (Optional):** Adjust rendering options such as color palette, contrast, and brightness to optimize the image appearance.
3.  **Export as PNG:** Select "Export" -> "PNG" from the menu bar.
4.  **Specify Output Location:** Choose a location on your computer to save the resulting PNG file.
5.  **Initiate Conversion:** Click the "Save" button to start the conversion process.

### Considerations

*   **File Size:** Large GeoTIFF files can result in substantial PNG image sizes. Consider resampling or cropping the data before conversion if file size is a concern.
*   **Color Depth:** The NetViewer supports various color depths for PNG export. Experiment with different settings to achieve the desired balance between image quality and file size.
*   **Transparency:** GeoTIFF files may contain alpha channels, which can be preserved during PNG conversion to create transparent images.

### Troubleshooting

*   **Error Loading File:** Ensure that the GeoTIFF file is not corrupted and is in a supported format.
*   **Conversion Failure:** Check for sufficient disk space and memory resources. Try restarting the NetViewer application.
*   **Unexpected Image Output:** Verify rendering options and color palette settings. Consult the NetViewer documentation for more details.
