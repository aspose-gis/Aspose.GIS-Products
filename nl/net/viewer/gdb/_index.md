## Overview

The GDB Viewer is a tool for visualizing and interacting with geodatabase data. It allows users to explore spatial data, query features, and perform basic analysis tasks.

## Features

*   **Data Visualization:** Display geodatabase layers on a map canvas.
*   **Feature Query:** Select and view attributes of individual features.
*   **Spatial Analysis:** Perform simple spatial operations like buffering and intersection.
*   **Attribute Editing:** Modify attribute values for selected features (requires appropriate permissions).
*   **Customizable Appearance:** Control layer symbology, labels, and other visual properties.

## Usage

1.  **Load Geodatabase:** Open a geodatabase file (.gdb) using the "Open Data" button.
2.  **Explore Layers:** The table of contents will display available layers within the geodatabase. Expand layers to view sublayers.
3.  **Zoom and Pan:** Use the map navigation tools (zoom, pan, rotate) to explore the data.
4.  **Select Features:** Click on features in the map canvas to select them. Selected features' attributes will be displayed in the attribute table.
5.  **Query Attributes:** Use the query tool to filter features based on attribute values.

## Troubleshooting

*   **Data Loading Errors:** Ensure that the geodatabase file is not corrupted and that you have sufficient permissions to access it.
*   **Performance Issues:** Large geodatabases can be slow to load and display. Try limiting the number of layers displayed or using a faster computer.
*   **Symbology Problems:** If layer symbology does not appear correctly, check the map projection settings and ensure that the data is in a supported coordinate system.
