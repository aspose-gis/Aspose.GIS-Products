JSON (JavaScript Object Notation) is een open standaard bestandsformaat voor het delen van data dat leesbare tekst gebruikt om data op te slaan en over te dragen. JSON bestanden worden opgeslagen met de .json extensie. JSON vereist minder formattering en is een goed alternatief voor XML. JSON is afgeleid van JavaScript, maar is een taal onafhankelijk data formaat. De generatie en parsing van JSON wordt ondersteund door veel moderne programmeertalen. application/json is het media type dat gebruikt wordt voor JSON.
