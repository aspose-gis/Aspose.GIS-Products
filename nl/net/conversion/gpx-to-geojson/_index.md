 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formats en OpenStreetMap. Het is een stand-alone .NET gebaseerde API en vereist geen GIS gebaseerde software zoals ArcGIS / ArcMap, QGIS etc.

        {{< blocks/products/pf/agp/about-file-text fileFormat="GPX" readMoreLink="https://docs.fileformat.com/gis/gpx/" >}}

De GPX extensie vertegenwoordigt GPS Exchange formaat voor de uitwisseling van GPS data tussen applicaties en web services op het internet. Het is een lichtgewicht XML formaat dat GPS data bevat, d.w.z. waypoints, routes en tracks die geïmporteerd en gelezen kunnen worden door meerdere programma's. GPX is open en wordt ondersteund door verschillende applicaties en GPS apparaten.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="GeoJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON is een JSON gebaseerd formaat dat ontworpen is om de geografische features met hun niet-spatiale attributen weer te geven. Dit formaat definieert verschillende JSON (JavaScript Object Notation) objecten en hoe ze samenkomen. JSON vertegenwoordigt collectieve informatie over de Geografische features, hun ruimtelijke extenties en eigenschappen.
