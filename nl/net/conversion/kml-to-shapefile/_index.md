 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formats en OpenStreetMap. Het is een stand-alone .NET gebaseerde API en vereist geen GIS gebaseerde software zoals ArcGIS / ArcMap, QGIS etc.

Het vertegenwoordigt Geografische informatie in de vorm van vector data om te gebruiken door Geographic Information Systems (GIS) applicaties. Het formaat is ontwikkeld als open specificaties om interoperabiliteit tussen ESRI en andere software producten te vergemakkelijken.
