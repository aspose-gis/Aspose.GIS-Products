        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON is een JSON gebaseerd formaat dat ontworpen is om de geografische kenmerken met hun niet-spatiale attributen weer te geven. Dit formaat definieert verschillende JSON (JavaScript Object Notation) objecten en hun manier van samenvoeging. JSON formaat vertegenwoordigt collectieve informatie over de Geografische kenmerken, hun ruimtelijke omvang en eigenschappen. Een object van dit bestand kan een geometrie (Punt, LineString, Polygon), een feature of verzameling van features aangeven. De features weerspiegelen adressen en plaatsen als punten, straten, hoofd wegen en grenzen als lijnen en landen, provincies en landregio's als polygonen. Door GEOJSON kunnen verschillende mobiele routing- en navigatieapplicaties de dekking van hun diensten weergeven. Een uitbreiding van GeoJSON is TopoJSON die kleiner in formaat is en geografische topologie codeert.

JSON (JavaScript Object Notation) is een open standaard bestandsformaat voor het delen van data dat leesbare tekst gebruikt om data op te slaan en over te dragen. JSON bestanden worden opgeslagen met de .json extensie. JSON vereist minder formattering en is een goed alternatief voor XML. JSON is afgeleid van JavaScript, maar is een taal onafhankelijk dataformaat. De generatie en parsing van JSON wordt ondersteund door veel moderne programmeertalen. application/json is het media type dat gebruikt wordt voor JSON.
