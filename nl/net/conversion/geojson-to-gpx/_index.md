 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formats en OpenStreetMap. Het is een standalone .NET gebaseerde API en vereist geen GIS gebaseerde software zoals ArcGIS / ArcMap, QGIS etc.

GeoJSON is een JSON gebaseerd formaat ontworpen om de geografische kenmerken met hun niet-spatiale attributen weer te geven. Dit formaat definieert verschillende JSON (JavaScript Object Notation) objecten en hun manier van verbinden. JSON vertegenwoordigt collectieve informatie over de Geografische kenmerken, hun ruimtelijke extenties en eigenschappen.

GPX extensie vertegenwoordigt GPS Exchange formaat voor uitwisseling van GPS data tussen applicaties en web services op het internet. Het is een lichtgewicht XML formaat dat GPS data bevat i.e. waypoints, routes en tracks om te importeren en te lezen door meerdere programma's. GPX is open en wordt ondersteund door verschillende applicaties en GPS apparaten.
