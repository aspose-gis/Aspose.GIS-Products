 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formats en OpenStreetMap.         {{< blocks/products/pf/agp/about-file-text fileFormat="GPX" readMoreLink="https://docs.fileformat.com/gis/gpx/" >}}

De GPX extensie staat voor GPS Exchange format voor de uitwisseling van GPS data tussen applicaties en web services op het internet. Het is een lichtgewicht XML formaat dat GPS data bevat, d.w.z. waypoints, routes en tracks die geïmporteerd en gelezen kunnen worden door meerdere programma's. GPX is open en wordt ondersteund door verschillende applicaties en GPS apparaten.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="CSV" readMoreLink="https://docs.fileformat.com/spreadsheet/csv/" >}}

Bestanden met de CSV (Comma Separated Values) extensie vertegenwoordigen platte tekstbestanden die records van data bevatten met komma gescheiden waarden. Elke regel in een CSV bestand is een nieuw record uit de set records die in het bestand zijn opgenomen. Dergelijke bestanden worden gegenereerd wanneer data overdracht bedoeld is vanuit één opslagsysteem naar een ander. Omdat alle applicaties records herkennen die door een komma worden gescheiden, wordt het importeren van dergelijke databestanden naar een database heel gemakkelijk gedaan.
