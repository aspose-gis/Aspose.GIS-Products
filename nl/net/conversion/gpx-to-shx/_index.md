 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formats en OpenStreetMap. Het is een op zichzelf staande .NET API en vereist geen GIS gebaseerde software zoals ArcGIS / ArcMap, QGIS enz.

Bestanden met de extensie GPX vertegenwoordigen het GPS Exchange formaat voor de uitwisseling van GPS data tussen applicaties en web services op internet. Het is een lichtgewicht XML bestandsformaat dat GPS data bevat, bijvoorbeeld waypoints, routes en tracks die geïmporteerd en gelezen kunnen worden door meerdere programma's. Het GPX bestandsformaat is open en wordt ondersteund door verschillende applicaties en GPS apparaten. GPS data uit dergelijke bestanden kan geladen worden voor weergave op mapping applicaties voor geo-spatiale doeleinden.
