 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formats en OpenStreetMap. Het is een standalone .NET gebaseerde API en vereist geen GIS gebaseerde software zoals ArcGIS / ArcMap, QGIS etc.

TopoJSON is een GeoJSON extensie die topologie codeert. JSON gebaseerd formaat ontworpen om de geografische kenmerken met hun niet-spatiale attributen weer te geven. Dit formaat definieert verschillende JSON (JavaScript Object Notation) objecten en hun manier van verbinden. JSON formaat vertegenwoordigt collectieve informatie over de Geografische kenmerken, hun ruimtelijke extenties en eigenschappen.

SHP is de bestands extensie voor een van de belangrijkste bestandstypen die worden gebruikt voor de weergave van ESRI Shapefile. Het vertegenwoordigt Geospatiale informatie in de vorm van vector data om te gebruiken door Geographic Information Systems (GIS) applicaties. Het formaat is ontwikkeld als open specificaties om interoperabiliteit tussen ESRI en andere software producten te vergemakkelijken.
