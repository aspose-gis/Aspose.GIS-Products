 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formats en OpenStreetMap. Het is een standalone .NET gebaseerde API en vereist geen GIS gebaseerde software zoals ArcGIS / ArcMap, QGIS etc.

SHP is de bestands extensie voor een van de belangrijkste bestandstypen die worden gebruikt voor de weergave van ESRI Shapefile. Het vertegenwoordigt Geografische informatie in de vorm van vector data om te worden gebruikt door Geographic Information Systems (GIS) applicaties. Het formaat is ontwikkeld als open specificaties om interoperabiliteit tussen ESRI en andere software producten te vergemakkelijken.

KML (Keyhole Markup Language) bevat geografische informatie in XML notatie. KML kan worden geopend in Geographic Information System (GIS) applicaties, mits deze het ondersteunen. Veel applicaties zijn begonnen met het bieden van ondersteuning voor KML formaat nadat het is overgenomen als internationale standaard.
