        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON is een JSON gebaseerd formaat ontworpen om de geografische features met hun niet-spatiale attributen weer te geven. Dit formaat definieert verschillende JSON (JavaScript Object Notation) objecten en hun manier van samenvoeging. JSON formaat vertegenwoordigt collectieve informatie over de Geografische features, hun ruimtelijke extenties en eigenschappen. Een object van dit bestand kan een geometrie (Punt, LijnString, Polygon), een feature of verzameling van features aangeven. De features weerspiegelen adressen en plaatsen als punten, straten, hoofd wegen en grenzen als lijn strings en landen, provincies en landregio's als polygonen. Door GeoJSON kunnen verschillende mobiele routing- en navigatie applicaties de dekking van hun diensten weergeven. Een uitbreiding van GeoJSON is TopoJSON die kleiner in formaat is en geografische topologie codeert.
