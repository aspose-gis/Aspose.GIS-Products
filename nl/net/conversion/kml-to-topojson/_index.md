 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formats en OpenStreetMap. KML (Keyhole Markup Language) bevat geografische informatie in XML notatie. KML kan worden geopend in Geographic Information System (GIS) applicaties, mits deze het ondersteunen. Veel applicaties zijn begonnen met de ondersteuning van KML formaat nadat het is overgenomen als internationale standaard.

        {{< blocks/products/pf/agp/about-file-text fileFormat="TopoJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

TopoJSON is een GeoJSON extensie die topologie codeert. JSON gebaseerd formaat ontworpen om de geografische kenmerken met hun niet-spatiale attributen weer te geven. Dit formaat definieert verschillende JSON (JavaScript Object Notation) objecten en hun manier van verbinden. JSON formaat vertegenwoordigt collectieve informatie over de Geografische kenmerken, hun ruimtelijke extenties en eigenschappen.
