 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formats en OpenStreetMap. JSON (JavaScript Object Notation) is een open standaard bestandsformaat voor het delen van data dat leesbare tekst gebruikt om data op te slaan en over te dragen. JSON bestanden worden opgeslagen met de .json extensie. JSON vereist minder formattering en is een goed alternatief voor XML. JSON is afgeleid van JavaScript, maar is een taal-onafhankelijk dataformaat. De generatie en parsing van JSON wordt ondersteund door veel moderne programmeertalen. application/json is het media type dat gebruikt wordt voor JSON.
