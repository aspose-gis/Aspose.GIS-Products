 Aspose.GIS voor .NET is een GIS data manipulatie en conversie API. Het ondersteunt volledig het lezen, schrijven en converteren van bekende GIS data formaten zoals ESRI Shapefiles, GeoJSON, TopoJSON, ESRI Geodatabase, Geography Markup Language, Google Earth, GPS Exchange Format, MapInfo Formaten en OpenStreetMap. Het is een standalone .NET gebaseerde API en vereist geen GIS gebaseerde software zoals ArcGIS / ArcMap, QGIS etc.

MapInfo TAB Format is een vector data formaat voor MapInfo software. Het is ontwikkeld en gereguleerd door de MapInfo Corporation als een propriëtair formaat.

        {{< blocks/products/pf/agp/about-file-text fileFormat="GPX" readMoreLink="https://docs.fileformat.com/gis/gpx/" >}}

GPX extensie vertegenwoordigt GPS Exchange formaat voor uitwisseling van GPS data tussen applicaties en web services op het internet. Het is een lichtgewicht XML formaat dat GPS data bevat i.e. waypoints, routes en tracks om te importeren en te lezen door meerdere programma's. GPX is open en wordt ondersteund door verschillende applicaties en GPS apparaten.
