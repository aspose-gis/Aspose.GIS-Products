## Introduction

This document provides an index of the databases used by Netviewer.  It includes information on the purpose of each database, its location, and the tables it contains.

## Database Index

### `main` Database

*   **Purpose:** This is the primary database for Netviewer. It stores all of the core data used by the application, including device configurations, network topologies, and alert history.
*   **Location:** `/opt/netviewer/data/main.gdb`
*   **Tables:**
    *   `devices` - Stores information about devices in the network.
    *   `networks` - Stores information about networks in the network.
    *   `alerts` - Stores historical alert data.
    *   `users` - Stores user account information.
    *   `roles` - Stores role definitions for user access control.

### `archive` Database

*   **Purpose:** This database is used to store archived data from the `main` database.  This allows for long-term storage of historical data without impacting the performance of the primary database.
*   **Location:** `/opt/netviewer/data/archive.gdb`
*   **Tables:** (Mirrors tables from the `main` database)

## Table Details

### `devices` Table

*   **Description:** Contains information about network devices.
*   **Columns:**
    *   `id` - Unique identifier for the device.
    *   `hostname` - The hostname of the device.
    *   `ip_address` - The IP address of the device.
    *   `device_type` - The type of device (e.g., router, switch, server).
    *   `location` - The physical location of the device.

### `networks` Table

*   **Description:** Contains information about network segments or logical networks.
*   **Columns:**
    *   `id` - Unique identifier for the network.
    *   `name` - The name of the network.
    *   `subnet` - The subnet address for the network.
    *   `description` - A description of the network.

### `alerts` Table

*   **Description:** Stores historical alert data generated by Netviewer.
*   **Columns:**
    *   `id` - Unique identifier for the alert.
    *   `device_id` - The ID of the device that triggered the alert.
    *   `timestamp` - The time the alert was generated.
    *   `severity` - The severity level of the alert (e.g., critical, warning, informational).
    *   `message` - A description of the alert.

### `users` Table

*   **Description:** Stores user account information for accessing Netviewer.
*   **Columns:**
    *   `id` - Unique identifier for the user.
    *   `username` - The username for logging into Netviewer.
    *   `password_hash` - A hashed version of the user's password.
    *   `email` - The user’s email address.

### `roles` Table

*   **Description:** Defines roles with specific permissions within Netviewer.
*   **Columns:**
    *   `id` - Unique identifier for the role.
    *   `name` - The name of the role (e.g., administrator, operator, viewer).
    *   `permissions` - A list of permissions associated with the role.

## Database Maintenance

Regular database maintenance is recommended to ensure optimal performance and data integrity.  This includes:

*   **Archiving:** Periodically archive older data from the `main` database to the `archive` database.
*   **Vacuuming:** Run vacuum operations to reclaim disk space and optimize query performance.
*   **Index Maintenance:** Rebuild or reorganize indexes as needed.

## Troubleshooting

If you encounter any issues with the databases, consult the Netviewer documentation or contact support for assistance.
