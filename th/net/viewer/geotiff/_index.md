## Introduction

The GeoTIFF viewer allows you to visualize and interact with GeoTIFF raster datasets directly in your web browser. It provides a user-friendly interface for exploring geospatial data without the need for specialized GIS software.

## Features

*   **Interactive Map Display:** Pan, zoom, and rotate the map view to explore different areas of interest.
*   **Raster Data Visualization:** Render GeoTIFF rasters with various color palettes and display options.
*   **Metadata Support:** View metadata associated with the GeoTIFF file, including spatial reference information and band descriptions.
*   **Band Selection:** Choose which bands to display for multi-band imagery.
*   **Contrast Stretching:** Adjust contrast levels to enhance visual clarity.
*   **Coordinate System Transformation:** Reproject data on-the-fly to different coordinate systems.
*   **Measurement Tools:** Measure distances and areas directly on the map.

## Usage

1.  **Loading Data:** Drag and drop a GeoTIFF file onto the viewer or use the "Load" button to select a file from your computer.
2.  **Navigation:** Use the mouse wheel to zoom in and out, click and drag to pan the map, and right-click to rotate the view.
3.  **Band Control:** Select the desired bands from the band selection dropdown menu.
4.  **Contrast Adjustment:** Adjust the contrast stretch settings using the provided sliders.

## Technical Details

The GeoTIFF viewer is built using [OpenLayers](https://openlayers.org/) and [GeoJSON](https://geojson.org/). It supports a wide range of GeoTIFF formats and coordinate systems.

## Troubleshooting

*   **File Loading Errors:** Ensure that the file is a valid GeoTIFF format and that it is not corrupted.
*   **Display Issues:** Check your browser's console for any JavaScript errors. Try clearing your browser cache and cookies.
*   **Performance Problems:** Large GeoTIFF files may require significant processing time. Consider using smaller tiles or reducing the display resolution.
