## Introduction

The Esri ASCII Viewer is a tool that allows you to visualize and interact with raster data stored in ASCII text files. It's particularly useful for working with elevation data, satellite imagery, and other types of geospatial information represented as grids of numbers.

## Features

*   **Data Visualization:** Displays ASCII raster data as an image.
*   **Interactive Exploration:** Zoom, pan, and rotate the view to examine different areas of the data.
*   **Color Mapping:** Apply color schemes to represent data values visually.
*   **Contour Generation:** Create contour lines from elevation data.
*   **Data Export:** Save images or contour data in various formats.

## Usage

1.  **Load Data:** Use the "Open" button to load an ASCII text file containing raster data.
2.  **Adjust Settings:** Configure display settings such as color scheme, contrast, and zoom level.
3.  **Explore Data:** Navigate through the data using the mouse or keyboard controls.
4.  **Export Results:** Save images or contour data for further analysis or presentation.

## Supported File Formats

The Esri ASCII Viewer supports a wide range of ASCII text file formats, including:

*   Comma-separated values (CSV)
*   Space-separated values
*   Tab-delimited files
*   Custom formats
