## Introduction

The shapefile viewer allows you to view and interact with shapefiles directly in your browser. It supports a wide range of vector data formats, including points, lines, polygons, and rasters.

## Features

*   View shapefiles in your browser
*   Support for various vector data formats (points, lines, polygons)
*   Zoom and pan functionality
*   Attribute table display
*   Feature styling based on attribute values
*   Customizable map layers
*   Geospatial analysis tools

## Usage

1.  Open the shapefile viewer in your browser.
2.  Load a shapefile using the "File" menu or by dragging and dropping it onto the viewer.
3.  Explore the data by zooming, panning, and selecting features.
4.  View attribute values in the attribute table.
5.  Customize map layers to highlight specific features.

## Supported Formats

*   Shapefile (.shp)
*   GeoJSON (.geojson)
*   KML (.kml)
*   GPX (.gpx)
