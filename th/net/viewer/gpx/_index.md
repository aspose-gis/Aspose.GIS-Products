## GPX Viewer

The GPX Viewer allows you to view and interact with GPX files directly in the browser.

### Features

*   View GPS tracks, routes, and waypoints
*   Display data on a map
*   Filter and search for specific features
*   Export data in various formats

### Usage

1.  Drag and drop a GPX file onto the viewer.
2.  The GPX data will be loaded and displayed on the map.
3.  Use the controls to zoom, pan, and interact with the data.

### Supported GPX Features

*   Tracks
*   Routes
*   Waypoints
*   Extensions (limited support)

### Limitations

*   Large GPX files may take time to load.
*   Complex extensions may not be fully supported.
*   The viewer is intended for viewing and basic interaction only. Editing capabilities are limited.

## ตัวอย่างการใช้งาน

สามารถลากและวางไฟล์ GPX ลงในโปรแกรมดูได้โดยตรง ข้อมูลจะถูกโหลดและแสดงบนแผนที่ คุณสามารถใช้ปุ่มควบคุมเพื่อซูม แพน และโต้ตอบกับข้อมูลได้

## การสนับสนุนรูปแบบ GPX

*   เส้นทาง
*   เส้นทางการเดิน
*   จุดอ้างอิง
*   ส่วนขยาย (รองรับแบบจำกัด)

## ข้อจำกัด

*   ไฟล์ GPX ขนาดใหญ่อาจใช้เวลาในการโหลดนาน
*   ส่วนขยายที่ซับซ้อนอาจไม่ได้รับการสนับสนุนอย่างเต็มที่
*   โปรแกรมดูนี้มีวัตถุประสงค์เพื่อการดูและการโต้ตอบขั้นพื้นฐานเท่านั้น ความสามารถในการแก้ไขมีจำกัด
