## Overview

The MapInfo tab provides access to MapInfo files and allows you to view them within the viewer.

## Features

*   Open MapInfo files
*   View data in a table format
*   Zoom to features
*   Identify features

## Opening a MapInfo File

To open a MapInfo file, click the "Open" button in the toolbar and select a `.tab` file. The file will then load into the viewer.

## Viewing Data

Once a MapInfo file is loaded, you can view the data in a table format by clicking the "View Data" button. This will open a table with all of the attributes for each feature in the file.

## Zooming to Features

You can zoom to a specific feature in the MapInfo file by right-clicking on the feature and selecting "Zoom To".

## Identifying Features

To identify a feature, simply click on it. A popup window will appear with information about the feature.

## Troubleshooting

If you are having trouble opening or viewing MapInfo files, make sure that you have the latest version of the viewer installed. Also, make sure that the file is not corrupted.
