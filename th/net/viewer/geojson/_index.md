## Introduction

This application allows you to view and interact with GeoJSON data on a map. You can load GeoJSON files from your computer or from a URL.

## Features

*   Load GeoJSON files from local disk
*   Load GeoJSON data from URLs
*   Zoom and pan the map
*   View feature properties in a popup window
*   Filter features based on their properties
*   Style features using custom styles

## Usage

1.  **Loading Data:**
    *   To load a GeoJSON file from your computer, click the "Load File" button and select the file you want to open.
    *   To load GeoJSON data from a URL, enter the URL in the "URL" field and click the "Load" button.

2.  **Navigation:**
    *   Use the mouse wheel or trackpad to zoom in and out of the map.
    *   Click and drag the map to pan around.

3.  **Feature Inspection:**
    *   Click on a feature to view its properties in a popup window.

4.  **Filtering:**
    *   Use the filter controls to display only features that meet certain criteria.

5.  **Styling:**
    *   Customize the appearance of features using the style options.

## Troubleshooting

If you encounter any problems, please check the following:

*   Make sure your GeoJSON file is valid. You can use an online validator to check for errors.
*   Ensure that the URL you are using is correct and accessible.
*   Check your browser's developer console for any error messages.
