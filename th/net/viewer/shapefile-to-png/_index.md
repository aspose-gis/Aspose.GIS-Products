## Convert Shapefiles to PNG Images

This viewer allows you to convert shapefiles (.shp) into Portable Network Graphics (.png) images.  It's a simple tool for visualizing geospatial data without needing complex GIS software.

### How it Works

The application reads the shapefile and renders its geometry on an image canvas. You can control the rendering process through various parameters, such as zoom level, color scheme, and background color. The resulting PNG image is then displayed and available for download.

### Usage Instructions

1.  **Upload Shapefile:** Drag and drop your `.shp` file into the designated area or use the "Choose File" button to select it from your computer.
2.  **Adjust Parameters (Optional):** Modify the zoom level, color scheme, and background color to customize the appearance of the rendered image.
3.  **Generate Image:** Click the "Generate PNG" button to start the conversion process.
4.  **Download Image:** Once the image is generated, a download link will appear. Click it to save the PNG file to your computer.

### Parameters

*   **Zoom Level:** Controls the scale of the map displayed in the image. Higher values zoom in closer to the data.
*   **Color Scheme:** Select from a variety of predefined color schemes to apply to the features in the shapefile.
*   **Background Color:** Set the background color of the image.

### Troubleshooting

*   **File Size Limits:**  Large shapefiles may take longer to process or exceed file size limits. Try simplifying your data or splitting it into smaller files.
*   **Unsupported Shapefile Types:** The viewer supports standard shapefile formats. If you encounter errors, ensure your shapefile is properly formatted.
*   **Rendering Issues:** If the image doesn't render correctly, try adjusting the zoom level and color scheme.
