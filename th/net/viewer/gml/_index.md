## GML Viewer

The GML Viewer allows you to view and interact with Geographic Markup Language (GML) files.

### Features

*   View GML data in a map interface
*   Query features based on attributes
*   Display feature properties
*   Support for various GML versions

### Usage

1.  Open the GML Viewer application.
2.  Load a GML file using the "File" -> "Open" menu option.
3.  The GML data will be displayed in the map interface.
4.  Use the navigation tools to pan and zoom the map.
5.  Select features on the map to view their properties in the attribute panel.

### Supported GML Versions

*   GML 2.1.2
*   GML 3.1.1
*   GML 3.2.1

### ข้อมูลเพิ่มเติม

ตัวแสดงผล GML ช่วยให้คุณดูและโต้ตอบกับไฟล์ Geographic Markup Language (GML) ได้

#### คุณสมบัติ

*   ดูข้อมูล GML ในอินเทอร์เฟซแผนที่
*   สอบถามข้อมูลตามแอตทริบิวต์
*   แสดงคุณสมบัติของข้อมูล
*   รองรับเวอร์ชัน GML ที่หลากหลาย

#### วิธีใช้งาน

1.  เปิดแอปพลิเคชันตัวแสดงผล GML
2.  โหลดไฟล์ GML โดยใช้ตัวเลือกเมนู "ไฟล์" -> "เปิด"
3.  ข้อมูล GML จะถูกแสดงในอินเทอร์เฟซแผนที่
4.  ใช้เครื่องมือนำทางเพื่อเลื่อนและซูมแผนที่
5.  เลือกคุณสมบัติบนแผนที่เพื่อดูคุณสมบัติของพวกเขาในแผงคุณลักษณะ

#### เวอร์ชัน GML ที่รองรับ

*   GML 2.1.2
*   GML 3.1.1
*   GML 3.2.1
