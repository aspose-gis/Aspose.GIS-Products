## Overview

This application allows you to convert GeoJSON data into a PNG image. You can customize the appearance of the map, including the basemap, zoom level, and markers.

## Features

*   Convert GeoJSON data to PNG images
*   Customize basemaps
*   Adjust zoom levels
*   Add custom markers
*   Download generated images

## Usage

1.  **Input GeoJSON Data:** Provide a valid GeoJSON file as input.
2.  **Configure Options:** Adjust the map settings, such as basemap, zoom level, and marker styles.
3.  **Generate PNG:** Click the "Generate" button to create the PNG image.
4.  **Download Image:** Download the generated PNG image for use in your projects.

## Configuration Options

*   **Basemap:** Select from a variety of basemaps provided by Mapbox.
*   **Zoom Level:** Adjust the zoom level to focus on specific areas of interest.
*   **Markers:** Add custom markers to highlight important locations on the map.
*   **Output Size:** Specify the desired width and height of the output PNG image.

## Troubleshooting

*   **Invalid GeoJSON:** Ensure that the input GeoJSON file is valid and well-formed.
*   **Mapbox API Key:** Make sure you have a valid Mapbox API key configured in the application settings.
*   **Image Generation Errors:** Check the console for any error messages related to image generation.
