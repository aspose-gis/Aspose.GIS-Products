## Overview ##

<p>The TopoJSON Viewer is a tool for visualizing and interacting with TopoJSON data.</p>

## Features ##

*   Display TopoJSON features on a map.
*   Support for various styling options, such as color, size, and labels.
*   Interactive zooming and panning.
*   Ability to query features by attribute.
*   Export map images in different formats.

## Usage ##

1.  Load a TopoJSON file using the "Load Data" button.
2.  Select a layer from the dropdown menu.
3.  Customize the styling options as desired.
4.  Zoom and pan the map to explore the data.
5.  Query features by attribute using the search bar.
6.  Export a map image in your preferred format.

## Data Sources ##

*   [Natural Earth](https://www.naturalearthdata.com/)
*   [TopoJSON Collection](https://geojson.io/topojson)

## ข้อมูลภาพรวม ##

<p>TopoJSON Viewer เป็นเครื่องมือสำหรับแสดงและโต้ตอบกับข้อมูล TopoJSON</p>

## คุณสมบัติ ##

*   แสดงคุณลักษณะ TopoJSON บนแผนที่
*   รองรับตัวเลือกการจัดรูปแบบต่างๆ เช่น สี ขนาด และป้ายกำกับ
*   ซูมและการแพนแบบอินเทอร์แอคทีฟ
*   ความสามารถในการสอบถามคุณลักษณะตามแอตทริบิวต์
*   ส่งออกรูปภาพแผนที่ในรูปแบบต่างๆ

## วิธีใช้งาน ##

1.  โหลดไฟล์ TopoJSON โดยใช้ปุ่ม "Load Data"
2.  เลือกเลเยอร์จากเมนูแบบดรอปดาวน์
3.  ปรับแต่งตัวเลือกการจัดรูปแบบตามต้องการ
4.  ซูมและแพนแผนที่เพื่อสำรวจข้อมูล
5.  สอบถามคุณลักษณะตามแอตทริบิวต์โดยใช้แถบค้นหา
6.  ส่งออกรูปภาพแผนที่ในรูปแบบที่คุณต้องการ
