## Overview

This application allows you to convert shapefiles into JPEGs. It's a simple and efficient way to visualize spatial data without needing complex GIS software.

## Features

*   **Simple Interface:** Easy-to-use controls for selecting input files and configuring output settings.
*   **Shapefile Support:** Handles various shapefile formats, including points, lines, and polygons.
*   **JPEG Output:** Generates high-quality JPEG images of your spatial data.
*   **Customization Options:** Adjust rendering parameters like color, line width, and font size.

## Usage

1.  **Select Shapefile:** Choose the shapefile you want to convert using the file selection dialog.
2.  **Configure Settings:** Set desired output options such as image resolution, background color, and layer visibility.
3.  **Generate JPEG:** Click the "Convert" button to create a JPEG image of your shapefile data.

## Requirements

*   .NET Framework 4.7 or later
*   GDAL/OGR (for shapefile reading) - *Ensure GDAL libraries are accessible in your system path.*

## Troubleshooting

*   **"Unable to open shapefile" error:** Verify that the selected file is a valid shapefile and that you have the necessary permissions to access it.
*   **Image rendering issues:** Experiment with different rendering settings to optimize image quality.
*   **GDAL not found:** Make sure GDAL libraries are installed and added to your system's PATH environment variable.
