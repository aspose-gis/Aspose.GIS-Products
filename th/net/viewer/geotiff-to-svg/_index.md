## Overview

This application converts GeoTIFF images into Scalable Vector Graphics (SVG) format. It allows users to visualize and interact with raster data in a vector environment, enabling further analysis and manipulation.

## Features

*   **GeoTIFF Input:** Supports various GeoTIFF formats.
*   **SVG Output:** Generates high-quality SVG files suitable for web display and printing.
*   **Customization Options:** Allows users to adjust color palettes, contrast, and other visual parameters.
*   **Interactive Zoom & Pan:** Provides interactive zoom and pan capabilities within the SVG viewer.
*   **Metadata Extraction:** Extracts and displays GeoTIFF metadata information.

## Usage

1.  **Input File:** Provide a valid GeoTIFF file as input.
2.  **Conversion Process:** The application processes the GeoTIFF data and generates an SVG representation.
3.  **Output File:** Download the generated SVG file for further use.

## Technical Details

*   **Programming Language:** C#
*   **Libraries Used:** GDAL, NetTopologySuite
*   **Platform:** Windows (.NET)
*   **Dependencies:** Requires .NET runtime environment.

## Troubleshooting

*   **Invalid GeoTIFF File:** Ensure the input file is a valid GeoTIFF format.
*   **Memory Issues:** Large GeoTIFF files may require significant memory resources. Consider using smaller tiles or reducing image resolution.
*   **Rendering Problems:** Verify that your web browser supports SVG rendering.
