## Introduction

NetViewer is a web application for viewing and interacting with geospatial data. It provides a user-friendly interface for exploring maps, performing spatial analysis, and creating custom visualizations.

## Features

*   **Map Viewing:** Display various map layers, including vector tiles, raster images, and WMS/WFS services.
*   **Spatial Analysis:** Perform basic spatial operations such as buffering, intersection, and union.
*   **Custom Visualizations:** Create custom charts and graphs to visualize geospatial data.
*   **Data Export:** Export data in various formats, including GeoJSON, KML, and Shapefile.
*   **User Authentication:** Secure access to data with user authentication.

## Getting Started

1.  **Installation:** Download the NetViewer installation package from [https://www.example.com/netviewer](https://www.example.com/netviewer).
2.  **Configuration:** Configure the application settings, including database connection and map server URLs.
3.  **Deployment:** Deploy the application to a web server.
4.  **Access:** Access the NetViewer interface through a web browser.

## Usage

*   **Zooming and Panning:** Use the mouse wheel or touch gestures to zoom in and out of the map. Drag the map to pan around.
*   **Feature Selection:** Click on features to view their attributes.
*   **Attribute Editing:** Edit feature attributes directly within the application.
*   **Querying:** Perform spatial queries to find features that meet specific criteria.

## Supported Data Formats

NetViewer supports a wide range of geospatial data formats, including:

*   GeoJSON
*   KML
*   Shapefile
*   WMS
*   WFS
*   Raster Images (e.g., GeoTIFF)

## คุณสมบัติ

*   **การดูแผนที่:** แสดงเลเยอร์แผนที่ต่างๆ รวมถึงเวกเตอร์ไทล์ รูปภาพ raster และบริการ WMS/WFS
*   **การวิเคราะห์เชิงพื้นที่:** ดำเนินการปฏิบัติการเชิงพื้นที่ขั้นพื้นฐาน เช่น การบัฟเฟอร์ การตัดกัน และการรวมกัน
*   **การสร้างภาพการแสดงผลแบบกำหนดเอง:** สร้างแผนภูมิและกราฟแบบกำหนดเองเพื่อแสดงข้อมูลทางภูมิศาสตร์
*   **การส่งออกข้อมูล:** ส่งออกข้อมูลในรูปแบบต่างๆ รวมถึง GeoJSON, KML และ Shapefile
*   **การยืนยันตัวตนผู้ใช้:** จำกัดสิทธิ์การเข้าถึงข้อมูลด้วยการยืนยันตัวตนผู้ใช้
