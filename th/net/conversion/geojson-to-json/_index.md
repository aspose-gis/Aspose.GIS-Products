GeoJSON เป็นรูปแบบตาม JSON ที่ออกแบบมาเพื่อแสดงคุณสมบัติทางภูมิศาสตร์พร้อมกับแอตทริบิวต์ที่ไม่ใช่เชิงพื้นที่ รูปแบบนี้กำหนดออบเจกต์ JSON ต่างๆ และวิธีการเข้าร่วมกัน รูปแบบ JSON แสดงข้อมูลโดยรวมเกี่ยวกับคุณสมบัติทางภูมิศาสตร์ ขอบเขตเชิงพื้นที่ และคุณสมบัติ ออบเจ็กต์ของไฟล์นี้อาจบ่งบอกถึงรูปทรงเรขาคณิต (จุด เส้นตรง รูปหลายเหลี่ยม) คุณสมบัติ หรือชุดของคุณสมบัติ คุณสมบัติสะท้อนถึงที่อยู่และสถานที่ในรูปแบบจุด ถนนสายหลักและพรมแดนในรูปแบบเส้นตรง และประเทศ จังหวัด และภูมิภาคที่ดินในรูปแบบรูปหลายเหลี่ยม การใช้ GeoJSON แอปพลิเคชันการกำหนดเส้นทางและการนำทางบนมือถือต่างๆ สามารถระบุขอบเขตของบริการได้ อ่านเพิ่มเติม
