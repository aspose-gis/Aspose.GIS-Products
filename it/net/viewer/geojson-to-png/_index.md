## GeoJSON to PNG Viewer

This application allows you to convert GeoJSON data into a PNG image. You can customize the appearance of the map, including the basemap, markers, and labels.

### Features

*   Convert GeoJSON data to PNG images
*   Customize the basemap
*   Add markers for specific locations
*   Add labels to features
*   Control the output resolution

### Usage

1.  **Prepare your GeoJSON data:** Make sure your GeoJSON file is valid and contains the data you want to visualize.
2.  **Upload your GeoJSON file:** Use the file upload button to select your GeoJSON file.
3.  **Configure the map settings:** Adjust the basemap, markers, labels, and resolution as desired.
4.  **Generate the PNG image:** Click the "Generate" button to create the PNG image.
5.  **Download the PNG image:** Once the image is generated, you can download it using the download button.

### Configuration Options

*   **Basemap:** Select a basemap from the available options.
*   **Markers:** Add markers for specific locations in your GeoJSON data. You can customize the marker color and size.
*   **Labels:** Add labels to features in your GeoJSON data. You can choose which attributes to display as labels.
*   **Resolution:** Control the resolution of the output PNG image. Higher resolutions will result in larger file sizes.

### Troubleshooting

*   **Invalid GeoJSON file:** Make sure your GeoJSON file is valid and well-formed. Use a GeoJSON validator to check for errors.
*   **No data displayed:** Check that your GeoJSON data contains features with geometry.
*   **Image generation failed:** Try reducing the resolution or simplifying your GeoJSON data.
