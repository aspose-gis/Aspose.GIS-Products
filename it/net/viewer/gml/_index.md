## GML Viewer

The GML Viewer is a web application that allows users to view and interact with Geographic Markup Language (GML) files. It provides a user-friendly interface for exploring geospatial data, including features, attributes, and relationships.

### Features

*   **Support for various GML formats:** The viewer supports a wide range of GML dialects, ensuring compatibility with different datasets.
*   **Interactive map display:** Users can pan, zoom, and rotate the map to explore the data from different perspectives.
*   **Feature information:** Clicking on a feature displays its attributes in a pop-up window.
*   **Attribute filtering:** Users can filter features based on their attribute values.
*   **Data download:** The viewer allows users to download the GML data in various formats.

### Usage

1.  **Load GML file:** Click the "Load" button and select a GML file from your computer.
2.  **Explore the map:** Use the mouse or keyboard to pan, zoom, and rotate the map.
3.  **View feature information:** Click on a feature to view its attributes in the pop-up window.
4.  **Filter data:** Use the attribute filters to display only features that meet specific criteria.
5.  **Download data:** Click the "Download" button to download the GML data in various formats.

### Supported GML Formats

*   Simple Feature Collection
*   Coordinate Reference Systems
*   Feature Styling
*   Time Stamps
*   Geometry Collections

## Visualizzatore GML

Il Visualizzatore GML è un'applicazione web che consente agli utenti di visualizzare e interagire con i file Geographic Markup Language (GML). Fornisce un'interfaccia intuitiva per esplorare dati geospaziali, inclusi elementi, attributi e relazioni.

### Funzionalità

*   **Supporto per vari formati GML:** Il visualizzatore supporta un'ampia gamma di dialetti GML, garantendo la compatibilità con diversi set di dati.
*   **Visualizzazione interattiva della mappa:** Gli utenti possono spostare, ingrandire e ruotare la mappa per esplorare i dati da diverse prospettive.
*   **Informazioni sull'elemento:** Cliccando su un elemento vengono visualizzati i suoi attributi in una finestra pop-up.
*   **Filtraggio degli attributi:** Gli utenti possono filtrare gli elementi in base ai valori dei loro attributi.
*   **Download dei dati:** Il visualizzatore consente agli utenti di scaricare i dati GML in vari formati.

### Utilizzo

1.  **Carica file GML:** Clicca sul pulsante "Carica" e seleziona un file GML dal tuo computer.
2.  **Esplora la mappa:** Usa il mouse o la tastiera per spostare, ingrandire e ruotare la mappa.
3.  **Visualizza le informazioni sull'elemento:** Clicca su un elemento per visualizzare i suoi attributi nella finestra pop-up.
4.  **Filtra i dati:** Usa i filtri degli attributi per visualizzare solo gli elementi che soddisfano criteri specifici.
5.  **Scarica i dati:** Clicca sul pulsante "Download" per scaricare i dati GML in vari formati.

### Formati GML Supportati

*   Simple Feature Collection
*   Coordinate Reference Systems
*   Feature Styling
*   Time Stamps
*   Geometry Collections
