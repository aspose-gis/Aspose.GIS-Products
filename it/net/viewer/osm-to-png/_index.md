## Overview

The OSM to PNG Viewer is a web application that allows users to convert OpenStreetMap (OSM) data into static images. It provides a user-friendly interface for configuring rendering parameters and generating customized map tiles.

## Features

*   **Dynamic Rendering:** Generate PNG images from OSM data based on user-defined settings.
*   **Customizable Parameters:** Control tile size, zoom level, output format, and other rendering options.
*   **User-Friendly Interface:** Simple and intuitive controls for easy operation.
*   **OpenStreetMap Integration:** Seamlessly utilizes OpenStreetMap data for map generation.

## Usage

1.  **Input Data:** Provide the URL of an OSM file or a tile server endpoint.
2.  **Configuration:** Adjust rendering parameters such as zoom level, tile size, and output format.
3.  **Generation:** Click the "Generate" button to create the PNG image.
4.  **Download:** Download the generated image for offline use.

## Configuration Options

*   **Zoom Level:** Specifies the magnification of the map. Higher values provide more detail.
*   **Tile Size:** Determines the dimensions (width and height) of the output image in pixels.
*   **Output Format:** Selects the desired image format (e.g., PNG, JPEG).
*   **Rendering Style:** Choose from predefined rendering styles or customize your own.
