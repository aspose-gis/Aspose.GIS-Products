## Convertitore SHP in PNG

Questo strumento ti permette di convertire i file shapefile (.shp) in immagini PNG.  È utile per visualizzare dati geografici o creare anteprime di mappe.

### Come usare

1.  Carica il tuo file SHP.
2.  Specifica le impostazioni desiderate (scala, colori, ecc.).
3.  Clicca sul pulsante "Converti".
4.  Scarica l'immagine PNG generata.

### Opzioni

*   **Scala:** Determina la dimensione dell'immagine risultante.
*   **Colori:** Permette di personalizzare i colori dei simboli e delle etichette.
*   **Legenda:** Includere o escludere la legenda nella mappa.
*   **Sfondo:** Scegli il colore dello sfondo della mappa.

### Esempio

Supponiamo che tu abbia un file shapefile chiamato `confini.shp` contenente i confini delle province italiane. Puoi usare questo strumento per creare un'immagine PNG di questa mappa, con una scala appropriata e colori personalizzati.  L'immagine risultante può essere utilizzata in presentazioni, report o siti web.

### Note

*   Il formato shapefile è un formato di file geografico ampiamente utilizzato.
*   Le immagini PNG sono adatte per la visualizzazione su schermi e la stampa.
*   Questo strumento supporta una varietà di formati di shapefile, inclusi punti, linee e poligoni.
*   Per risultati ottimali, assicurati che il tuo file SHP sia correttamente georeferenziato.

### Risoluzione dei problemi

*   **Immagine vuota:** Assicurati che il file SHP contenga dati validi e che la scala sia appropriata.
*   **Colori errati:** Verifica le impostazioni dei colori e assicurati che corrispondano ai tuoi requisiti.
*   **Errore di conversione:** Controlla che il file SHP non sia corrotto o incompleto.
