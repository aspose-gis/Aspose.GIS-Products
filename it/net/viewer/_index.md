## Introduzione

NetViewer è un'applicazione web per la visualizzazione di dati geospaziali. Permette agli utenti di esplorare e interagire con mappe, immagini e altri dati geografici direttamente nel loro browser.

## Caratteristiche Principali

*   **Visualizzazione Interattiva:** Ingrandisci, rimpicciolisci, ruota e sposta le mappe per una navigazione intuitiva.
*   **Supporto Multi-Formato:** Visualizza vari formati di dati geospaziali come GeoJSON, Shapefile, raster e altro ancora.
*   **Strumenti di Misurazione:** Calcola distanze, aree e coordinate direttamente sulla mappa.
*   **Overlay Personalizzabili:** Aggiungi layer personalizzati per visualizzare informazioni aggiuntive.
*   **Ricerca Geospaziale:** Trova posizioni specifiche inserendo indirizzi o coordinate.
*   **Condivisione Semplice:** Condividi le tue mappe e i tuoi risultati con altri tramite link URL.

## Installazione

1.  Clona il repository: `git clone [repository url]`
2.  Installa le dipendenze: `npm install`
3.  Costruisci l'applicazione: `npm run build`
4.  Distribuisci i file nella cartella `dist` su un server web.

## Utilizzo

1.  Apri NetViewer nel tuo browser web.
2.  Carica dati geospaziali utilizzando la funzione "Carica Dati".
3.  Esplora la mappa e utilizza gli strumenti disponibili per analizzare i dati.
4.  Salva le tue mappe personalizzate per un utilizzo futuro.
