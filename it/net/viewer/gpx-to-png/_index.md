## Convertitore da GPX a PNG

Questo strumento ti permette di convertire file GPX in immagini PNG.

### Come funziona

Il processo è semplice:

1.  Carica il tuo file GPX.
2.  Specifica le impostazioni desiderate (dimensioni dell'immagine, zoom, ecc.).
3.  Clicca sul pulsante "Converti".
4.  Scarica l'immagine PNG generata.

### Funzionalità

*   Supporto per diversi formati di file GPX.
*   Personalizzazione delle dimensioni e dello zoom dell'immagine.
*   Anteprima in tempo reale del risultato.
*   Download facile dell'immagine PNG.

### Esempi di utilizzo

*   Creazione di mappe personalizzate per attività all'aperto.
*   Condivisione dei tuoi percorsi GPS con amici e familiari.
*   Documentazione delle tue avventure.

### Note

*   Le dimensioni massime del file GPX sono limitate a 10 MB.
*   L'immagine PNG generata avrà una risoluzione massima di 2048x2048 pixel.
