## MapInfo Tab

The MapInfo tab provides access to MapInfo specific functionality within the viewer.

### Toolbar

The toolbar contains the following buttons:

*   **Select by Attributes:** Opens a dialog allowing you to select features based on their attribute values.
*   **Identify:** Identifies the feature at the cursor location and displays its attributes in a table.
*   **Zoom to Feature:** Zooms the view to the selected feature.
*   **Show Labels:** Toggles the display of labels for the current layer.

### Context Menu

Right-clicking on a feature opens a context menu with the following options:

*   **Identify:** Displays the attributes of the selected feature.
*   **Zoom to Feature:** Zooms the view to the selected feature.
*   **Open Attribute Table:** Opens the attribute table for the layer containing the selected feature.
*   **Go to Record:** Jumps to the corresponding record in the data source.

### Properties

The properties panel allows you to configure the behavior of the MapInfo tab.

*   **Attribute Filtering:** Enables or disables attribute filtering for the current layer.
*   **Labeling:** Configures the labeling options for the current layer.
*   **Zoom Behavior:** Controls how the view zooms when zooming to a feature.
