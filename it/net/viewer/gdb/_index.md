## Introduction

The GDB Viewer is a tool that enables you to browse and interact with geodatabase files (.gdb). It provides a graphical interface for exploring the contents of a GDB, including feature classes, tables, rasters, and other spatial data.

## Features

*   **Browse Geodatabases:** Easily open and navigate through different geodatabase files.
*   **Explore Contents:** View a hierarchical structure of all elements within the GDB.
*   **Preview Data:** Display sample records from feature classes and tables.
*   **Spatial Visualization:** Visualize spatial data on a map canvas (requires configuration).
*   **Metadata Access:**  View metadata associated with each element in the GDB.

## Usage

1.  **Open a Geodatabase:** Use the "Open" button to select a .gdb file.
2.  **Navigate Contents:** Expand nodes in the content tree to explore the different elements within the geodatabase.
3.  **Preview Data:** Select a feature class or table and click the "Preview" button to view a sample of its data.
4.  **Spatial Visualization (Optional):** Configure the map canvas with appropriate basemaps and coordinate systems to visualize spatial data.

## Configuration

The GDB Viewer can be configured to customize its behavior and appearance. Available configuration options include:

*   **Basemap Selection:** Choose a basemap for spatial visualization.
*   **Coordinate System:** Set the default coordinate system for map projections.
*   **Data Display Settings:** Adjust data display properties such as symbology and labeling.

## Troubleshooting

*   **Unable to Open Geodatabase:** Ensure that the .gdb file is not corrupted and that you have the necessary permissions to access it.
*   **Spatial Visualization Issues:** Verify that the map canvas is properly configured with a basemap and coordinate system.
*   **Data Preview Errors:** Check for any data type mismatches or invalid values in the feature class or table.
