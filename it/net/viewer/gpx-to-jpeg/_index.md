## GPX to JPEG Converter

This tool converts GPX files into JPEGs, allowing you to visualize your GPS data as images.

### Features

*   Convert GPX files to JPEGs
*   Adjustable image resolution
*   Customizable map markers
*   Support for multiple coordinate systems

### Usage

1.  Place your GPX file in the `gpx` directory.
2.  Run the converter tool.
3.  The JPEG image will be generated in the `output` directory.

### Configuration

The converter can be configured using a configuration file. The configuration file allows you to customize the following settings:

*   Image resolution
*   Map markers
*   Coordinate system
