## Introduction

Shapefiles are a popular geospatial file format used to store vector data. This viewer allows you to visualize and interact with shapefiles directly in your browser.

## Features

*   **Display Shapefiles:** Load and display shapefiles containing points, lines, and polygons.
*   **Zoom and Pan:** Navigate the map by zooming in/out and panning.
*   **Attribute Data:** View attribute data associated with each feature.
*   **Feature Styling:** Customize the appearance of features based on their attributes.
*   **Data Filtering:** Filter features based on specific attribute values.

## Usage

1.  **Load Shapefile:** Drag and drop a shapefile (``.shp``) onto the viewer or use the "Load" button to select one from your computer.
2.  **Explore Data:** Use the zoom and pan controls to explore the data.
3.  **View Attributes:** Click on a feature to view its attribute data in the table below the map.
4.  **Style Features:** Adjust the styling options (color, size, opacity) to customize the appearance of the features.

## Supported Shapefile Contents

The viewer supports shapefiles containing the following geometry types:

*   Points
*   Lines
*   Polygons

It also supports attribute data stored in a corresponding database file (``.dbf``).

## Troubleshooting

*   **Shapefile Not Loading:** Ensure that all necessary files for the shapefile (``.shp``, ``.shx``, ``.dbf``) are present and in the same directory.
*   **Attribute Data Missing:** Verify that the database file (``.dbf``) is properly associated with the shapefile.
*   **Rendering Issues:** Try adjusting the styling options or simplifying the geometry of the features.
