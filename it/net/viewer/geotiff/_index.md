## GeoTIFF Viewer

The GeoTIFF Viewer is a web application that allows you to view and interact with GeoTIFF files. It provides features such as zooming, panning, measuring distances, and displaying metadata.

### Features

*   **Zooming and Panning:** Easily navigate through the image by zooming in and out, and panning across the map.
*   **Metadata Display:** View essential information about the GeoTIFF file, including spatial reference, data type, and creation date.
*   **Distance Measurement:** Measure distances between points on the map using the measurement tool.
*   **Coordinate Lookup:** Determine the geographic coordinates of any location on the image by clicking on it.
*   **Customizable Color Palettes:** Adjust the color palette to enhance visualization and highlight specific features.

### Usage

1.  **Loading a GeoTIFF file:** Drag and drop a GeoTIFF file onto the viewer, or use the "Load" button to select a file from your computer.
2.  **Navigation:** Use the mouse wheel to zoom in and out, and click and drag to pan across the image.
3.  **Metadata Inspection:** Click the "Metadata" button to view detailed information about the GeoTIFF file.
4.  **Measurement:** Select the "Measure" tool to measure distances between points on the map. Click two or more points to define the measurement line.
5.  **Coordinate Lookup:** Click on any location in the image to display its geographic coordinates.

### Technical Details

*   **Programming Language:** JavaScript
*   **Libraries:** Leaflet, GeoTIFF-Web
*   **Supported GeoTIFF Formats:** All standard GeoTIFF formats are supported.
*   **Browser Compatibility:** Compatible with modern web browsers, including Chrome, Firefox, Safari, and Edge.

### Troubleshooting

*   **File Loading Issues:** Ensure that the GeoTIFF file is not corrupted and is in a supported format.
*   **Performance Problems:** Large GeoTIFF files may require significant processing time. Try reducing the image resolution or using a faster computer.
*   **Display Errors:** If you encounter any display errors, try updating your web browser to the latest version.
