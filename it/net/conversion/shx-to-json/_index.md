JSON (JavaScript Object Notation) è un formato di file standard aperto per la condivisione dei dati che utilizza testo leggibile dall'uomo per archiviare e trasmettere i dati. I file JSON sono archiviati con l'estensione .json. JSON richiede meno formattazione ed è una buona alternativa a XML. JSON deriva da JavaScript ma è un formato di dati indipendente dal linguaggio. La generazione e l'analisi di JSON sono supportate da molti linguaggi di programmazione moderni. application/json è il tipo di media utilizzato per JSON.
