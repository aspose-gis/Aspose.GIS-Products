GeoJSON은 지리적 특징과 비 공간 속성을 나타내기 위해 설계된 JSON 기반 형식입니다. 이 형식은 다양한 JSON (JavaScript Object Notation) 객체와 결합 방식을 정의합니다. JSON 형식은 지리적 특징, 공간 범위 및 속성에 대한 집합 정보를 나타냅니다. 이 파일의 개체는 점, 선 문자열, 다각형과 같은 기하 도형을 나타낼 수 있으며, 특징은 주소와 장소를 점으로, 도로와 경계를 선 문자열로, 국가, 지방 및 토지 지역을 다각형으로 나타냅니다. GeoJSON을 사용하면 다양한 모바일 라우팅 및 탐색 애플리케이션이 서비스 범위를 표시할 수 있습니다. TopoJSON은 크기가 더 작고 지리 공간 위상 관계를 인코딩하는 GeoJSON의 확장입니다.

JSON (JavaScript Object Notation)은 데이터를 공유하기 위한 개방형 표준 파일 형식으로, 사람이 읽을 수 있는 텍스트를 사용하여 데이터를 저장하고 전송합니다. JSON 파일은 .json 확장자로 저장됩니다. JSON은 서식이 적고 XML의 좋은 대안입니다. JSON은 JavaScript에서 파생되었지만 언어에 의존하지 않는 데이터 형식입니다. 많은 최신 프로그래밍 언어가 JSON 생성 및 구문 분석을 지원합니다. application/json은 JSON에 사용되는 미디어 유형입니다.
