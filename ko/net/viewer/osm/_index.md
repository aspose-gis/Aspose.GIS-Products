## 기능

*   **데이터 시각화:** OpenStreetMap 데이터를 다양한 스타일로 시각화합니다.
*   **탐색:** 지도를 확대, 축소하고 이동하여 관심 지역을 탐색합니다.
*   **쿼리:** 특정 속성을 가진 요소를 쿼리합니다.
*   **측정:** 거리와 면적을 측정합니다.
*   **데이터 다운로드:** 데이터를 다양한 형식으로 다운로드합니다.

## 사용법

1.  뷰어를 실행합니다.
2.  지도를 확대, 축소하고 이동하여 관심 지역을 찾습니다.
3.  다양한 기능을 사용하여 데이터를 시각화하고 탐색합니다.

## 추가 정보

*   [OpenStreetMap](https://www.openstreetmap.org/)
*   [Leaflet](https://leafletjs.com/)
