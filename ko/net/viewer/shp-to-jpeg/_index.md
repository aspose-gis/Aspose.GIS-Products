## Overview

This tool allows you to convert shapefiles (.shp) into JPEG images. It's useful for quickly visualizing and sharing geospatial data without requiring specialized GIS software.

## Features

*   Simple and easy-to-use interface
*   Supports various symbology options (color, size, outline)
*   Allows specifying output resolution and image quality
*   No installation required – runs directly in your web browser

## Usage

1.  **Upload SHP File:** Drag and drop your `.shp` file into the designated area or click "Choose File" to select it from your computer.
2.  **Configure Options (Optional):** Adjust symbology settings, resolution, and quality as desired.
3.  **Convert:** Click the "Convert" button to start the conversion process.
4.  **Download JPEG:** Once the conversion is complete, a download link for the resulting JPEG image will appear.

## Example

Let's say you have a shapefile containing data about parks in a city. You can use this tool to quickly generate a JPEG image of the park boundaries, which you can then easily share with others or include in a presentation.

## Troubleshooting

*   **File Size Limit:**  The maximum file size for SHP uploads is 50MB.
*   **Unsupported Features:** Complex shapefiles with advanced symbology may not render correctly.
*   **Browser Compatibility:** This tool is compatible with modern web browsers (Chrome, Firefox, Safari, Edge).
