## Overview

This viewer allows you to view and interact with GeoTIFF files directly in your web browser. It supports various features such as zooming, panning, and measuring distances.

## Features

*   **Zooming and Panning:** Easily navigate through the image by zooming in and out, and panning across the map.
*   **Metadata Display:** View metadata information associated with the GeoTIFF file, such as spatial reference, data type, and creation date.
*   **Distance Measurement:** Measure distances between two points on the image.
*   **Coordinate Lookup:** Determine the geographic coordinates of a specific location on the image.
*   **Color Adjustment:** Adjust the color balance to enhance visibility.

## Usage

1.  **Load GeoTIFF File:** Drag and drop a GeoTIFF file onto the viewer, or use the "Open" button to select a file from your computer.
2.  **Navigate the Image:** Use the mouse wheel to zoom in and out, and click and drag to pan across the image.
3.  **View Metadata:** Click the "Metadata" tab to view information about the GeoTIFF file.
4.  **Measure Distance:** Click the "Measure" button, then click two points on the image to measure the distance between them.
5.  **Lookup Coordinates:** Click the "Coordinates" button, then click a location on the image to display its geographic coordinates.

## Supported GeoTIFF Formats

The viewer supports standard GeoTIFF formats, including:

*   Integer-based georeferenced images
*   Floating-point georeferenced images
*   Byte-aligned data
*   Big-endian and little-endian byte order

## Troubleshooting

If you encounter any issues while using the viewer, please refer to the following troubleshooting tips:

*   **File Size Limitations:** Large GeoTIFF files may take a long time to load or display. Try reducing the image resolution if possible.
*   **Unsupported Formats:** If the viewer does not support the format of your GeoTIFF file, you may need to convert it to a supported format using a GIS software package.
*   **Browser Compatibility:** The viewer is compatible with most modern web browsers. However, if you encounter any issues, try updating your browser to the latest version.
