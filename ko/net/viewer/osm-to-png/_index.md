## 개요

이 도구는 OpenStreetMap (OSM) 데이터를 PNG 이미지로 변환할 수 있습니다.  이를 통해 지리 정보를 시각적으로 표현하고 공유하기가 더 쉬워집니다.

## 사용법

1.  **데이터 준비:** OpenStreetMap 데이터를 추출합니다. 일반적으로 `.osm` 또는 `.pbf` 형식입니다.
2.  **변환 실행:** 도구를 사용하여 OSM 데이터를 PNG 이미지로 변환합니다. 필요한 매개변수를 지정해야 합니다 (예: 출력 파일 이름, 확대/축소 수준, 레이어).
3.  **결과 확인:** 생성된 PNG 이미지를 열고 내용이 예상대로 표시되는지 확인합니다.

## 매개변수

*   `--input`: 입력 OSM 데이터 파일 경로.
*   `--output`: 출력 PNG 이미지 파일 이름.
*   `--zoom`: 확대/축소 수준 (기본값: 10).
*   `--layer`: 사용할 레이어 (예: 도로, 건물, 수역).

## 예제

```bash
osm-to-png --input my_map.osm --output map.png --zoom 12 --layer roads
```

이 명령은 `my_map.osm` 파일을 사용하여 `map.png`라는 PNG 이미지를 생성합니다. 확대/축소 수준은 12이고, 도로 레이어가 사용됩니다.

## 추가 정보

*   **레이어:** 다양한 레이어를 사용하여 지리 정보를 시각적으로 표현할 수 있습니다.
*   **확대/축소:** 확대/축소를 조정하여 이미지의 디테일 수준을 변경할 수 있습니다.
*   **출력 형식:** PNG 외에 다른 이미지 형식으로도 변환할 수 있습니다 (예: JPEG, GIF).

## 문제 해결

*   **오류 메시지:** 오류 메시지가 표시되면 명령줄 인수를 다시 확인하고 올바르게 지정했는지 확인합니다.
*   **결과 품질:** 결과 이미지의 품질이 좋지 않으면 확대/축소 수준 또는 레이어를 조정해 봅니다.
*   **데이터 형식:** 입력 데이터 형식이 지원되는 형식인지 확인합니다.

## 참고 사항

*   OpenStreetMap 데이터는 Creative Commons Attribution-NonCommercial 라이선스에 따라 제공됩니다.
*   이 도구는 OpenStreetMap 데이터를 시각화하기 위한 하나의 방법일 뿐입니다. 다른 도구나 기술을 사용하여 동일한 결과를 얻을 수도 있습니다.
