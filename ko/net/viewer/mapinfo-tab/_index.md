## Overview
## 개요

The MapInfo tab provides access to MapInfo files and allows you to view and interact with the data.
지도 정보 탭은 MapInfo 파일에 접근하고 데이터를 보고 상호 작용할 수 있게 해줍니다.

## Supported Formats
## 지원되는 형식

*   `.tab`
*   `.map`
*   `.e00`
*   `.e01`
*   `.e02`
*   `.e03`
*   `.e04`
*   `.e05`
*   `.e06`
*   `.e07`
*   `.e08`
*   `.e09`
*   `.e10`

## Loading a MapInfo File
## MapInfo 파일 로드하기

To load a MapInfo file, click the "Open" button in the toolbar and select the desired `.tab`, `.map`, or `.e00` file.
MapInfo 파일을 로드하려면 도구 모음에서 "열기" 버튼을 클릭하고 원하는 `.tab`, `.map`, 또는 `.e00` 파일을 선택하세요.

## Displaying Data
## 데이터 표시하기

Once the MapInfo file is loaded, the data will be displayed in the map view.  You can pan and zoom to explore the data.
MapInfo 파일이 로드되면 데이터가 지도 보기에서 표시됩니다. 데이터를 탐색하려면 이동하고 확대/축소할 수 있습니다.

## Interacting with Data
## 데이터와 상호 작용하기

You can interact with the data by clicking on features in the map view.  This will display information about the feature in the attribute table.
지도 보기에서 피처를 클릭하여 데이터와 상호 작용할 수 있습니다. 그러면 속성 테이블에 피처 정보가 표시됩니다.

## Attribute Table
## 속성 테이블

The attribute table displays the attributes for each feature in the MapInfo file.  You can sort the attribute table by clicking on the column headers.
속성 테이블은 MapInfo 파일의 각 피처에 대한 속성을 표시합니다. 열 머리글을 클릭하여 속성 테이블을 정렬할 수 있습니다.

## Exporting Data
## 데이터 내보내기

You can export the data from the MapInfo file to a variety of formats, including:
MapInfo 파일에서 데이터를 다양한 형식으로 내보낼 수 있으며, 여기에는 다음이 포함됩니다.

*   CSV
*   Shapefile
*   GeoJSON

To export the data, click the "Export" button in the toolbar and select the desired format.
데이터를 내보내려면 도구 모음에서 "내보내기" 버튼을 클릭하고 원하는 형식을 선택하세요.
