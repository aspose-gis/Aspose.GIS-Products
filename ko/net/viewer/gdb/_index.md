## Overview

The GDB Viewer is a tool that allows you to explore and visualize geographic databases (GDBs). It provides a user-friendly interface for browsing tables, feature classes, rasters, and other spatial data within a GDB.

## Features

*   **Browse GDB Contents:** Easily navigate through the contents of a GDB, including tables, feature classes, rasters, and more.
*   **Visualize Spatial Data:** Display feature classes and raster datasets on a map canvas with customizable symbology.
*   **View Table Data:** Examine attribute data associated with feature classes in a tabular format.
*   **Spatial Queries:** Perform spatial queries to select features based on their location or relationship to other features.
*   **Attribute Filtering:** Filter feature class data based on attribute values.
*   **Zoom and Pan:** Zoom in and out of the map canvas and pan to different areas of interest.
*   **Identify Features:** Click on features to view their attributes and spatial information.

## Usage

1.  **Open a GDB:** Use the "Open" button to select a GDB file from your computer.
2.  **Explore Contents:** Browse the contents of the GDB in the "Contents" pane.
3.  **Visualize Data:** Double-click on feature classes or raster datasets to display them on the map canvas.
4.  **Interact with Map:** Use the zoom, pan, and identify tools to explore the spatial data.

## Supported Formats

The GDB Viewer supports the following GDB formats:

*   Esri File Geodatabase (.gdb)
*   ArcSDE Geodatabase
