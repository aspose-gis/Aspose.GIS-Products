## Introduction

The Shapefile Viewer is a web application that allows users to view and interact with shapefiles. It provides a user-friendly interface for exploring geospatial data directly in the browser.

## Features

*   **Display Shapefiles:** View various shapefile formats, including points, lines, polygons, and rasters.
*   **Interactive Map:** Pan, zoom, and identify features on an interactive map.
*   **Attribute Table:** Browse and filter feature attributes in a table format.
*   **Feature Information:** Display detailed information about selected features.
*   **Customizable Styling:** Adjust symbol appearance based on attribute values.
*   **Data Download:** Export data in various formats (e.g., GeoJSON, CSV).

## Usage

1.  **Load Shapefile:** Drag and drop a shapefile (.shp) onto the viewer or use the "Open" button to select it from your computer.
2.  **Explore Data:** Use the map controls to navigate and zoom into areas of interest. Click on features to view their attributes in the attribute table.
3.  **Customize View:** Adjust layer styles, symbolization, and basemaps to enhance visualization.

## Technical Details

*   **Supported Shapefile Formats:** ESRI Shapefile (points, lines, polygons, rasters)
*   **Programming Languages:** JavaScript, HTML, CSS
*   **Libraries:** Leaflet, jQuery
*   **Dependencies:** None

## Troubleshooting

*   **Shapefile Not Loading:** Ensure the shapefile is valid and all associated files (.shp, .shx, .dbf, .prj) are in the same directory.
*   **Performance Issues:** Large shapefiles may require more time to load and render. Try simplifying the data or using a basemap with less detail.
