## 개요

GML(Geography Markup Language)은 지리적 특징을 설명하기 위한 XML 기반 마크업 언어입니다. GML은 OGC(Open Geospatial Consortium)에서 개발되었으며, 다양한 GIS(Geographic Information System) 응용 프로그램에서 사용됩니다.

## GML 뷰어 기능

GML 뷰어는 GML 파일을 시각적으로 표시하고 분석할 수 있는 도구입니다. 다음 기능을 제공합니다.

*   GML 파일 로드 및 저장
*   지리적 특징의 시각적 표현
*   특징 속성 정보 표시
*   데이터 필터링 및 검색
*   측정 기능
*   지도 기반 탐색

## GML 뷰어 사용법

1.  GML 파일을 뷰어에 로드합니다.
2.  지리적 특징을 시각적으로 검사합니다.
3.  특징 속성 정보를 확인합니다.
4.  필요한 경우 데이터를 필터링하거나 검색합니다.
5.  측정 기능을 사용하여 거리를 측정합니다.
6.  지도 기반 탐색을 통해 지리적 영역을 탐색합니다.

## GML 뷰어 장점

*   GML 데이터 시각화 및 분석 용이성
*   데이터 품질 검증 지원
*   GIS 응용 프로그램과의 통합
*   사용자 친화적인 인터페이스
