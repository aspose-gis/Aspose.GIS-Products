## What is GML?
## GML Nedir?
GML (Geography Markup Language) is an XML-based encoding for geographic features. It's a standard format used to exchange geospatial data.
GML (Coğrafi Özellikler için Coğrafya İşaretleme Dili), coğrafi özellikler için XML tabanlı bir kodlama biçimidir. Uzamsal verilerin değişimi için kullanılan standart bir formattır.

## GML Viewer Features
## GML İzleyici Özellikleri
The GML viewer provides the following features:
GML izleyicisi aşağıdaki özellikleri sağlar:

*   View GML files
*   GML dosyalarını görüntüleme
*   Zoom and pan
*   Yakınlaştırma ve kaydırma
*   Identify features
*   Özellikleri belirleme
*   Attribute display
*   Nitelik gösterimi
*   Support for various GML versions
*   Çeşitli GML sürümleri desteği

## How to Use the GML Viewer
## GML İzleyici Nasıl Kullanılır
1.  Open the GML viewer.
2.  GML izleyicisini açın.
3.  Load a GML file using the "File" menu.
4.  "Dosya" menüsünü kullanarak bir GML dosyası yükleyin.
5.  Navigate and interact with the features in the GML file.
6.  GML dosyasındaki özellikler arasında gezinerek etkileşim kurun.
