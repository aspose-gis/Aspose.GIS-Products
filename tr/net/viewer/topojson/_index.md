## Introduction

The TopoJSON viewer is a tool for visualizing and interacting with TopoJSON data. It allows you to explore geographic features, zoom in on areas of interest, and query attributes associated with each feature.

## Features

*   **Interactive Map:** Pan and zoom around the map to explore different regions.
*   **Feature Highlighting:** Hover over features to see their attributes displayed in a sidebar.
*   **Attribute Filtering:** Filter features based on specific attribute values.
*   **Data Export:** Export selected features as GeoJSON or TopoJSON files.
*   **Customizable Styling:** Change the appearance of features using custom color schemes and styling rules.

## Usage

1.  **Load Data:** Provide a URL to a TopoJSON file or upload a local file.
2.  **Explore Map:** Use the mouse wheel to zoom in and out, and click and drag to pan around the map.
3.  **View Attributes:** Hover over features to see their attributes displayed in the sidebar.
4.  **Filter Data:** Use the attribute filters to narrow down the visible features.
5.  **Export Data:** Select features and export them as GeoJSON or TopoJSON files.

## Supported Formats

*   TopoJSON
*   GeoJSON

## Dependencies

*   [Leaflet](https://leafletjs.com/) - A JavaScript library for interactive maps.
*   [TopoJSON](https://topojson.org/) - A format for representing geographic data.
