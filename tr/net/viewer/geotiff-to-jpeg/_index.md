## Overview

This viewer allows you to convert a GeoTIFF file into a JPEG image. You can adjust the zoom level and color palette to customize the output.

## Usage

1.  **Upload GeoTIFF:** Drag and drop your GeoTIFF file onto the designated area or click "Choose File" to select it from your computer.
2.  **Adjust Settings (Optional):**
    *   **Zoom Level:** Modify the zoom level using the slider to focus on specific areas of interest.
    *   **Color Palette:** Select a color palette that best represents the data in your GeoTIFF file.
3.  **Convert:** Click the "Convert" button to initiate the conversion process.
4.  **Download JPEG:** Once the conversion is complete, download the resulting JPEG image.

## Supported File Types

*   GeoTIFF (.tif, .tiff)

## Limitations

*   Large GeoTIFF files may take longer to convert.
*   The color palette options are limited to those provided in the viewer.

## Troubleshooting

If you encounter any issues during the conversion process, please ensure that your GeoTIFF file is valid and not corrupted. Also, check your internet connection and try again later. If the problem persists, contact support for assistance.
