## Overview
## Genel Bakış
The MapInfo tab is available in the Viewer when viewing .tab files.
HaritaBilgisi sekmesi, .tab dosyalarını görüntülenirken Görüntüleyici'de mevcuttur. It provides access to MapInfo specific functionality.
MapInfo'ya özgü işlevlere erişim sağlar.

## Table Display
## Tablo Gösterimi
The table display shows the contents of the .tab file.
Tablo gösterimi, .tab dosyasının içeriğini gösterir. The columns are displayed with their names and data types.
Sütunlar adları ve veri türleriyle birlikte görüntülenir. You can sort the table by clicking on the column headers.
Tabloyu sütun başlıklarına tıklayarak sıralayabilirsiniz.

## Layer Information
## Katman Bilgisi
The layer information panel displays details about the current layer.
Katman bilgisi paneli, geçerli katman hakkında ayrıntıları görüntüler. This includes the layer name, data type, and number of records.
Bu, katman adı, veri türü ve kayıt sayısı gibi bilgileri içerir.

## Attribute Statistics
## Öznitelik İstatistikleri
The attribute statistics panel displays summary statistics for each attribute in the table.
Öznitelik istatistikleri paneli, tablodaki her öznitelik için özet istatistiklerini görüntüler. This includes the minimum, maximum, mean, and standard deviation.
Bu, minimum, maksimum, ortalama ve standart sapmayı içerir.

## SQL Query
## SQL Sorgusu
You can use the SQL query editor to run SQL queries against the .tab file.
SQL sorgu düzenleyicisini kullanarak .tab dosyasına karşı SQL sorguları çalıştırabilirsiniz. The results of the query are displayed in a table.
Sorgunun sonuçları bir tabloda görüntülenir.

## Export
## Dışa Aktarma
You can export the data from the .tab file to various formats, such as CSV and Shapefile.
.tab dosyasındaki verileri CSV ve Şekil Dosyası gibi çeşitli formatlara aktarabilirsiniz.
