## Overview

This viewer allows you to convert OpenStreetMap (OSM) data into static images. You can customize the appearance of the map, including the zoom level, size, and output format.

## Features

*   **Customizable Map Appearance:** Adjust zoom level, size, and other visual settings.
*   **Multiple Output Formats:** Generate PNG images in various resolutions.
*   **Easy to Use Interface:** Simple controls for creating your desired map image.
*   **Dynamic Rendering:**  Real-time preview of the generated image.

## Usage

1.  Enter the coordinates and zoom level for the area you want to view.
2.  Adjust the size and format of the output image.
3.  Click "Generate" to create the PNG image.
4.  Download the generated image.

## Parameters

*   **Latitude:** The latitude coordinate of the center of the map.
*   **Longitude:** The longitude coordinate of the center of the map.
*   **Zoom Level:** Determines how close in you are zoomed on the map (1-19).
*   **Width:** The width of the output image in pixels.
*   **Height:** The height of the output image in pixels.

## Example

To generate a PNG image of Istanbul at zoom level 12 with a size of 512x512 pixels:

*   Latitude: 41.0083
*   Longitude: 28.9784
*   Zoom Level: 12
*   Width: 512
*   Height: 512

## Troubleshooting

If you encounter any issues, please check the following:

*   Ensure that the latitude and longitude coordinates are valid.
*   Verify that the zoom level is within the acceptable range (1-19).
*   Confirm that the width and height values are positive integers.
