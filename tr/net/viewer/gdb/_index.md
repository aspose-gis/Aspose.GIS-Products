## Introduction

The GDB Viewer is a tool for viewing and interacting with geodatabases. It allows users to explore the contents of a GDB, view attribute tables, and perform basic spatial queries.

## Features

*   View table structures and data types
*   Browse feature classes and tables
*   Display attributes in tabular format
*   Perform simple spatial selections
*   Zoom and pan within the geodatabase extent

## Usage

1.  Open the GDB Viewer application.
2.  Select a GDB file to load.
3.  The viewer will display the contents of the selected GDB.
4.  Use the navigation tools to explore the data.

## Supported Geodatabase Types

*   File Geodatabases (.gdb)
*   Personal Geodatabases (.mdb)
*   Enterprise Geodatabases (via connection)
