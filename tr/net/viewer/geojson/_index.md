## Introduction

This application is a simple GeoJSON viewer that allows you to view and interact with GeoJSON data on a map.

Bu uygulama, harita üzerinde GeoJSON verilerini görüntülemenize ve etkileşim kurmanıza olanak tanıyan basit bir GeoJSON görüntüleyicidir.

## Features

*   View GeoJSON data on a map
*   Zoom and pan the map
*   Display popups with information about features
*   Filter features by attribute
*   Style features based on attributes
*   Support for various GeoJSON formats
*   Customizable appearance

Harita üzerinde GeoJSON verilerini görüntüleme
Haritayı yakınlaştırma ve kaydırma
Özellikler hakkında bilgi içeren açılır pencereleri görüntüleme
Özniteliklere göre özellikleri filtreleme
Özniteliklere göre özelliklerin stilini ayarlama
Çeşitli GeoJSON formatlarını destekleme
Özelleştirilebilir görünüm

## Usage

1.  Open the application
2.  Load a GeoJSON file using the "File" menu
3.  The GeoJSON data will be displayed on the map

Uygulamayı açın
"Dosya" menüsünü kullanarak bir GeoJSON dosyası yükleyin
GeoJSON verileri harita üzerinde görüntülenecektir

## Customization

The application can be customized by modifying the configuration file. The configuration file is located in the `config` directory.

Uygulama, yapılandırma dosyasını değiştirerek özelleştirilebilir. Yapılandırma dosyası `config` dizininde bulunur.
