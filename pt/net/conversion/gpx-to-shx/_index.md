Arquivos com extensão GPX representam o formato de troca GPS para intercâmbio de dados GPS entre aplicativos e serviços web na internet. É um formato XML leve que contém dados GPS, ou seja, pontos de referência, rotas e rastreamentos a serem importados e lidos por vários programas. O formato de arquivo GPX é aberto e é suportado por uma variedade de aplicativos e dispositivos GPS. Os dados GPS desses arquivos podem ser carregados para exibição em aplicativos de mapeamento para fins geoespaciais.
