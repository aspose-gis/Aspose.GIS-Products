        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON é um formato baseado em JSON projetado para representar os recursos geográficos com seus atributos não espaciais. Este formato define diferentes objetos JSON (JavaScript Object Notation) e sua forma de junção. O formato JSON representa informações coletivas sobre os recursos Geográficos, suas extensões espaciais e propriedades. Um objeto deste arquivo pode indicar uma geometria (Ponto, LineString, Polígono), um recurso ou coleção de recursos. Os recursos refletem endereços e lugares como pontos, ruas principais e estradas como strings de linha e países, províncias e regiões terrestres como polígonos. Usando o GeoJSON, diferentes aplicativos de roteamento e navegação móveis podem indicar a cobertura de seus serviços. Uma extensão do GeoJSON é TopoJSON que é menor em tamanho e codifica a topologia geoespacial.
