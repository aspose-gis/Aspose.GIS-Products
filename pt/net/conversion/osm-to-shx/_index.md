OpenStreetMap (OSM) é uma enorme coleção de informações geográficas voluntárias armazenadas em diferentes tipos de arquivos, usando diferentes esquemas de codificação para converter esses dados em bits e bytes. OSM é um esforço colaborativo para a criação de um mapa editável gratuito do mundo. A saída principal desse esforço colaborativo são dados geográficos em vez do próprio mapa. As restrições ao uso ou disponibilidade de informações geográficas em grande parte do mundo desencadeiam a necessidade de criar um OSM. Os dados disponíveis no OSM estão prontos para substituir o Google Maps para aplicações clássicas (Facebook, Craigslist etc.) e dados padrão para aplicações de receptores GPS. Embora a qualidade dos dados varie em todo o mundo, os dados OpenStreetMap podem ser convenientemente comparados com fontes de dados patenteadas.
