A extensão GPX representa o formato de troca GPS para a troca de dados GPS entre aplicativos e serviços da web na internet. É um formato XML leve que contém dados GPS, ou seja, pontos de referência, rotas e faixas para serem importados e lidos por vários programas. GPX é aberto e é suportado por uma variedade de aplicativos e dispositivos GPS.

        {{< blocks/products/pf/agp/about-file-text fileFormat="GeoJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON é um formato baseado em JSON projetado para representar os recursos geográficos com seus atributos não espaciais. Este formato define diferentes objetos JSON (Notação de Objeto JavaScript) e sua forma de junção. JSON representa uma coleção de informações sobre os recursos Geográficos, suas extensões espaciais e propriedades.
