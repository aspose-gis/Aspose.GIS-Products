A conversão pode ser feita com apenas uma linha de código ao usar o método
*VectorLayer.Convert*. Ele recebe 4 parâmetros conforme detalhado abaixo.

{{% /blocks/products/pf/agp/text %}}

1.  Um caminho de arquivo do tipo string para o arquivo MIF de origem
2.  Driver de origem para informar à API sobre o formato de entrada. Defina-o como Drivers.MapInfoInterchange
3.  O caminho do arquivo do tipo string para o arquivo de dados SHX de destino
4.  Driver de destino para especificar o formato de saída. Defina-o como Drivers.Shapefile
