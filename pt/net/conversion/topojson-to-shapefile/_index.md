TopoJSON é uma extensão GeoJSON que codifica a topologia. Formato baseado em JSON projetado para representar os recursos geográficos com seus atributos não espaciais. Este formato define diferentes objetos JSON (JavaScript Object Notation) e sua forma de junção. O formato JSON representa informações coletivas sobre os recursos Geográficos, suas extensões espaciais e propriedades.

SHP é a extensão de arquivo para um dos tipos de arquivo primários usados para representação de ESRI Shapefile. Ele representa informações Geoespaciais na forma de dados vetoriais a serem usados por aplicativos de Sistemas de Informações Geográficas (GIS). O formato foi desenvolvido como especificações abertas, a fim de facilitar a interoperabilidade entre ESRI e outros produtos de software.
