<p>
 Aspose.GIS for .NET permite que você converta Graus Decimais (DD) para unidades geoespaciais. Nossa biblioteca permite converter facilmente e rapidamente latitude e longitude para um formato de unidade desejado. Além disso, nossa biblioteca contém a possibilidade de extrair locais para um ponto de um texto.
</p>

<p>
 Aspose.GIS for .NET é projetado com simplicidade, desempenho, usabilidade e portabilidade em mente. Ele contém APIs para serem usadas com as plataformas .NET Framework e .NET Core, permitindo que você crie aplicativos multiplataforma com grande facilidade.
</p>
