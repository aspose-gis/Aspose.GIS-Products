## O que é USNG?

USNG (United States National Grid) é um sistema de grade para localizar lugares nos Estados Unidos. É semelhante a outros sistemas de grade, como o UTM (Universal Transverse Mercator), mas usa uma projeção diferente e zonas diferentes.

## Por que converter para USNG?

Existem várias razões pelas quais você pode querer converter coordenadas geográficas para USNG:

*   **Precisão:** O USNG é um sistema muito preciso, permitindo localizar lugares com precisão de alguns centímetros.
*   **Facilidade de uso:** O USNG é mais fácil de usar do que as coordenadas geográficas, especialmente para pessoas que não estão familiarizadas com o sistema de coordenadas.
*   **Compatibilidade:** O USNG é compatível com uma variedade de sistemas de informação geográfica (SIG) e outras aplicações.
