## About the GeoTIFF Viewer
## Sobre o Visualizador de GeoTIFF

The GeoTIFF Viewer is a web application that allows you to view and interact with GeoTIFF files directly in your browser. It provides features such as zooming, panning, and metadata display.
O Visualizador de GeoTIFF é uma aplicação web que permite visualizar e interagir com arquivos GeoTIFF diretamente no seu navegador. Ele oferece recursos como zoom, panorâmica e exibição de metadados.

## Features
## Características

*   **Zooming and Panning:** Navigate through the image with ease.
    **Zoom e Panorâmica:** Navegue pela imagem com facilidade.
*   **Metadata Display:** View information about the GeoTIFF file, such as spatial reference and data type.
    **Exibição de Metadados:** Visualize informações sobre o arquivo GeoTIFF, como referência espacial e tipo de dado.
*   **Color Manipulation:** Adjust color settings to enhance visualization.
    **Manipulação de Cores:** Ajuste as configurações de cores para melhorar a visualização.
*   **Legend Support:** Display legends for raster data.
    **Suporte a Legendas:** Exiba legendas para dados raster.
*   **Customizable Settings:** Configure the viewer to your preferences.
    **Configurações Personalizáveis:** Configure o visualizador de acordo com suas preferências.

## Usage
## Uso

1.  **Load a GeoTIFF file:** Drag and drop a GeoTIFF file onto the viewer or use the "Open File" button.
    **Carregue um arquivo GeoTIFF:** Arraste e solte um arquivo GeoTIFF no visualizador ou use o botão "Abrir Arquivo".
2.  **Explore the image:** Use the zoom and pan controls to navigate.
    **Explore a imagem:** Use os controles de zoom e panorâmica para navegar.
3.  **View metadata:** Click the "Metadata" button to see information about the file.
    **Visualize metadados:** Clique no botão "Metadados" para ver informações sobre o arquivo.

## Supported GeoTIFF Features
## Recursos GeoTIFF Suportados

*   Georeferenced imagery
    Imagens georreferenciadas
*   Multiple bands
    Múltiplas bandas
*   Internal and external color tables
    Tabelas de cores internas e externas
*   Compression (e.g., LZW, Deflate)
    Compressão (por exemplo, LZW, Deflate)

## Limitations
## Limitações

*   Large files may take time to load.
    Arquivos grandes podem demorar para carregar.
*   Complex GeoTIFF structures may not be fully supported.
    Estruturas GeoTIFF complexas podem não ser totalmente suportadas.
