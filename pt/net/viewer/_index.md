## Overview ##

The NetViewer is a web application that allows users to view and interact with geospatial data. It supports various data formats, including shapefiles, GeoJSON, KML, and WMS. The NetViewer can be used for a variety of purposes, such as displaying maps, performing spatial analysis, and creating custom visualizations.

## Features ##

*   Support for multiple data formats
*   Interactive map display
*   Spatial analysis tools
*   Customizable visualizations
*   User-friendly interface

## Installation ##

The NetViewer can be installed on any web server that supports Node.js. To install the NetViewer, follow these steps:

1.  Clone the repository from GitHub: `https://github.com/your-username/netviewer`
2.  Navigate to the root directory of the repository: `cd netviewer`
3.  Install the dependencies: `npm install`
4.  Build the application: `npm run build`
5.  Copy the contents of the `dist` directory to your web server.

## Usage ##

To use the NetViewer, simply open it in a web browser. The NetViewer will automatically load any data that is available on your web server. You can also manually add data by clicking the "Add Data" button and selecting a file from your computer.

## Configuration ##

The NetViewer can be configured using a variety of options. These options can be set in the `config.json` file. Some of the most common options are:

*   `mapCenter`: The center of the map.
*   `zoomLevel`: The initial zoom level of the map.
*   `dataSources`: An array of data sources to load when the NetViewer starts.

If you encounter any problems while using the NetViewer, please consult the troubleshooting guide in the documentation. You can also contact the developers for assistance.
