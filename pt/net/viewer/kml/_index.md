## What is KML?
linkTitle: O que é KML?

KML (Keyhole Markup Language) is an XML-based format for expressing geographic data. It's commonly used to display features like points, lines, polygons, images, and 3D models on a map.
linkTitle: KML (Linguagem de Marcação Keyhole) é um formato baseado em XML para expressar dados geográficos. É comumente usado para exibir recursos como pontos, linhas, polígonos, imagens e modelos 3D em um mapa.

## Using the KML Viewer
linkTitle: Usando o Visualizador de KML

The KML viewer allows you to open and interact with KML files directly in your browser. Here's how to use it:
linkTitle: O visualizador de KML permite abrir e interagir com arquivos KML diretamente no seu navegador. Veja como usá-lo:

1.  **Open a KML file:** Drag and drop a KML file onto the viewer, or use the "Open File" button to select one from your computer.
linkTitle: **Abrir um arquivo KML:** Arraste e solte um arquivo KML no visualizador ou use o botão "Abrir Arquivo" para selecionar um do seu computador.
2.  **Navigate the map:** Use your mouse or touch screen to pan and zoom around the map.
linkTitle: **Navegar no mapa:** Use o mouse ou a tela sensível ao toque para mover e ampliar o mapa.
3.  **View features:** Click on features in the KML file to see their details in the sidebar.
linkTitle: **Visualizar recursos:** Clique nos recursos do arquivo KML para ver seus detalhes na barra lateral.
4.  **Customize the view:** Adjust the display options, such as layer visibility and styling, using the controls in the toolbar.
linkTitle: **Personalizar a visualização:** Ajuste as opções de exibição, como visibilidade da camada e estilo, usando os controles na barra de ferramentas.

## Troubleshooting
linkTitle: Solução de Problemas

If you encounter any issues while using the KML viewer, here are some troubleshooting tips:
linkTitle: Se você encontrar algum problema ao usar o visualizador de KML, aqui estão algumas dicas para solucionar problemas:

*   **File size limits:** The viewer may have limitations on the size of KML files it can handle. Try splitting large files into smaller chunks.
linkTitle: **Limites de tamanho do arquivo:** O visualizador pode ter limitações no tamanho dos arquivos KML que ele pode lidar. Tente dividir arquivos grandes em partes menores.
*   **Unsupported features:** Some advanced KML features may not be fully supported by the viewer.
linkTitle: **Recursos não suportados:** Alguns recursos avançados de KML podem não ser totalmente suportados pelo visualizador.
*   **Browser compatibility:** Ensure that you are using a compatible web browser.
linkTitle: **Compatibilidade com o navegador:** Certifique-se de que você está usando um navegador da Web compatível.
