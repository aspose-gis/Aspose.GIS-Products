## Overview

This application allows you to convert OpenStreetMap (OSM) data into Portable Network Graphics (PNG) images. It provides a user-friendly interface for configuring rendering parameters and generating customized map visualizations.

## Features

*   **Dynamic Rendering:** Generate PNG images on the fly based on specified parameters.
*   **Customizable Parameters:** Control various aspects of the rendering process, including:
    *   Map extent (bounding box)
    *   Zoom level
    *   Tile size
    *   Rendering layers and styles
*   **User-Friendly Interface:**  Intuitive controls for easy configuration and image generation.
*   **OpenStreetMap Integration:** Leverages OpenStreetMap data for map visualization.

## Usage

1.  **Input Data:** The application utilizes OpenStreetMap data, which is freely available online. You do not need to provide your own OSM files.
2.  **Configuration:** Adjust the rendering parameters according to your desired output. Experiment with different settings to achieve the best results.
3.  **Image Generation:** Click the "Generate" button to create a PNG image based on the configured parameters.
4.  **Download:** Download the generated PNG image for use in your projects or presentations.

## Parameters

*   **Extent (Bounding Box):** Defines the geographical area to be rendered. Specify the minimum and maximum latitude and longitude values.
*   **Zoom Level:** Controls the level of detail displayed on the map. Higher zoom levels show more detail but require more processing power.
*   **Tile Size:** Determines the size of individual tiles used to compose the PNG image. Smaller tile sizes result in higher resolution images but increase file size.
*   **Rendering Layers:** Select which OSM features to display (e.g., roads, buildings, water).
*   **Rendering Styles:** Customize the appearance of rendered features (e.g., color, line width, font size).
