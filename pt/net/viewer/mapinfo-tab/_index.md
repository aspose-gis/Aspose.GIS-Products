## Overview

The MapInfo tab provides access to MapInfo-specific functionality within the viewer. It allows you to connect to MapInfo tables and display them as layers in the viewer.

## Connecting to a MapInfo Table

To connect to a MapInfo table:

1.  Click the "Add Layer" button on the toolbar.
2.  Select "MapInfo Table" from the list of layer types.
3.  Enter the path to the MapInfo table file in the "Table Path" field.
4.  Click "Connect".

## Displaying a MapInfo Table

Once connected, the MapInfo table will be displayed as a layer in the viewer. You can control the visibility and properties of the layer using the Layer Properties dialog.

## Supported Features

The MapInfo tab supports the following features:

*   Connecting to MapInfo tables
*   Displaying MapInfo tables as layers
*   Controlling the visibility and properties of MapInfo layers
*   Support for various MapInfo table formats

## Troubleshooting

If you are having trouble connecting to a MapInfo table, make sure that:

*   The path to the table file is correct.
*   The table file is not corrupted.
*   You have the necessary permissions to access the table file.
*   The MapInfo drivers are installed correctly.
