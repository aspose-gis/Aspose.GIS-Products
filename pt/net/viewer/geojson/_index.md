## About ##

O Visualizador GeoJSON é uma ferramenta para visualizar dados GeoJSON. Ele permite que você carregue arquivos GeoJSON e os exiba em um mapa interativo.

## Features ##

*   Visualização de dados GeoJSON
*   Suporte a várias fontes de dados GeoJSON
*   Mapas interativos
*   Personalização da aparência do mapa
*   Ferramentas de análise espacial

## Usage ##

Para usar o Visualizador GeoJSON, siga estas etapas:

1.  Carregue um arquivo GeoJSON.
2.  Selecione uma fonte de dados GeoJSON.
3.  Personalize a aparência do mapa (opcional).
4.  Visualize os dados no mapa.

## Supported Formats ##

O Visualizador GeoJSON suporta os seguintes formatos:

*   GeoJSON
*   Shapefile
*   KML

## Requirements ##

O Visualizador GeoJSON requer o seguinte:

*   Um navegador web moderno
*   JavaScript
*   Bibliotecas de mapeamento (por exemplo, Leaflet, OpenLayers)
