## Overview
Visão geral

The ArcGIS ASCII Viewer is a lightweight tool for viewing and interacting with ASCII raster datasets. It provides a simple interface for displaying data, performing basic analysis, and exporting results.

O Visualizador de ASCII do ArcGIS é uma ferramenta leve para visualizar e interagir com conjuntos de dados raster ASCII. Ele fornece uma interface simples para exibir dados, realizar análises básicas e exportar resultados.

## Features
Funcionalidades

*   **Data Visualization:** Display ASCII raster datasets in a variety of color schemes and display options.
    Visualização de Dados: Exibir conjuntos de dados raster ASCII em vários esquemas de cores e opções de exibição.
*   **Basic Analysis:** Perform basic analysis such as calculating statistics, creating profiles, and measuring distances.
    Análise Básica: Realizar análises básicas, como calcular estatísticas, criar perfis e medir distâncias.
*   **Data Export:** Export data in various formats including CSV, GeoTIFF, and Esri Grid.
    Exportação de Dados: Exportar dados em vários formatos, incluindo CSV, GeoTIFF e Grade Esri.
*   **Customization:** Customize the viewer's appearance and behavior through configuration files.
    Personalização: Personalizar a aparência e o comportamento do visualizador por meio de arquivos de configuração.

## Getting Started
Começando

1.  **Installation:** Download and install the ArcGIS ASCII Viewer from the [Esri website](https://www.esri.com/).
    Instalação: Baixe e instale o Visualizador de ASCII do ArcGIS no site da Esri ([https://www.esri.com/](https://www.esri.com/)).
2.  **Data Loading:** Open the viewer and load an ASCII raster dataset using the "File" menu.
    Carregamento de Dados: Abra o visualizador e carregue um conjunto de dados raster ASCII usando o menu "Arquivo".
3.  **Visualization:** Adjust display settings such as color scheme, contrast, and brightness to optimize data visualization.
    Visualização: Ajuste as configurações de exibição, como esquema de cores, contraste e brilho, para otimizar a visualização dos dados.
4.  **Analysis:** Perform basic analysis tasks using the toolbar or menu options.
    Análise: Realize tarefas básicas de análise usando as opções da barra de ferramentas ou do menu.
5.  **Exporting Results:** Export data and analysis results in your desired format using the "File" menu.
    Exportação de Resultados: Exporte dados e resultados de análise no formato desejado usando o menu "Arquivo".

## Configuration
Configuração

The ArcGIS ASCII Viewer can be customized through configuration files located in the installation directory. These files allow you to modify settings such as default color schemes, data display options, and analysis parameters.

O Visualizador de ASCII do ArcGIS pode ser personalizado por meio de arquivos de configuração localizados no diretório de instalação. Esses arquivos permitem modificar configurações como esquemas de cores padrão, opções de exibição de dados e parâmetros de análise.

## Troubleshooting
Solução de problemas

*   **Data Loading Errors:** Ensure that the ASCII raster dataset is in a supported format and that the file path is correct.
    Erros ao Carregar Dados: Verifique se o conjunto de dados raster ASCII está em um formato suportado e se o caminho do arquivo está correto.
*   **Display Issues:** Adjust display settings such as color scheme, contrast, and brightness to resolve any visual artifacts or distortions.
    Problemas de Exibição: Ajuste as configurações de exibição, como esquema de cores, contraste e brilho, para resolver quaisquer artefatos ou distorções visuais.
*   **Analysis Errors:** Verify that the data is valid and that the analysis parameters are appropriate for the task at hand.
    Erros de Análise: Verifique se os dados são válidos e se os parâmetros de análise são apropriados para a tarefa em questão.
