## Overview {#overview}

The GML Viewer is a web application that allows users to visualize and interact with Geographic Markup Language (GML) data. It provides a user-friendly interface for exploring spatial information represented in GML format.

## Features {#features}

*   **Visualization:** Displays GML data on an interactive map.
*   **Data Exploration:** Allows users to zoom, pan, and identify features within the GML dataset.
*   **Attribute Inspection:** Provides access to attribute data associated with each feature.
*   **Querying:** Enables users to query the GML data based on specific criteria.
*   **Styling:** Supports custom styling of GML features using CSS or other styling languages.

## Usage {#usage}

1.  **Loading Data:** Load a GML file into the viewer using the "Load" button.
2.  **Navigation:** Use the zoom and pan controls to navigate the map.
3.  **Feature Inspection:** Click on a feature to view its attribute data in a pop-up window.
4.  **Querying Data:** Use the query form to filter features based on specific criteria.

## Supported GML Dialects {#supported-gml-dialects}

The GML Viewer supports various GML dialects, including:

*   Simple Feature GML
*   Complex Feature GML
*   Motion Feature GML

## Customization {#customization}

The GML Viewer can be customized to meet specific needs. Users can modify the styling, add custom controls, and integrate the viewer into other web applications.
