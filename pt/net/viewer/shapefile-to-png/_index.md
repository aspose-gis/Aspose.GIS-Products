## Introduction

This is a simple viewer that allows you to convert shapefiles (.shp) into Portable Network Graphics (.png) images. It's designed to be easy to use and provides basic functionality for visualizing geospatial data.

## Features

*   Convert Shapefiles to PNG Images: The core function of the viewer is to transform your shapefile data into a visual representation as a PNG image.
*   Simple Interface:  The user interface is straightforward, making it accessible even for those with limited technical expertise.
*   Basic Visualization: Provides a basic view of the shapefile's geometry.

## Usage

1.  **Input Shapefile:** Provide the path to your .shp file.
2.  **Output PNG File:** Specify the desired filename and location for the output .png image.
3.  **Run Conversion:** Initiate the conversion process, which will generate a PNG image representing the shapefile data.

## Technical Details

*   **Programming Language:** C#
*   **Libraries Used:** ESRI Shapefile Library (for reading shapefiles)
*   **Output Format:** PNG

## Limitations

*   **No Advanced Styling:** The viewer offers limited styling options for the output image.  It focuses on basic visualization rather than complex cartographic design.
*   **Single Layer Support:** Currently, it only supports single-layer shapefiles.
*   **Basic Functionality:** It's a simple tool and lacks advanced features found in full-fledged GIS software.
