## Introduction

This document provides an index of available GeoDatabase (GDB) viewers. Each viewer is designed to display and interact with specific types of GDB data.

## Available Viewers

### 1. Raster Data Viewer

*   **Description:** This viewer specializes in displaying raster datasets within a GDB. It supports various raster formats, including imagery, elevation models, and thematic maps.
*   **Features:**
    *   Zooming and panning capabilities for detailed exploration.
    *   Color palette customization to enhance visual interpretation.
    *   Legend display to understand data classification.
    *   Query functionality to retrieve pixel values at specific locations.

### 2. Vector Data Viewer

*   **Description:** This viewer is dedicated to displaying vector datasets, such as points, lines, and polygons, stored in a GDB. It's ideal for visualizing geographic features like roads, buildings, and land parcels.
*   **Features:**
    *   Symbolization options to represent different feature types with distinct symbols and colors.
    *   Attribute table display to view associated data for each feature.
    *   Selection tools to highlight specific features based on attribute values or spatial location.
    *   Measurement capabilities to calculate distances and areas.

### 3. Attribute Data Viewer

*   **Description:** This viewer focuses solely on displaying the attribute tables associated with GDB datasets. It allows users to browse, sort, and filter data without rendering any geographic features.
*   **Features:**
    *   Column sorting in ascending or descending order.
    *   Filtering based on specific attribute values.
    *   Data export to various formats (e.g., CSV, Excel).

### 4. 3D Data Viewer

*   **Description:** This viewer is designed for visualizing three-dimensional data stored within a GDB. It supports point clouds, TIN surfaces, and other 3D representations of geographic features.
*   **Features:**
    *   Perspective control to adjust viewing angle and orientation.
    *   Vertical exaggeration to enhance the appearance of elevation changes.
    *   Clipping planes to isolate specific areas of interest.

## Viewer Selection Guide

The choice of viewer depends on the type of data you want to explore:

*   For raster imagery and thematic maps, use the **Raster Data Viewer**.
*   For vector features like roads and buildings, use the **Vector Data Viewer**.
*   To examine attribute tables without geographic display, use the **Attribute Data Viewer**.
*   For 3D data visualization, use the **3D Data Viewer**.

## Troubleshooting
