## Introduction

This is a simple viewer for TopoJSON files. It allows you to view and interact with geographic data stored in the TopoJSON format.

## Features

*   View TopoJSON files
*   Zoom and pan
*   Support for different projections
*   Customizable styling

## Usage

1.  Open the viewer in your browser.
2.  Load a TopoJSON file using the "File" menu or by dragging and dropping it onto the viewer.
3.  Explore the data by zooming, panning, and interacting with the features.
