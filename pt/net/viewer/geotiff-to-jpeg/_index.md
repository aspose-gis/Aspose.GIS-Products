### Formato GeoTIFF

GeoTIFF (Tagged Image File Format) é um formato de arquivo para imagens raster georreferenciadas. Ele é amplamente utilizado em sistemas de informação geográfica (SIG) e outras aplicações que exigem informações geoespaciais. Os arquivos GeoTIFF podem conter várias bandas de dados, como imagens multiespectrais ou modelos de elevação digital.

### Formato JPEG

JPEG (Joint Photographic Experts Group) é um formato de arquivo para imagens fotográficas. Ele é amplamente utilizado na web e em outras aplicações onde o tamanho do arquivo é uma preocupação. Os arquivos JPEG são comprimidos usando uma perda de dados, o que significa que alguma informação é perdida durante a compressão. No entanto, a perda de qualidade geralmente não é perceptível para o olho humano.
