## Introduction
## Introdução

This tool converts GPX (GPS Exchange Format) files into SVG (Scalable Vector Graphics) format. This allows you to view your GPS data as a vector image, which can be easily zoomed and shared.
Esta ferramenta converte arquivos GPX (Formato de Troca de GPS) para o formato SVG (Gráficos Vetoriais Escaláveis). Isso permite visualizar seus dados de GPS como uma imagem vetorial, que pode ser facilmente ampliada e compartilhada.

## Usage
## Uso

1.  **Input GPX File:** Select the GPX file you want to convert.
    **Arquivo GPX de Entrada:** Selecione o arquivo GPX que deseja converter.
2.  **Conversion:** Click the "Convert" button to generate the SVG output.
    **Conversão:** Clique no botão "Converter" para gerar a saída SVG.
3.  **Output SVG File:** Download the generated SVG file.
    **Arquivo SVG de Saída:** Baixe o arquivo SVG gerado.

## Features
## Características

*   Supports GPX files with waypoints, routes, and tracks.
    Suporta arquivos GPX com pontos de referência, rotas e trilhas.
*   Generates high-quality SVG output.
    Gera saída SVG de alta qualidade.
*   Easy to use interface.
    Interface fácil de usar.
*   Customizable appearance (e.g., line color, thickness).
    Aparência personalizável (por exemplo, cor da linha, espessura).

## Limitations
## Limitações

*   Large GPX files may take longer to convert.
    Arquivos GPX grandes podem levar mais tempo para converter.
*   Complex routes with many points may result in a large SVG file.
    Rotas complexas com muitos pontos podem resultar em um arquivo SVG grande.

## Troubleshooting
## Solução de Problemas

*   **File Not Supported:** Ensure the file is a valid GPX file.
    **Arquivo Não Suportado:** Verifique se o arquivo é um arquivo GPX válido.
*   **Conversion Error:** Try reducing the size of the GPX file or simplifying the route.
    **Erro de Conversão:** Tente reduzir o tamanho do arquivo GPX ou simplificar a rota.
*   **SVG Output Issues:** Check your browser's SVG rendering capabilities.
    **Problemas com a Saída SVG:** Verifique as capacidades de renderização SVG do seu navegador.
