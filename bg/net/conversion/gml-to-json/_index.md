Geographic Markup Language (известен като GML) е XML-базиран формат, използван в GIS. GML е отворен обменен формат за географски транзакции в Интернет. Този формат е ориентиран към данни и структура.

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="JSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

JSON базиран формат, предназначен да представя географските характеристики с техните не-пространствени атрибути. Този формат определя различни JSON (JavaScript Object Notation) обекти и начина им на свързване. JSON представлява колективна информация за Географските характеристики, техните пространствени размери и свойства.
