KML (Keyhole Markup Language) съдържа геопространствена информация в XML нотация. KML може да бъде отворен в приложения за Географски Информационни Системи (GIS), ако те го поддържат. Много приложения са започнали да предоставят поддръжка за KML формат след като е приет като международен стандарт.

        {{< blocks/products/pf/agp/about-file-text fileFormat="GeoJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON е формат, базиран на JSON, предназначен за представяне на географски обекти с техните не-пространствени атрибути. Този формат определя различни JSON (JavaScript Object Notation) обекти и начина им на свързване. JSON представлява колективна информация за Географските обекти, техните пространствени граници и свойства.
