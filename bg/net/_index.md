    <h2 class="h2title">
     Един API за различни формати
    </h2>
    <p>
     Aspose.GIS се грижи за всички сложни детайли на файловите формати и ви предоставя чист и прост обектен модел за GIS данни. Можете да четете или съхранявате данни във файлове с универсален, форматно-независим код.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Четене на GIS данни от Shapefile - C#
     </h3>
     <pre><code class="cs">using (var layer = VectorLayer.Open(dir + "myDataFile.shp", Drivers.Shapefile))

{

    foreach (var feature in layer)

    {

        Console.WriteLine(feature.Geometry.AsText()); // отпечатва геометрията като WKT
        Console.WriteLine(feature.GetValue&lt;string&gt;("CITY_NAME")); // отпечатва стойност на атрибут
        Console.WriteLine(feature.GetValue&lt;DateTime&gt;("UPDATE_DAT")); 

    }

}</code></pre>
    </div>

    <p>

    <div class="codeblock" id="code">

      Рендиране на TopoJSON карта към SVG - C#

    map.Add(layer, style);

    map.Render(dir + "mymap.svg", Renderers.Svg);

}</code></pre>

   <div class="col-lg-12">
    <h2 class="h2title">
     Извършване на пространствен анализ
    </h2>
    <p>
     Aspose.GIS включва пълен набор от пространствени предикати, базирани на DE-9IM модела, който оценява топологичните отношения между обектите. Типични случаи са:
    </p>
    <ul>
     <li>
      Определете дали два обекта се припокриват
     </li>
     <li>
      Определете дали един обект пресича друг обект
     </li>
     <li>
      Намерете минимално разстояние между геометрия и друга геометрия
     </li>
     <li>
      Проверете дали геометрията на обект се самопресича
     </li>
     <li>
      Изчислете площта на геометрия
     </li>
    </ul>
    <p>
     Aspose.GIS ви позволява лесно да извършвате геометрични операции, като например:
    </p>
    <ul>
     <li>
      Създаване на буферна зона около геометрия
