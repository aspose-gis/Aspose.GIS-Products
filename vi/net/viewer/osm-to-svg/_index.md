## Overview

This tool converts OpenStreetMap (OSM) data into Scalable Vector Graphics (SVG) format. It allows users to visualize and interact with OSM data in a web browser.

## Features

*   Convert OSM data to SVG format
*   Zoom and pan the map
*   Display various layers of OSM data, such as roads, buildings, and landuse
*   Search for locations by name or coordinates
*   Customizable rendering options

## Usage

1.  Provide an OpenStreetMap (OSM) file in XML format.
2.  Configure rendering options as needed.
3.  Click the "Convert" button to generate the SVG output.

## Configuration Options

*   **Data Source:** The URL or local path to the OSM data file.
*   **Rendering Layers:** Select which layers of OSM data to display.
*   **Zoom Level:** Set the initial zoom level of the map.
*   **Color Scheme:** Choose a color scheme for rendering the map elements.

## Technical Details

The tool is built using JavaScript and Leaflet, an open-source mapping library. It utilizes a custom parsing algorithm to convert OSM data into SVG format.

## Troubleshooting

*   If the conversion fails, ensure that the OSM data file is valid XML.
*   Check the browser's developer console for any error messages.
*   Contact support if you encounter persistent issues.
