## Overview

This viewer allows you to convert OpenStreetMap data into JPEG images. It's a useful tool for creating custom maps and visualizations.

## Features

*   Convert OSM data to JPEGs
*   Customizable rendering options
*   Easy-to-use interface

## Usage

1.  **Input Data:** Provide an OpenStreetMap `.osm` file as input.
2.  **Rendering Options:** Configure the desired rendering style, including color schemes, label sizes, and layer visibility.
3.  **Output Image:** The viewer generates a JPEG image based on your settings.

## Configuration

The viewer supports various configuration options to control the output image's appearance. These include:

*   **Color Schemes:** Choose from predefined color palettes or create custom ones.
*   **Label Sizes:** Adjust the size of labels for roads, points of interest, and other features.
*   **Layer Visibility:** Control which layers are displayed in the final image (e.g., roads, buildings, water).
