## Overview ##

This viewer allows you to convert shapefiles (.shp) into Portable Network Graphics (.png) images. It's a simple tool for visualizing geospatial data without needing complex GIS software.

## Features ##

*   **Simple Interface:** Easy-to-use controls for zooming, panning, and adjusting the image quality.
*   **Shapefile Support:** Handles various shapefile formats commonly used in geographic information systems.
*   **PNG Output:** Generates high-quality PNG images suitable for reports, presentations, or web use.
*   **Customizable Rendering:** Options to control color schemes, symbol sizes, and label visibility.

## Usage ##

1.  **Upload Shapefile:** Drag and drop your `.shp` file into the designated area or click "Choose File" to select it from your computer.
2.  **Adjust Settings (Optional):** Modify rendering options such as background color, feature symbols, and labels.
3.  **Generate PNG:** Click the "Convert to PNG" button to start the conversion process.
4.  **Download Image:** Once the image is generated, click the "Download" button to save it to your computer.

## Technical Details ##

*   **Programming Language:** JavaScript
*   **Libraries:** Leaflet, Shapefile-js
*   **Dependencies:** None (browser-based)
*   **File Size Limit:** 50MB

## Troubleshooting ##

*   **Shapefile Not Loading:** Ensure the shapefile is valid and contains geographic data. Check for missing files (.shp, .dbf, .shx).
*   **Image Quality Issues:** Adjust the resolution settings to improve image clarity.
*   **Rendering Errors:** Try simplifying the shapefile by reducing the number of features or generalizing geometry.
