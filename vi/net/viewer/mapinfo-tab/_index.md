## MapInfo Tab Index

The MapInfo tab index is a list of all the tabs in the MapInfo viewer.

### Adding a New Tab

To add a new tab, you must first create a new MapInfo project. Once the project has been created, you can then add a new tab to the project.

#### Steps

1.  Create a new MapInfo project.
2.  Add a new tab to the project.
3.  Save the project.

### Removing a Tab

To remove a tab, you must first open the MapInfo project that contains the tab. Once the project has been opened, you can then select the tab and click the "Remove" button.

#### Steps

1.  Open the MapInfo project.
2.  Select the tab to be removed.
3.  Click the "Remove" button.
4.  Save the project.

### Editing a Tab

To edit a tab, you must first open the MapInfo project that contains the tab. Once the project has been opened, you can then select the tab and click the "Edit" button. This will open a dialog box where you can change the properties of the tab.

#### Steps

1.  Open the MapInfo project.
2.  Select the tab to be edited.
3.  Click the "Edit" button.
4.  Change the properties of the tab in the dialog box.
5.  Save the project.

### Tab Properties

The following are some of the properties that can be changed for a tab:

*   **Name:** The name of the tab.
*   **Description:** A description of the tab.
*   **Icon:** The icon to display for the tab.
*   **Visible:** Whether or not the tab is visible.
*   **Enabled:** Whether or not the tab is enabled.
