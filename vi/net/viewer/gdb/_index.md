## Features

*   View tables, feature classes, rasters, and other data sources.
*   Query data using SQL.
*   Edit data in place.
*   Share data with others.

## Getting Started

1.  Open the GDB Viewer.
2.  Connect to your geodatabase.
3.  Start exploring!

## Connecting to a Geodatabase

The GDB Viewer supports several types of geodatabases, including:

*   File geodatabases
*   Personal geodatabases
*   ArcSDE geodatabases

To connect to a geodatabase, click the "Connect" button and follow the prompts.

## Viewing Data

Once you are connected to a geodatabase, you can view its contents in the "Contents" pane. The Contents pane displays a hierarchical list of all data sources in the geodatabase.

You can expand each data source to see its child elements. For example, expanding a feature class will display its attributes.

## Querying Data

You can query data using SQL. To do this, click the "Query" button and enter your SQL query. The results of the query will be displayed in the "Results" pane.

## Editing Data

You can edit data in place. To do this, right-click on a feature or table and select "Edit". This will open an editor where you can modify the data.

## Sharing Data

You can share data with others by exporting it to a variety of formats. To export data, click the "Export" button and choose your desired format.
