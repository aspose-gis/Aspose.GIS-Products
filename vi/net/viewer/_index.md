## Overview

NetViewer is a web application that allows users to view and interact with geospatial data. It supports various data formats, including shapefiles, GeoJSON, and raster datasets.

## Features

*   **Data Visualization:** Display geospatial data on an interactive map.
*   **Attribute Queries:** Query attribute information for selected features.
*   **Spatial Analysis:** Perform basic spatial analysis operations such as buffering and intersection.
*   **Customization:** Customize the appearance of the map and data display.
*   **Sharing:** Share maps and datasets with others.

## Supported Data Formats

*   Shapefile
*   GeoJSON
*   Raster Datasets (e.g., GeoTIFF)
*   WMS/WMTS Services

## Installation

1.  Clone the repository:

    ```bash
    git clone [repository URL]
    ```
2.  Install dependencies:

    ```bash
    npm install
    ```
3.  Build the application:

    ```bash
    npm run build
    ```
4.  Serve the application:

    ```bash
    npm start
    ```

## Usage

1.  Open NetViewer in your web browser.
2.  Load a geospatial dataset using the "Load Data" button.
3.  Explore the data on the map by panning and zooming.
4.  Select features to view their attribute information.
5.  Perform spatial analysis operations as needed.
