  - title: "GPX File Support"
    content: "Supports standard GPX format for storing waypoints, routes, and tracks."
  - title: "Interactive Map"
    content: "Displays GPX data on an interactive map using Leaflet.js."
  - title: "Route Visualization"
    content: "Clearly visualizes routes with customizable line colors and thicknesses."
  - title: "Waypoint Markers"
    content: "Shows waypoints as markers on the map, allowing for easy identification of points of interest."
  - title: "Track Display"
    content: "Displays tracks as lines or paths, providing a visual representation of movement over time."
  - title: "Data Table"
    content: "Presents GPX data in a table format for detailed inspection and analysis."
  - title: "Customizable Appearance"
    content: "Allows users to customize the map's appearance with different basemaps and styles."
  - title: "Responsive Design"
    content: "Adapts seamlessly to various screen sizes, ensuring usability on desktops, tablets, and mobile devices."
usage: |
  1. **Open GPX File:** Drag and drop a GPX file onto the viewer or use the 'Open' button to select one from your computer.
  2. **View Data:** The GPX data will be displayed on the map and in the data table.
  3. **Interact with Map:** Zoom, pan, and interact with the map to explore the GPX data.
  4. **Customize Appearance (Optional):** Adjust the map's appearance using the customization options.

title: Cách sử dụng
content: |
  1. **Mở tệp GPX:** Kéo và thả tệp GPX lên trình xem hoặc sử dụng nút 'Mở' để chọn từ máy tính của bạn.
  2. **Xem dữ liệu:** Dữ liệu GPX sẽ được hiển thị trên bản đồ và trong bảng dữ liệu.
  3. **Tương tác với bản đồ:** Thu phóng, xoay và tương tác với bản đồ để khám phá dữ liệu GPX.
  4. **Tùy chỉnh giao diện (tùy chọn):** Điều chỉnh giao diện của bản đồ bằng cách sử dụng các tùy chọn tùy chỉnh.
