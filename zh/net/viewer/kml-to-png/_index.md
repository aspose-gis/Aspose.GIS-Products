## Convert KML to PNG

This tool converts KML files to PNG images.

### Input Requirements

*   **KML File:** A valid KML file containing geographic data.
*   **Output Resolution:** Specify the desired resolution of the output image (e.g., 800x600).
*   **Map Style:** Choose a map style to apply to the rendered image. Options include:
    *   Satellite
    *   Road Map
    *   Terrain

### Conversion Process

1.  Upload your KML file.
2.  Set the desired output resolution.
3.  Select a map style.
4.  Click "Convert" to generate the PNG image.

### Output Format

The tool will produce a PNG image representing the geographic data in the KML file, styled according to your selections.

### Troubleshooting

*   **Invalid KML File:** Ensure that the uploaded KML file is valid and well-formed.
*   **Resolution Issues:** If the output image appears blurry or pixelated, try increasing the resolution setting.
*   **Map Style Conflicts:** Some map styles may not be compatible with certain KML features. Experiment with different styles to find one that works best for your data.
