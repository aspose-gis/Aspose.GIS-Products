## Introduction

The GeoJSON Viewer is a tool for visualizing and interacting with GeoJSON data. It allows you to load, display, and explore geographic information encoded in the GeoJSON format.

## Features

*   **Loading GeoJSON Data:** Easily load GeoJSON files from local storage or remote URLs.
*   **Interactive Map Display:** View GeoJSON features on an interactive map with zoom and pan capabilities.
*   **Feature Highlighting:** Highlight individual features by clicking on them.
*   **Data Inspection:** Inspect the attributes of each feature in a detailed data panel.
*   **Customizable Styling:** Customize the appearance of GeoJSON features using various styling options.

## Usage

1.  **Load GeoJSON Data:** Click the "Load" button and select a GeoJSON file or enter a URL to load data from a remote source.
2.  **Explore the Map:** Use your mouse to pan and zoom around the map, exploring the geographic features displayed.
3.  **Inspect Features:** Click on individual features to view their attributes in the data panel.
4.  **Customize Styling (Optional):** Adjust styling options such as color, line width, and fill opacity to customize the appearance of GeoJSON features.

## Supported GeoJSON Formats

The GeoJSON Viewer supports a wide range of GeoJSON formats, including:

*   **Feature Collections:** A collection of geographic features with associated attributes.
*   **Feature Sets:** A set of geographic features with identical geometry types.
*   **Geometry Objects:** Individual geometric objects such as points, lines, and polygons.

## Troubleshooting

If you encounter any issues while using the GeoJSON Viewer, please refer to the following troubleshooting tips:

*   **Invalid GeoJSON Format:** Ensure that the GeoJSON file is valid and well-formed.
*   **Large Data Files:** Loading very large GeoJSON files may take a significant amount of time or cause performance issues. Consider simplifying the data or using a more efficient data format.
*   **Browser Compatibility:** The GeoJSON Viewer is compatible with most modern web browsers. If you encounter any compatibility issues, try updating your browser to the latest version.
