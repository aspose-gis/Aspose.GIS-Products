## MapInfo Tab Index

The MapInfo tab index allows you to view and interact with MapInfo tables directly within the viewer. This provides a convenient way to explore tabular data associated with your spatial datasets.

### Features

*   **Table Display:** View the contents of MapInfo tables in a structured format.
*   **Data Exploration:** Scroll through rows, examine column headers, and get an overview of the data.
*   **Filtering:** Filter table rows based on specific criteria to focus on relevant data.
*   **Sorting:** Sort table columns in ascending or descending order for easier analysis.
*   **Record Selection:** Select individual records within the table for further processing or export.

### Usage

1.  **Accessing the Tab Index:** Navigate to the "MapInfo" tab in the viewer interface. The tab index will be displayed by default, showing the tables associated with the currently loaded map.
2.  **Table Selection:** If multiple MapInfo tables are available, use the table selection dropdown to choose which table to display.
3.  **Navigation:** Use the scrollbars or page up/down keys to navigate through the rows of the selected table.
4.  **Filtering Data:** Utilize the filter options to narrow down the displayed records based on specific criteria.
5.  **Sorting Columns:** Click on column headers to sort the data in ascending or descending order.

### Configuration Options

The MapInfo tab index can be configured through various settings:

*   **Initial Table:** Specify which table should be displayed when the viewer loads.
*   **Default Sort Column:** Set the default column used for sorting the table data.
*   **Visible Columns:** Control which columns are initially visible in the table display.
*   **Filter Settings:** Define default filter criteria to apply to the table data.

### Troubleshooting

*   **Table Not Displaying:** Ensure that MapInfo tables are associated with the currently loaded map. Verify that the table paths are correct and accessible.
*   **Filtering Issues:** Double-check your filter criteria for accuracy. Make sure the data types of the columns match the filter conditions.
*   **Sorting Problems:** Confirm that the column you're trying to sort by contains sortable data. Avoid sorting on columns with mixed data types.

### Further Information

For more detailed information and advanced configuration options, refer to the viewer documentation or contact support.
