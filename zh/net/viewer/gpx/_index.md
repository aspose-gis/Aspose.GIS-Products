## 关于 GPX 文件查看器

本 GPX 文件查看器允许您加载和可视化 GPX 文件。GPX（GPS Exchange Format）是一种用于交换 GPS 数据的文件格式，通常包含航点、路线和轨迹信息。

## 功能

*   **加载 GPX 文件：**  您可以从本地文件系统或 URL 加载 GPX 文件。
*   **地图显示：**  GPX 文件中的航点、路线和轨迹将在地图上显示。
*   **数据表：**  GPX 文件的内容将以表格形式显示，方便您查看和编辑数据。
*   **搜索：**  您可以根据名称或描述搜索 GPX 文件中的特定航点。
*   **过滤：**  您可以根据类别或其他属性过滤 GPX 文件中的航点。
*   **导出：**  您可以将 GPX 数据导出为 CSV 或 KML 格式。

## 使用方法

1.  **加载 GPX 文件：** 点击“打开文件”按钮选择本地 GPX 文件，或在地址栏输入 URL 加载在线 GPX 文件。
2.  **地图显示：** 地图将自动缩放到 GPX 文件的范围，并显示航点、路线和轨迹。
3.  **数据表：** 数据表将显示 GPX 文件的内容，您可以滚动查看所有航点。
4.  **搜索和过滤：** 使用搜索框查找特定航点，使用过滤器筛选航点。
5.  **导出：** 点击“导出”按钮选择导出的格式（CSV 或 KML），然后保存文件。

## 支持的 GPX 元素

*   **航点 (Waypoint):**  包含经纬度、名称、描述和其他属性的信息。
*   **路线 (Route):**  一系列航点的集合，用于规划导航路径。
*   **轨迹 (Track):**  记录了 GPS 设备移动的轨迹，包含多个航道片段。

## 常见问题解答

*   **GPX 文件是什么？** GPX 是一种用于交换 GPS 数据的标准文件格式。
*   **如何创建 GPX 文件？** 您可以使用各种 GPS 设备或软件创建 GPX 文件。
*   **GPX 文件查看器支持哪些地图服务？**  目前支持 OpenStreetMap 和 Google Maps。
*   **我可以编辑 GPX 文件吗？**  本工具主要用于查看 GPX 文件，不提供直接编辑功能。
