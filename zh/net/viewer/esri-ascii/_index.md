## Introduction

The Esri ASCII Viewer is a tool that allows you to view and interact with ASCII raster datasets. It's particularly useful for visualizing data stored in simple text formats, such as elevation grids or satellite imagery represented as numbers.

## Features

*   **Data Visualization:** Displays ASCII raster data as an image.
*   **Interactive Zooming and Panning:** Allows users to navigate the dataset.
*   **Color Mapping:** Supports various color schemes for enhanced visualization.
*   **Data Query:** Enables querying of pixel values at specific locations.
*   **Simple Data Format Support:** Handles common ASCII raster formats.

## Usage

1.  **Load Data:** Use the "Open" button to load an ASCII raster dataset. Supported file types include `.asc`, `.txt`, and others.
2.  **Adjust Color Scheme:** Select a color scheme from the dropdown menu to optimize visualization based on data characteristics.
3.  **Zoom and Pan:** Use the mouse wheel to zoom in/out and click-and-drag to pan across the dataset.
4.  **Query Pixel Values:** Right-click on any pixel to display its value.

## Supported Data Formats

*   `.asc` (Esri ASCII Grid)
*   `.txt` (Generic Text File - comma, space or tab delimited)
*   Other simple text formats where data is represented as numbers separated by delimiters.

## Troubleshooting

*   **Data Not Loading:** Ensure the file is in a supported format and contains numerical data. Check for any non-numerical characters that might be causing issues.
*   **Visualization Issues:** Experiment with different color schemes to find one that best represents your data. Adjust contrast settings if necessary.
*   **Performance Problems:** Large datasets can impact performance. Consider downsampling the data or using a more powerful computer.
