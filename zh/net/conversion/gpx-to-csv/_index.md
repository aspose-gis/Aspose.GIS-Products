        {{< blocks/products/pf/agp/about-file-text fileFormat="GPX" readMoreLink="https://docs.fileformat.com/gis/gpx/" >}}

GPX 扩展名代表 GPS Exchange 格式，用于在应用程序和互联网上的 Web 服务之间交换 GPS 数据。它是一种轻量级的 XML 格式，包含 GPS 数据，即航点、路线和轨迹，以便多个程序导入和读取。 GPX 是开放的，并受各种应用程序和 GPS 设备的支持。

        {{< /blocks/products/pf/agp/about-file-text >}}

        {{< blocks/products/pf/agp/about-file-text fileFormat="CSV" readMoreLink="https://docs.fileformat.com/spreadsheet/csv/" >}}

具有 CSV (逗号分隔值) 扩展名的文件代表纯文本文件，其中包含以逗号分隔的值的数据记录。CSV 文件中的每一行都是文件中记录集中的新记录。当打算从一个存储系统传输到另一个存储系统时，会生成此类文件。由于所有应用程序都可以识别由逗号分隔的记录，因此非常方便地将这些数据导入数据库。
