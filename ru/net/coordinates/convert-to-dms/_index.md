<p>
 Aspose.GIS для .NET позволяет преобразовывать градусы минуты секунды (DMS) для геопространственных единиц. Наша библиотека позволяет легко и быстро преобразовывать широту и долготу в желаемый формат единиц измерения. Кроме того, наша библиотека содержит возможность извлечения местоположений в точку из текста.
</p>

<p>
 Aspose.GIS для .NET разработан с учетом простоты, производительности, удобства использования и портативности. Он содержит API для использования с платформами .NET Framework и .NET Core, что позволяет создавать кроссплатформенные приложения с большой легкостью.
</p>
