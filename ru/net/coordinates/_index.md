<p>
 Aspose.GIS for .NET позволяет вам создавать координатный конвертер для геопространственных единиц. Наша библиотека позволяет легко и быстро преобразовывать широту и долготу в желаемый формат единиц измерения. Кроме того, наша библиотека содержит возможность извлекать местоположения в точку из текста.
</p>

<p>
 Aspose.GIS for .NET разработан с учетом простоты, производительности, удобства использования и портативности. Он содержит API для использования с платформами .NET Framework и .NET Core, что позволяет вам создавать кроссплатформенные приложения с большой легкостью.
</p>
