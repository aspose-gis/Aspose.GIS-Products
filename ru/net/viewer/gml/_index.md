## Overview

The GML Viewer allows you to visualize and interact with Geographic Markup Language (GML) files. It provides a user-friendly interface for exploring spatial data, performing queries, and analyzing features.

## Features

*   **Visualization:** Display GML data on an interactive map.
*   **Querying:** Filter and select features based on attributes.
*   **Attribute Inspection:** View detailed information about individual features.
*   **Zoom and Pan:** Navigate the map to explore different areas of interest.
*   **Layer Management:** Control the visibility and order of GML layers.
*   **Data Export:** Export selected features or the entire dataset in various formats.

## Usage

1.  **Load GML File:** Use the "Open" button to load a GML file from your computer.
2.  **Explore Data:** Pan, zoom, and interact with the map to view the loaded data.
3.  **Query Features:** Use the query tools to select features based on attribute values.
4.  **Inspect Attributes:** Click on a feature to view its attributes in the details panel.
5.  **Export Data:** Use the export functionality to save selected or all data to a file.

## Supported GML Dialects

The GML Viewer supports various GML dialects, including:

*   Simple Feature GML
*   Complex Feature GML
*   Motion Feature GML
