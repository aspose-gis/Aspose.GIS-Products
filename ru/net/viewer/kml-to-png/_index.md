## Frequently Asked Questions (FAQ)

**Q: What is KML?**
**A:** KML (Keyhole Markup Language) is a file format used to store geographic data, such as points, lines, polygons, and images. It's commonly used with Google Earth and other mapping applications.

**Q: What is PNG?**
**A:** PNG (Portable Network Graphics) is a raster image file format that supports lossless compression.
