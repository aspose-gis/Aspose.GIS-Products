## Convert GPX to PNG

This tool converts GPX files to PNG images. You can upload a GPX file and adjust the settings to create a custom map image.

### Upload GPX File

Upload your GPX file using the file input field. Supported formats are `.gpx`.

### Settings

*   **Map Style:** Choose from different map styles to customize the appearance of the generated image.
*   **Zoom Level:** Adjust the zoom level to control the scale of the map.
*   **Image Width:** Set the width of the output PNG image in pixels.
*   **Image Height:** Set the height of the output PNG image in pixels.

### Generate Image

Click the "Generate Image" button to create the PNG image based on your GPX file and settings. The generated image will be displayed below the button.

### Download Image

Download the generated PNG image by clicking the "Download Image" button.

## Привести GPX к PNG

Этот инструмент преобразует файлы GPX в изображения PNG. Вы можете загрузить файл GPX и настроить параметры для создания пользовательского изображения карты.

### Загрузка файла GPX

Загрузите свой файл GPX с помощью поля ввода файла. Поддерживаемые форматы — `.gpx`.

### Настройки

*   **Стиль карты:** Выберите различные стили карт, чтобы настроить внешний вид создаваемого изображения.
*   **Уровень масштаба:** Отрегулируйте уровень масштаба для управления масштабом карты.
*   **Ширина изображения:** Установите ширину выходного PNG-изображения в пикселях.
*   **Высота изображения:** Установите высоту выходного PNG-изображения в пикселях.

### Создать изображение

Нажмите кнопку «Создать изображение», чтобы создать изображение PNG на основе вашего файла GPX и настроек. Сгенерированное изображение будет отображаться под кнопкой.

### Загрузить изображение

Загрузите созданное изображение PNG, нажав кнопку «Загрузить изображение».
