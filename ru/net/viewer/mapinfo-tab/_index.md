## Overview

The MapInfo tab provides access to various tools and functions for working with MapInfo files. This includes importing, exporting, displaying, and editing data in MapInfo format.

## Importing Data

To import a MapInfo file into the viewer, use the "Import" button on the toolbar or select "File -> Import -> MapInfo".  A dialog box will appear allowing you to specify the file name and other import options.

## Exporting Data

To export data from the viewer in MapInfo format, use the "Export" button on the toolbar or select "File -> Export -> MapInfo". A dialog box will appear allowing you to specify the file name and other export options.

## Displaying Data

Once a MapInfo file has been imported, it will be displayed in the main map view.  You can zoom, pan, and rotate the view as needed.

## Editing Data

The MapInfo tab also provides tools for editing data in MapInfo files. This includes adding, deleting, and modifying features.

## Supported Formats

The viewer supports the following MapInfo file formats:

*   .tab
*   .map
*   .e00
*   .e01
*   .e02
*   .e03
*   .e04
*   .e05
*   .e06
*   .e07
*   .e08
*   .e09
*   .e10

## Troubleshooting

If you are having trouble importing or exporting MapInfo files, please consult the troubleshooting section of the documentation.
