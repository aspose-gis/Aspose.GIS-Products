## Описание

Этот инструмент позволяет преобразовывать файлы шейп-файлов (.shp), используемые в географических информационных системах (ГИС), в формат Scalable Vector Graphics (.svg).  SVG - это масштабируемый векторный графический формат, который идеально подходит для веб-графики и других приложений, где требуется высокое качество изображения при любом размере.

## Функциональность

*   **Загрузка SHP файла:** Вы можете загрузить файл шейп-файла с вашего компьютера.
*   **Предварительный просмотр:** Инструмент отображает предварительный просмотр содержимого SHP файла на карте.
*   **Преобразование в SVG:**  Выполняет преобразование выбранного SHP файла в SVG формат.
*   **Скачивание SVG файла:** Предоставляет возможность скачать полученный SVG файл.

## Использование

1.  Загрузите свой SHP файл, нажав кнопку "Выберите файл".
2.  Ознакомьтесь с предварительным просмотром на карте.
3.  Нажмите кнопку "Преобразовать в SVG", чтобы начать процесс преобразования.
4.  После завершения преобразования вы сможете скачать полученный SVG файл.

## Примечания

*   Размер загружаемого SHP файла может быть ограничен.
*   Сложные SHP файлы могут потребовать больше времени для преобразования.
*   Убедитесь, что у вас есть необходимые права доступа для чтения и записи файлов.

## Поддержка форматов

*   SHP (Shapefile)
*   SVG (Scalable Vector Graphics)

## Ограничения

*   Поддерживаются только SHP файлы с простой геометрией (точки, линии, полигоны).
*   Не поддерживается преобразование SHP файлов с атрибутивной информацией.  Атрибуты будут потеряны в процессе преобразования.
*   Преобразование может быть неточным для очень больших или сложных SHP файлов.

## Примеры использования

*   Создание векторных карт для веб-сайтов.
*   Экспорт данных ГИС в формат, совместимый с другими графическими редакторами.
*   Подготовка данных для печати и публикации.
