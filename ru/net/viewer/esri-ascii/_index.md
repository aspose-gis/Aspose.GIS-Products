## Overview

The Esri ASCII viewer is a simple tool for viewing ASCII text files as rasters. It's useful for visualizing data that has been exported from other applications or created manually.

## Features

*   View ASCII text files as rasters
*   Adjust the color scheme
*   Zoom and pan the image
*   Save the image as a PNG file

## Usage

1.  Open the Esri ASCII viewer.
2.  Click the "File" menu and select "Open".
3.  Select the ASCII text file you want to view.
4.  Adjust the color scheme as needed.
5.  Zoom and pan the image to see the data in more detail.
6.  Click the "File" menu and select "Save As" to save the image as a PNG file.

## Troubleshooting

*   If the image is not displaying correctly, make sure that the ASCII text file is properly formatted.
*   If you are having trouble opening the ASCII text file, make sure that you have the correct permissions.
*   If you are still having problems, contact Esri support for assistance.
