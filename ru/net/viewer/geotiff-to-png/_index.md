## Что такое GeoTIFF?

GeoTIFF (Georeferenced Tagged Image File Format) - это расширение формата TIFF, которое добавляет географические данные к изображению. Это позволяет использовать изображения в ГИС-приложениях и других геопространственных системах.

## Что такое PNG?

PNG (Portable Network Graphics) - это графический формат файла, который использует сжатие без потерь. Он широко используется для хранения изображений, особенно тех, которые содержат текст или графику.
