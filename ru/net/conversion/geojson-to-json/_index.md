GeoJSON — это формат на основе JSON, предназначенный для представления географических объектов с их не пространственными атрибутами. Этот формат определяет различные объекты JSON (нотация JavaScript Object Notation) и способ их соединения. Формат JSON представляет коллективную информацию о географических объектах, их пространственных пределах и свойствах. Объект этого файла может указывать геометрию (Точка, Линия, Полигон), признак или набор признаков. Признаки отражают адреса и места как точки, улицы, основные дороги и границы как линии и страны, провинции и земельные регионы как полигоны. Используя GeoJSON, различные мобильные приложения для маршрутизации и навигации могут указывать покрытие своих услуг. Расширением GeoJSON является TopoJSON, который меньше по размеру и кодирует геопространственную топологию.

JSON (JavaScript Object Notation) — это открытый стандарт формата файла для обмена данными, который использует удобочитаемый текст для хранения и передачи данных. JSON файлы хранятся с расширением .json. JSON требует меньше форматирования и является хорошей альтернативой XML. JSON происходит из JavaScript, но представляет собой язык-независимый формат данных. Генерация и разбор JSON поддерживается многими современными языками программирования. application/json — это тип носителя, используемый для JSON.
