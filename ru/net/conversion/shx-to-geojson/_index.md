        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON — это формат на основе JSON, предназначенный для представления географических объектов с их не пространственными атрибутами. Этот формат определяет различные объекты JSON (нотация JavaScript Object Notation) и способ их соединения. Формат JSON представляет коллективную информацию о географических объектах, их пространственных пределах и свойствах. Объект этого файла может указывать на геометрию (Точка, Линия, Полигон), объект или набор объектов. Объекты отражают адреса и места как точки, улицы, основные дороги и границы как линии и страны, провинции и регионы земли как полигоны. Используя GeoJSON, различные мобильные приложения маршрутизации и навигации могут указывать покрытие своих услуг. Расширением GeoJSON является TopoJSON, который меньше по размеру и кодирует геопространственную топологию.
