Файлы с расширением CSV (Comma Separated Values) представляют собой обычные текстовые файлы, содержащие записи данных со значениями, разделенными запятыми. Каждая строка в CSV файле — это новая запись из набора записей, содержащихся в файле. Такие файлы создаются при передаче данных из одной системы хранения в другую.
