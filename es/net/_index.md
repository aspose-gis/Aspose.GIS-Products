<p>Aspose.GIS para .NET le permite acceder y manipular información geográfica de formatos de datos geoespaciales basados en vectores. La API admite leer, escribir y convertir los formatos de archivo GIS más populares como Shapefile, GeoJSON, FIleGDB, KML y OSM XML, así como renderizar un mapa a partir de formatos compatibles a SVG. Además, un desarrollador puede personalizar fácilmente la representación y los estilos de las características para obtener el aspecto deseado del mapa.</p>

<p>Aspose.GIS para .NET está diseñado pensando en la simplicidad, el rendimiento, la usabilidad y la portabilidad. Contiene API para usar con .NET Framework, .NET Core y plataformas Xamarin, lo que le permite crear aplicaciones multiplataforma con gran facilidad.</p>

   <div class="col-lg-12">
    <h2 class="h2title">
     Una API Única para Varios Formatos
    </h2>
    <p>
     Aspose.GIS se encarga de todos los detalles tediosos de los formatos de datos y le proporciona un modelo de objeto limpio y simple para los datos GIS. Puede leer o almacenar datos en archivos con un código universal e independiente del formato.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Lea datos GIS desde un Shapefile - C#
     </h3>
     <pre><code class="cs">using (var layer = VectorLayer.Open(dir + "myDataFile.shp", Drivers.Shapefile))

{

    foreach (var feature in layer)

    {

        Console.WriteLine(feature.Geometry.AsText()); // imprima la geometría como WKT

        Console.WriteLine(feature.GetValue&lt;string&gt;("CITY_NAME")); // imprima un valor de atributo

        Console.WriteLine(feature.GetValue&lt;DateTime&gt;("UPDATE_DAT")); 
    }

}</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Convierta Datos GIS Entre Formatos
    </h2>
    <p>
     Convertir datos GIS de un formato a otro con Aspose.GIS generalmente toma solo una línea de código.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Convierta un Shapefile a GeoJSON - C#
     </h3>
     <pre><code class="cs">VectorLayer.Convert(dir + "example.shp", Drivers.Shapefile, dir + "output.json", Drivers.GeoJson);</code></pre>
    </div>
    <p>
     Si es necesario, puede realizar operaciones adicionales durante las conversiones, como ajustar el esquema de atributos de datos o reproyección sobre la marcha de las geometrías de las características.
    </p>
    <p>
     Algunos ejemplos de conversiones de formatos admitidas:
    </p>
    <ul>
     <li>
      Shapefile a KML
     </li>
     <li>
      Shapefile a Base de Datos Geográfica
     </li>
     <li>
      GeoJSON a Shapefile
     </li>
     <li>
      KML a Base de Datos Geográfica
     </li>
     <li>
      KML a Shapefile
     </li>
     <li>
      KML a GeoJSON
     </li>
     <li>
      GPX a Base de Datos Geográfica
     </li>
     <li>
      GPX a GeoJSON
     </li>
     <li>
      GPX a KML
     </li>
     <li>
      GPX a TopoJSON
     </li>
     <li>
      MapInfo Interchange a GeoJSON
     </li>
     <li>
      MapInfo Interchange a Shapefile
     </li>
     <li>
      MapInfo TAB a KML
     </li>
     <li>
      OSM a Shapefile
     </li>
     <li>
      GML a Base de Datos Geográfica
     </li>
    </ul>
    <p>
     La conversión de archivos GIS a formatos raster está impulsada por los módulos de exportación de
     <a href="https://products.aspose.com/imaging/net">
      Aspose.Imaging
     </a>
    </p>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Renderice Mapas
    </h2>
    <p>
     Los datos solo son útiles cuando alguien puede verlos. La biblioteca GIS para .NET facilita y acelera la exportación de datos GIS a imágenes vectoriales o rasterizadas y proporciona una simbología rica para escenarios de visualización complejos.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Renderice un mapa TopoJSON a SVG - C#
     </h3>
     <pre><code class="cs">using (var map = new Map(800, 600))

{

    var layer = VectorLayer.Open(dir + "map.json", Drivers.TopoJson);

    var style = new SimpleFill { FillColor = Color.Azure, StrokeWidth = 1.5 };

    map.Add(layer, style);

    map.Render(dir + "mymap.svg", Renderers.Svg);

}</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Use Diferentes Sistemas de Coordenadas
    </h2>
    <p>
     Con Aspose.GIS, puede transformar coordenadas geográficas, geometrías y capas enteras desde un sistema de referencia de coordenadas a otro. Se admiten proyecciones cartográficas así como transformaciones geodésicas.
    </p>
    <p>
     Puede buscar un sistema de referencia de coordenadas por SRID, importar desde WKT o establecer parámetros personalizados directamente en el código.
    </p>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Realice Análisis Espacial

    <ul>

     <li>

      Compruebe si la geometría de un objeto se intersecta consigo misma
     </li>
     <li>
      Compute el área de una geometría
     </li>
    </ul>
    <p>
     Aspose.GIS le permite realizar fácilmente operaciones geométricas, como:
