<p>
 Aspose.GIS para .NET le permite convertir Sistema de Referencia Geográfico Mundial (GeoRef) para unidades geoespaciales. Nuestra biblioteca le permite convertir fácilmente y rápidamente la latitud y la longitud a un formato de unidad deseado. También nuestra biblioteca contiene la posibilidad de extraer ubicaciones a un punto desde un texto.
</p>

<p>
 Aspose.GIS para .NET está diseñado pensando en la simplicidad, el rendimiento, la usabilidad y la portabilidad. Contiene APIs para usar con las plataformas .NET Framework y .NET Core, lo que le permite crear aplicaciones multiplataforma con gran facilidad.
</p>
