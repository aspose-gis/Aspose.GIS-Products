        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON es un formato basado en JSON diseñado para representar las características geográficas con sus atributos no espaciales. Este formato define diferentes objetos JSON (Notación de Objetos JavaScript) y su forma de unión. El formato JSON representa información colectiva sobre las características geográficas, sus extensiones espaciales y propiedades. Un objeto de este archivo puede indicar una geometría (Punto, LineString, Polígono), una característica o una colección de características. Las características reflejan direcciones y lugares como puntos, calles, carreteras principales y bordes como líneas y países, provincias y regiones terrestres como polígonos. Usando GeoJSON, diferentes aplicaciones de enrutamiento y navegación móvil pueden indicar la cobertura de sus servicios. Una extensión de GeoJSON es TopoJSON que es más pequeña en tamaño y codifica la topología geoespacial.
