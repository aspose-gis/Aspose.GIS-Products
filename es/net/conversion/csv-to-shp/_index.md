Los archivos con extensión CSV (Comma Separated Values) representan archivos de texto plano que contienen registros de datos con valores separados por comas. Cada línea en un archivo CSV es un nuevo registro del conjunto de registros contenidos en el archivo. Dichos archivos se generan cuando se pretende la transferencia de datos de un sistema de almacenamiento a otro. Dado que todas las aplicaciones pueden reconocer registros separados por comas, la importación de dichos archivos de datos a una base de datos se realiza de forma muy conveniente.
