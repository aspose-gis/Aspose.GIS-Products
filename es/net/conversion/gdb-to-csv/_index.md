GDB es el formato utilizado por la plataforma Esri ArcGIS. Esta es la carpeta que contiene una colección de archivos .gdbtable, .gdbtablx, .gdbindexes, .atx, .spx y .freelist, etc.

        {{< blocks/products/pf/agp/about-file-text fileFormat="CSV" readMoreLink="https://docs.fileformat.com/spreadsheet/csv/" >}}

Los archivos con extensión CSV (Comma Separated Values) representan archivos de texto plano que contienen registros de datos con valores separados por comas. Cada línea en un archivo CSV es un nuevo registro del conjunto de registros contenido en el archivo. Estos archivos se generan cuando se pretende la transferencia de datos de un sistema de almacenamiento a otro. Dado que todas las aplicaciones pueden reconocer registros separados por comas, la importación de dichos archivos de datos a una base de datos se realiza de forma muy conveniente.
