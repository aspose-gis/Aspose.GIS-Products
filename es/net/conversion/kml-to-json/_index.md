KML (Keyhole Markup Language) contiene información geoespacial en notación XML. KML se puede abrir en aplicaciones de sistemas de información geográfica (GIS) siempre que las admitan. Muchas aplicaciones han comenzado a brindar soporte para el formato KML después de que se adoptó como estándar internacional.

        {{< blocks/products/pf/agp/about-file-text fileFormat="GeoJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON es un formato basado en JSON diseñado para representar las características geográficas con sus atributos no espaciales. Este formato define diferentes objetos JSON (Notación de Objetos JavaScript) y su forma de unión. JSON representa una información colectiva sobre las características geográficas, sus extensiones espaciales y propiedades.
