GeoJSON es un formato basado en JSON diseñado para representar las características geográficas con sus atributos no espaciales. Este formato define diferentes objetos JSON y su forma de unión. JSON representa una información colectiva sobre las características geográficas, sus extensiones espaciales y propiedades.

        {{< blocks/products/pf/agp/about-file-text fileFormat="CSV" readMoreLink="https://docs.fileformat.com/spreadsheet/csv/" >}}

Los archivos con extensión CSV (Comma Separated Values) representan archivos de texto plano que contienen registros de datos con valores separados por comas. Cada línea en un archivo CSV es un nuevo registro del conjunto de registros contenido en el archivo. Dichos archivos se generan cuando se pretende la transferencia de datos de un sistema de almacenamiento a otro. Dado que todas las aplicaciones pueden reconocer los registros separados por comas, la importación de dichos archivos de datos a una base de datos se realiza de forma muy conveniente.
