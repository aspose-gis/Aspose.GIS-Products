OpenStreetMap (OSM) es una gran colección de información geográfica voluntaria almacenada en diferentes tipos de archivos, utilizando diferentes esquemas de codificación para convertir estos datos en bits y bytes. OSM es un esfuerzo colaborativo hacia la creación de un mapa editable gratuito del mundo. La salida principal de este esfuerzo colaborativo son los datos geográficos más que el propio mapa. Las restricciones sobre el uso o la disponibilidad de información geográfica en gran parte del mundo desencadenan la necesidad de crear un OSM. Los datos disponibles de OSM están listos para reemplazar Google Maps para aplicaciones clásicas (Facebook, Craigslist, etc.) y datos predeterminados para las aplicaciones de receptores GPS. Aunque la calidad de los datos varía en todo el mundo, los datos de OpenStreetMap se pueden comparar cómodamente con las fuentes de datos patentadas.
