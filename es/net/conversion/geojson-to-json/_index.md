        {{< blocks/products/pf/agp/about-file-text fileFormat="GEOJSON" readMoreLink="https://docs.fileformat.com/gis/geojson/" >}}

GeoJSON es un formato basado en JSON diseñado para representar las características geográficas con sus atributos no espaciales. Este formato define diferentes objetos JSON (Notación de Objetos JavaScript) y su forma de unión. El formato JSON representa información colectiva sobre las características geográficas, sus extensiones espaciales y propiedades. Un objeto de este archivo puede indicar una geometría (Punto, LineString, Polígono), una característica o una colección de características. Las características reflejan direcciones y lugares como puntos, calles principales y carreteras como líneas y países, provincias y regiones terrestres como polígonos. Usando GeoJSON, diferentes aplicaciones de enrutamiento y navegación móviles pueden indicar la cobertura de sus servicios. Una extensión de GeoJSON es TopoJSON que es más pequeña en tamaño y codifica la topología geoespacial.

        {{< blocks/products/pf/agp/about-file-text fileFormat="JSON" readMoreLink="https://docs.fileformat.com/web/json/" >}}

JSON (Notación de Objetos JavaScript) es un formato de archivo estándar abierto para compartir datos que utiliza texto legible por humanos para almacenar y transmitir datos. Los archivos JSON se almacenan con la extensión .json. JSON requiere menos formateo y es una buena alternativa a XML. JSON deriva de JavaScript pero es un formato de datos independiente del lenguaje. La generación y el análisis de JSON son compatibles con muchos lenguajes de programación modernos. application/json es el tipo de medio utilizado para JSON.
