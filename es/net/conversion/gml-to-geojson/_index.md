Geographic Markup Language (conocido como GML) es un formato basado en XML utilizado en GIS. GML es un formato de intercambio abierto para transacciones geográficas en Internet. Este formato está orientado a datos y estructura.

GeoJSON es un formato basado en JSON diseñado para representar las características geográficas con sus atributos no espaciales. Este formato define diferentes objetos JSON (JavaScript Object Notation) y su forma de unión. JSON representa una información colectiva sobre las características geográficas, sus extensiones espaciales y propiedades.
