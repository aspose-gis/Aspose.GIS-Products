Los archivos con extensión GPX representan el formato de intercambio GPS para el intercambio de datos GPS entre aplicaciones y servicios web en Internet. Es un formato XML ligero que contiene datos GPS, es decir, puntos de ruta, rutas y pistas para ser importados y leídos por múltiples programas. El formato de archivo GPX es abierto y es compatible con una variedad de aplicaciones y dispositivos GPS. Los datos GPS de dichos archivos se pueden cargar para su visualización en aplicaciones de mapeo con fines geoespaciales.
