SHP es la extensión de archivo para uno de los tipos de archivos principales utilizados para la representación de Shapefiles ESRI. Este formato define diferentes objetos JSON (Notación de Objetos JavaScript) y su forma de unión. JSON representa una información colectiva sobre las características geográficas, sus extensiones espaciales y propiedades.
